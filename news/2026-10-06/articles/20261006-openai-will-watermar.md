# OpenAI will watermark ChatGPT text in the EU but makes it optional for API users worldwide

**Source**: The Decoder | **Published**: Mon, 05 Oct 2026 17:32:42 +0000 | **Topics**: llm_models, ai_policy

## Summary
오픈AI가 EU 내 챗GPT·코덱스 텍스트에 보이지 않는 'textGrain' 워터마크를 적용하되, 앤트로픽과 달리 전 세계 API 고객에게는 해제 옵션을 준다. 검출률은 최대 95%지만 단어 4분의 1을 바꾸면 17%로 떨어진다.

## Key Points
- EU AI Act 대응 텍스트 워터마크 도입
- API 고객은 전 세계적으로 옵트아웃 가능
- 검출률 95%, 편집 시 17%로 급락
- 검출 도구 접근은 연구자부터

## Why This Matters
AI 생성 콘텐츠 표시 의무가 현실화되며, EU 대상 고객 커뮤니케이션에 생성형 AI를 쓰는 기업은 워터마크 적용 여부와 고지 정책을 정비해야 한다.
