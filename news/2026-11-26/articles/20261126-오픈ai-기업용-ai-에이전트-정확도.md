# 오픈AI, 기업용 AI 에이전트 정확도 높이는 데이터 도구 '아테나' 개발 중

**Source**: AI타임스 | **Published**: 2026-11-25 17:46:26 | **Topics**: ai_agents, ai_industry

## Summary
오픈AI가 기업용 데이터 에이전트의 분석 정확도를 높이기 위한 데이터 관리 플랫폼 '아테나'를 개발 중이다. 기업별 데이터 구조·업무 용어·지표 의미를 AI가 정확히 이해하도록 하는 것이 목표로, 일부 고객사에서 답변 오류가 문제된 것이 배경이다.

## Key Points
- 코드명 '아테나' 데이터 관리 플랫폼 개발
- 기업별 용어·지표 정의를 에이전트에 제공
- 챗GPT 워크 데이터 에이전트의 오류 개선 목적

## Why This Matters
데이터 에이전트 성과는 모델보다 기업 데이터 정의·메타데이터 정비에 달려 있음을 보여, 데이터 거버넌스 투자가 선행 과제가 된다.
