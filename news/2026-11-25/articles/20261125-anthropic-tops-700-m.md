# Anthropic tops 700 million monthly MCP SDK downloads and expands the protocol for more autonomous AI agents

**Source**: The Decoder | **Published**: Tue, 24 Nov 2026 19:23:41 +0000 | **Topics**: ai_agents, ai_industry

## Summary
앤트로픽은 MCP SDK 월간 다운로드가 7억 건을 넘었다고 밝혔다. 백그라운드 작업, 사용자 후속 질문, 파일 업로드 기능을 추가해 에이전트가 더 독립적으로 일하도록 확장했다.

## Key Points
- 출시 2년 만에 MCP SDK 월 7억 다운로드
- 백그라운드 작업·후속 질문·파일 업로드 추가
- 장시간 자율 실행형 에이전트 지원 강화

## Why This Matters
MCP가 에이전트 연동 표준으로 굳어져, 기업은 사내 시스템을 MCP 서버로 개방하는 것을 에이전트 전략의 기본 인프라로 볼 필요가 있다.
