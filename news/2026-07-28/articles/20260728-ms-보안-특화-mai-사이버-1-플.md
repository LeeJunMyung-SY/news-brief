# MS, 보안 특화 'MAI-사이버-1-플래시' 공개..."앤트로픽·오픈AI 능가"

**Source**: AI타임스 | **Published**: 2026-07-28 13:30:13 | **Topics**: llm_models, ai_agents, ai_industry

## Summary
마이크로소프트가 사이버 보안 특화 모델 'MAI-사이버-1-플래시'와 다중 에이전트 보안 플랫폼 '프로젝트 퍼셉션'을 공개했다. 보안 벤치마크에서 앤트로픽·구글·오픈AI 최신 모델을 앞서면서 운영 비용은 절반 수준이라고 강조했다.

## Key Points
- 보안 특화 모델 MAI-Cyber-1-Flash 공개
- 다중 에이전트 취약점 탐지·복구 프레임워크 MDASH에 적용
- 경쟁 모델 대비 벤치마크 우위 + 운영비 절반 주장
- 에이전틱 보안 플랫폼 '프로젝트 퍼셉션' 동시 발표

## Why This Matters
보안 영역에서 도메인 특화 소형 모델이 범용 프런티어 모델보다 비용·성능 모두 유리하다는 주장이 나온 것으로, 기업의 AI 보안 솔루션 조달 기준이 '범용 최고 모델'에서 '도메인 특화 TCO'로 이동할 수 있다.
