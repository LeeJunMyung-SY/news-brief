# 오픈AI, 'GPT-6.2' 응답 늦게 받으면 API 요금 최대 40% 할인

**Source**: AI타임스 | **Published**: 2026-11-20 17:17:56 | **Topics**: ai_industry, llm_models

## Summary
오픈AI가 API 요청의 완료 목표 시간을 2시간 또는 8시간으로 설정하면 요금을 할인하는 과금 옵션을 도입했다. 2시간은 표준 요금보다 30%, 8시간은 40% 저렴하다.

## Key Points
- 완료 목표 시간에 따른 차등 요금 도입
- 2시간 설정 시 30%, 8시간 설정 시 40% 할인
- 대규모 작업을 수행하는 기업·개발자의 비용 절감이 목적
- 설정 시간은 처리 완료 목표 시간

## Why This Matters
실시간 응답이 필요 없는 문서 처리·분석·배치 업무는 지연 허용 요금제로 옮기면 비용을 크게 줄일 수 있다. 업무를 응답 시급성 기준으로 분류해 요금제를 나누는 것이 조달 설계의 새 변수가 된다.
