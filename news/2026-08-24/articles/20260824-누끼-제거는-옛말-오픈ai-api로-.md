# "누끼 제거는 옛말"…오픈AI, API로 '배경 없는 투명 이미지' 직접 생성

**Source**: AI타임스 | **Published**: 2026-08-24 15:48:24 | **Topics**: llm_models

## Summary
오픈AI가 이미지 생성 모델 'gpt-image-2' API에 네이티브 알파 채널 지원을 추가했다. 별도 배경 제거 후처리 없이 한 번의 요청으로 투명 배경 PNG를 생성할 수 있게 됐다.

## Key Points
- background='transparent'와 output_format='png' 파라미터로 적용
- 누끼 따기 후처리 공정 제거
- 개발자 API 업데이트로 제공
- 21일(현지시간) 발표

## Why This Matters
디자인·커머스 콘텐츠 제작에서 별도 후처리 도구와 인력이 차지하던 공정을 API 호출 하나로 흡수해, 제작 파이프라인 재설계 여지를 만든다.
