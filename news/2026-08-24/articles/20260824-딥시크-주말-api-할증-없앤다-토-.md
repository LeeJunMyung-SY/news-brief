# 딥시크, 주말 API 할증 없앤다…토·일요일 '오프피크' 단가 단일화

**Source**: AI타임스 | **Published**: 2026-08-24 15:23:53 | **Topics**: llm_models, ai_industry

## Summary
딥시크가 주말 API 요금에서 피크 시간대 할증을 없애고 토·일요일 전 시간대에 비성수기 단가를 적용한다. 이달 초 이용량 급증에 대응해 도입한 가변 요금제를 주말만 완화한 조치다.

## Key Points
- 베이징 시간 8월 23일 0시부터 적용
- 주말 전 시간대 오프피크 단가 단일화
- 이달 초 도입한 가변 요금제의 부분 완화
- 대량 배치·비실시간 작업 비용 부담 완화

## Why This Matters
비실시간 대량 처리 작업을 주말로 몰아 비용을 낮추는 운영 전략이 가능해지며, 모델 조달 시 시간대별 단가 구조가 비교 항목이 된다.
