# “AI 트레이딩 개발 쉬워진다”…키움증권, REST API 개발도구 공개

**Source**: 매일경제 증권 | **Published**: Tue, 21 Jul 2026 12:42:51 +09:00 | **Topics**: ai_agents, ai_industry, 금융회사 AI

## Summary
키움증권이 AI 기반 트레이딩 서비스 개발을 지원하기 위해 REST API 개발 환경을 대폭 개선했다. AI 에이전트·AX 전문기업 라이브데이터와 협력해 개발도구를 공개했다.

## Key Points
- REST API 개발 환경 전면 개선
- AI 에이전트 기업 라이브데이터와 협력
- 외부 개발자의 AI 트레이딩 서비스 구축 지원
- 증권사 플랫폼의 개방형 생태계 전략

## Why This Matters
증권사가 직접 AI 서비스를 만드는 대신 개발 인프라를 개방해 생태계를 확보하는 전략으로, 금융 플랫폼 경쟁 방식의 전환을 보여준다.
