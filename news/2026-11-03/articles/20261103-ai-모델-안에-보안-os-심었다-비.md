# AI 모델 안에 보안 OS 심었다…비드래프트, 정보 유출 차단 기술 개발

**Source**: ZDNet Korea | **Published**: Tue, 03 Nov 2026 14:49:51 +0900 | **Topics**: ai_agents, ai_policy

## Summary
비드래프트가 AI 모델 가중치 안에서 작동하는 보안 운영체제 '바이커널'을 개발해 공개 시연을 시작했다. 승인되지 않은 외부 전송을 차단하고 이상 행동 감지와 실행 기록 관리를 모델 내부에서 처리하도록 설계했다고 밝혔다.

## Key Points
- 보안 기능을 모델 가중치와 결합했다
- 모델을 옮겨도 통제 장치가 유지된다고 설명한다
- 외부 전송 차단과 실행 기록 관리를 지원한다
- 성능은 회사 측 설명이며 시연 단계다

## Why This Matters
에이전트 통제가 외부 게이트웨이에 더해 모델 수준으로 확장될 수 있는지가 보안 설계의 쟁점이 된다.
