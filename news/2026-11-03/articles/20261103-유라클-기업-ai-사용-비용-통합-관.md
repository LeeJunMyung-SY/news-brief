# 유라클, 기업 AI 사용·비용 통합 관리…'오르다 API 게이트웨이' 출시

**Source**: ZDNet Korea | **Published**: Tue, 03 Nov 2026 11:12:35 +0900 | **Topics**: ai_agents, ai_industry

## Summary
유라클이 사내 AI 서비스, 외부 LLM, 자체 모델, 에이전트, MCP 서버를 한 접속 지점에서 관리하는 '오르다 API 게이트웨이'를 출시했다. 사용자별 권한과 비용, 실행 승인까지 통제하는 것이 핵심이다.

## Key Points
- 내외부 모델과 에이전트, MCP 서버를 단일 지점에 연결
- 사용자별 접근 권한과 이용 비용, 실행 승인 관리
- 모델 교체 시 수정 작업 축소
- 새 모델을 일부 요청에 먼저 적용해 성능 비교 가능

## Why This Matters
멀티모델과 에이전트가 늘면서 비용과 권한을 묶어 관리하는 운영 계층이 별도 구매 항목이 되고 있다.
