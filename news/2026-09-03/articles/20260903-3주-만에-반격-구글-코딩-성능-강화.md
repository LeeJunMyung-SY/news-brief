# "3주 만에 반격"...구글, 코딩 성능 강화한 '제미나이 3.8 플래시' 공개

**Source**: AI타임스 | **Published**: 2026-09-03 11:07:58 | **Topics**: llm_models, ai_agents, ai_industry

## Summary
구글이 출시 3주 만에 코딩·추론 성능을 끌어올린 '제미나이 3.8 플래시'와 사이버보안 특화 '제미나이 3.8 플래시 사이버'를 동시에 공개했다. 모델 규모 확대 대신 복잡한 문제에 연산을 더 투입해 스스로 추론하고 도구를 반복 호출하는 방식으로 성능을 높였다.

## Key Points
- 출시 3주 만의 성능 개선판으로 갱신 주기가 크게 짧아짐
- 규모 확장이 아닌 추론 시점 연산 투입으로 성능 확보
- 사이버보안 특화 파생 모델을 동시 출시
- 도구 반복 활용(에이전트형) 능력을 전면에 배치

## Why This Matters
모델 갱신이 수 주 단위로 짧아지면서 도입 기업은 특정 버전에 업무 프로세스를 고정하기 어려워졌다. 운영 중 모델 교체 정책과 회귀 테스트 체계를 미리 갖춰야 한다.
