# 오픈AI, 분류·선택 특화 ‘디시전스 API’ 정식 출시…최대 10배 빠르게

**Source**: AI타임스 | **Published**: 2026-10-23 18:59:59 | **Topics**: ai_agents, llm_models

## Summary
오픈AI가 입력 분류나 다음 행동 선택 같은 반복 판단을 빠르고 저렴하게 처리하는 디시전스 API를 모든 고객에게 정식 제공한다. 개발자가 정한 답변 범위 안에서 선택하거나 확률·점수를 반환하며, GPT-6 루나 기반으로 기존 리스폰스 API 대비 최대 10배 빠르다.

## Key Points
- 디시전스 API 정식 출시
- 정해진 선택지 내 분류·선택과 확률 반환에 특화
- 최대 10배 빠른 처리, 비용 절감 초점
- GPT-6 루나 기반
- 에이전트 라우팅·분류 업무에 적합

## Why This Matters
고빈도 판단 업무를 범용 모델이 아닌 전용 저비용 API로 분리할 수 있어, 금융 상담 분류·이상거래 1차 판정·에이전트 라우팅 같은 대량 업무의 운영 비용 설계가 달라진다.
