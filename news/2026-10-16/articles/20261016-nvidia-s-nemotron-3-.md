# Nvidia's Nemotron 3.5 Super VL is an open model built to run enterprise AI agents nonstop

**Source**: The Decoder | **Published**: Thu, 15 Oct 2026 16:09:44 +0000 | **Topics**: ai_industry, llm_models, ai_agents

## Summary
엔비디아가 엔터프라이즈 에이전트용 1200억 매개변수 오픈 멀티모달 모델 네모트론 3.5 슈퍼 VL과 로컬 구동용 소형 볼트 모델 2종을 공개했다. 이미 수십 개 조직이 파인튜닝 중이며, 성능을 끌어내려면 추론 설정 최적화가 필요하다.

## Key Points
- 1200억 매개변수 오픈 멀티모달 에이전트 모델
- 로컬 구동용 소형 볼트 모델 동반 공개
- 수십 조직이 파인튜닝 진행 중
- 상시 구동 에이전트 워크로드 겨냥

## Why This Matters
망분리 환경의 금융사가 외부 API 없이 자체 인프라에서 에이전트를 상시 운영할 오픈 모델 선택지가 넓어졌다.
