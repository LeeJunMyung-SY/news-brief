# 메타, ‘뮤즈 스파크 오픈’ 공개…맥 2대로 구동·미국 최고 성능 내세워

**Source**: AI타임스 | **Published**: 2026-10-16 06:17:00 | **Topics**: ai_industry, llm_models

## Summary
메타가 8160억 매개변수 오픈웨이트 멀티모달 모델 뮤즈 스파크 오픈의 가중치를 공개하고 외부 플랫폼 API 서비스를 시작했다. 애플과 협력해 맥 스튜디오 2대 연결 환경에서 구동되도록 최적화했으며, 복잡한 코딩과 다단계 작업을 개인 컴퓨터에서 수행하는 데 초점을 맞췄다.

## Key Points
- 8160억 매개변수, 100만 토큰 컨텍스트 오픈웨이트
- 애플 M5 울트라 맥 스튜디오 2대에서 로컬 구동
- '가장 뛰어난 미국 오픈웨이트 모델' 표방
- 다운로드·자체 환경 수정 허용, API도 병행

## Why This Matters
중국계 오픈 모델의 보안 우려가 커지는 시점에 미국산 고성능 오픈웨이트가 나와, 망분리 환경 자체 운영 모델의 선택 기준이 바뀐다.
