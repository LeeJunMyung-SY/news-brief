# Offering Zero Data Retention for frontier models

**Source**: OpenAI Blog | **Published**: Wed, 19 Aug 2026 19:00:00 GMT | **Topics**: llm_models, ai_policy, ai_industry, 금융회사 AI

## Summary
오픈AI가 자격을 갖춘 API 고객에게 데이터를 저장하지 않는 제로 데이터 리텐션 정책을 재확인하고, 데이터 프라이버시를 훼손하지 않고 안전성 검사를 수행하는 '프라이빗 세이프티 프로세싱'을 예고했다. 프런티어 모델까지 적용 범위를 넓힌 것이 핵심이다.

## Key Points
- 자격 요건을 충족한 API 고객에게 프런티어 모델 대상 제로 데이터 리텐션 적용
- 안전성 모니터링과 데이터 프라이버시를 동시에 충족하는 프라이빗 세이프티 프로세싱 예고
- 규제 산업 고객의 데이터 잔존 우려를 계약 조건으로 해소하려는 접근

## Why This Matters
금융·의료 등 데이터 반출이 어려운 산업에서 외부 모델 도입의 최대 장애물이 데이터 잔존 문제였던 만큼, 조달 심사 통과 기준선이 바뀐다.
