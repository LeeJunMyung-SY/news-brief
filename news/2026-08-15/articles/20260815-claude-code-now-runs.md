# Claude Code now runs daily maintenance on Anthropic's software with a 46 percent merge rate

**Source**: The Decoder | **Published**: Fri, 14 Aug 2026 11:44:38 +0000 | **Topics**: ai_agents, ai_industry

## Summary
앤트로픽이 자사 앱의 일상 유지보수를 클로드 코드에 맡기는 실험을 진행했다. 몇 주 동안 388건의 풀리퀘스트가 생성됐고 사람 검토를 거쳐 46%가 병합됐다.

## Key Points
- 크래시 퍼징·데드코드 제거 등 유지보수 업무 자동화
- 수 주간 388건 PR 생성
- 인간 검토 후 병합률 46%
- 완전 자율이 아닌 검토 전제 운영

## Why This Matters
에이전트 성과를 '자동화율'이 아닌 '채택된 산출물 비율'로 측정하는 실무 지표를 제시해, 도입 KPI 설계에 참고가 된다.
