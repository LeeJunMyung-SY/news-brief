# Perplexity's new Monitor API turns web search from a one-off query into a nonstop watchdog

**Source**: The Decoder | **Published**: Sun, 22 Nov 2026 14:20:28 +0000 | **Topics**: ai_agents

## Summary
퍼플렉시티가 웹을 주기적으로 검색하다 관련 변화가 있을 때만 웹훅으로 에이전트에 알리는 Monitor API를 출시했다. 자체 판단 모델이 노이즈를 걸러 의미 있는 변화만 전달한다.

## Key Points
- 일회성 검색을 상시 감시형으로 전환
- 변화 감지 시 웹훅으로 에이전트 호출
- 자체 판단 모델로 무관한 변화 필터링

## Why This Matters
경쟁사·규제·시장 동향 모니터링을 에이전트가 이벤트 기반으로 수행할 수 있게 돼, 리서치 업무 자동화 설계 선택지가 넓어졌다.
