# '공구리' 통역하는 AI…외국인 근로자도 척척 알아듣는다

**Source**: ZDNet Korea | **Published**: Mon, 23 Nov 2026 14:02:22 +0900 | **Topics**: llm_models, ai_industry

## Summary
오픈AI 코리아의 '보이스 AI 기업 활용' 세션에서 하이로컬은 건설·조선 현장 작업 지시를 베트남어·네팔어 등으로 실시간 통역하는 서비스를 소개했다. 소음 환경 인식 정확도와 응답 속도 때문에 오픈AI 모델을 쓰지만 API 비용이 지출의 상당 부분을 차지한다고 밝혔다.

## Key Points
- 건설현장 다국어 실시간 통역
- 외국인 노동자 120만명 소통 수요
- 소음 환경 인식·응답 속도가 선택 이유
- API 비용이 주요 지출 항목

## Why This Matters
음성 AI가 산업안전 영역에서 상용화되고 있지만, 사용량 기반 API 비용이 사업성의 핵심 변수임을 보여준다.
