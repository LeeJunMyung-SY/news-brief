# 알리바바, 에이전트용 ‘큐원3.7-맥스’ 공개...“35시간 자율 작업 달성”

**Source**: AI타임스 | **Published**: 2026-05-20 19:15:47 | **Topics**: llm_models, ai_agents

## Summary
알리바바가 에이전트용 파운데이션 모델 '큐원3.7-맥스'를 공개했다. 코딩·디버깅·다중 파일 SW 엔지니어링·사무 자동화·MCP 워크플로우·수백~수천 단계 장기 자율 작업 수행을 표방하며 35시간 자율 작업 달성 사례를 강조했다.

## Key Points
- 큐원3.7-맥스 공개, 에이전트용 파운데이션 모델
- MCP 기반 워크플로우, 다중 파일 SW 엔지니어링 지원
- 35시간 장기 자율 작업 수행 사례 제시

## Why This Matters
중국 진영 모델이 단순 가성비를 넘어 '에이전트 전용 파운데이션 모델' 카테고리로 전환하고 있다는 명확한 신호.
