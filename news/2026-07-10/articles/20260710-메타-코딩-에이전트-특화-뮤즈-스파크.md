# 메타, 코딩·에이전트 특화 ‘뮤즈 스파크 1.1’ 출시…API 공개로 유료화 시동

**Source**: AI타임스 | **Published**: 2026-07-10 13:51:39 | **Topics**: llm_models, ai_agents, ai_industry

## Summary
메타가 코딩·업무 자동화에 특화된 차세대 멀티모달 추론 모델 '뮤즈 스파크(Muse Spark) 1.1'을 공개하고 개발자용 API를 처음 개방했다. 텍스트·이미지·영상을 이해하며 코딩, 컴퓨터 사용, 도구 활용, 장시간 프로젝트 수행 능력이 대폭 향상됐다.

## Key Points
- 메타 슈퍼인텔리전스 랩스(MSL) 개발 '뮤즈 스파크 1.1' 발표
- 텍스트·이미지·영상 이해 멀티모달 추론 모델
- 코딩·컴퓨터 사용·외부 도구 활용·장기 프로젝트 수행 능력 강화
- 개발자용 API 첫 개방으로 생성 AI 수익화 착수

## Why This Matters
메타가 오픈웨이트 전략에서 API 유료화로 전환하며 오픈AI·앤트로픽과 에이전트·코딩 모델 시장에서 직접 경쟁에 나선 신호다.
