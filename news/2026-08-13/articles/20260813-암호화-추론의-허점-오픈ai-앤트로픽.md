# '암호화' 추론의 허점…오픈AI·앤트로픽·구글 API에서 숨은 사고 과정 추출

**Source**: ZDNet Korea | **Published**: Wed, 12 Aug 2026 20:32:52 +0900 | **Topics**: llm_models, ai_agents, ai_industry, ai_policy, 금융회사 AI

## Summary
프런티어 모델의 암호화된 내부 사고 과정을 평문으로 추출하는 공격이 논문으로 공개됐다. 암호화 블록이 같은 제공자의 다른 세션·사용자·모델 간에 호환된다는 점을 이용해, 강한 모델이 만든 블록을 안전장치가 느슨한 모델에 주입하면 내용이 그대로 노출된다.

## Key Points
- 오픈AI·앤트로픽·구글 API 모두 영향
- 세션·사용자 간 암호화 블록 호환성이 취약점
- 약한 모델에 주입해 평문 복원

## Why This Matters
모델에 넘긴 내부 판단 근거가 외부에서 복원될 수 있어, 민감 업무의 상용 API 사용 범위와 로그 취급 기준을 다시 정해야 한다.
