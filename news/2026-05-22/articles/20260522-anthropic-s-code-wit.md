# Anthropic’s Code with Claude showed off coding’s future—whether you like it or not

**Source**: MIT Technology Review | **Published**: Thu, 21 May 2026 14:30:45 +0000 | **Topics**: ai_agents, ai_industry

## Summary
Anthropic의 'Code with Claude' 개발자 이벤트가 런던에서 5월 19일 개막했다. AI가 PR을 완전 작성하는 시연이 핵심이었으며, '좋든 싫든 코딩의 미래'라는 평가가 이어졌다. 같은 날 구글 I/O와 정면 충돌하는 일정이었다.

## Key Points
- Anthropic 첫 대규모 개발자 컨퍼런스 'Code with Claude' 런던 개막
- AI가 PR 완전 작성 시연이 핵심
- '좋든 싫든 코딩의 미래' 평가
- 구글 I/O와 같은 날 충돌 일정
- 자율 코딩 에이전트 시장 본격 경쟁 신호

## Why This Matters
Claude Code가 Anthropic 흑자 전환의 핵심 매출 동력으로 부상한 사례 위에서 진행된 이벤트. 자율 코딩 도구의 기업 채택 가속화는 한국 개발 조직의 생산성·인력 구조에도 직접 영향.
