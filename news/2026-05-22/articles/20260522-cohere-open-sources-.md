# Cohere open-sources its strongest model yet

**Source**: The Decoder | **Published**: Thu, 21 May 2026 15:17:35 +0000 | **Topics**: llm_models, ai_industry

## Summary
Cohere가 자사 최강 언어 모델 'Command A+'를 Apache 2.0 라이선스로 오픈소스 공개했다. 상업적 활용이 허용되는 관대한 라이선스를 채택하며 기업용 AI 시장에서 자체 모델 호스팅 수요에 직접 대응하는 행보다.

## Key Points
- Cohere 최강 언어 모델 Command A+ Apache 2.0 오픈소스 공개
- 상업적 사용·재배포 모두 허용되는 관대한 라이선스
- Meta Llama, Mistral 등에 이은 주요 연구소의 가중치 공개 행렬
- 기업용 AI 시장에서 자체 호스팅 수요에 직접 대응
- 오픈소스 프론티어급 모델 라인업이 다시 확장

## Why This Matters
주요 AI 연구소의 최강 모델 오픈소스화는 폐쇄형 API 의존도가 높은 기업 고객에게 실질적 선택지를 추가한다. 한국 기업도 자체 호스팅 옵션이 한층 넓어진다.
