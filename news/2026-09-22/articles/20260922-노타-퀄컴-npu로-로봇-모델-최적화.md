# 노타, 퀄컴 NPU로 로봇 모델 최적화 성공..."로봇팔 작업 속도 3배 향상"

**Source**: AI타임스 | **Published**: 2026-09-22 15:56:40 | **Topics**: physical_ai, physical_ai_robotics, ai_compute_energy

## Summary
노타가 퀄컴 산업용 SoC의 NPU에 비전언어행동모델(VLA)을 최적화해 로봇팔 작업 속도를 3배 높였다. 경량화부터 멀티 NPU 런타임 구축까지 전 과정을 최적화해 외부 서버 없이 로봇 내부에서 모델이 실행된다.

## Key Points
- 퀄컴 '드래곤윙 IQ-9075' NPU에 VLA 최적화 적용
- GPU·외부 서버 의존 없이 로봇 내부 실행 구현
- 언어 명령 기반 집기·이동 작업에서 속도 3배 향상
- 연산 그래프 최적화·행동 생성 가속 등 전 단계 튜닝

## Why This Matters
로봇 AI의 병목이 모델 성능에서 현장 연산 비용으로 옮겨간 상황에서, 온디바이스 실행은 도입 단가와 통신 의존도를 동시에 낮추는 수단이 된다.
