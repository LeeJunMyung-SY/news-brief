# 딥엑스, AWS 클라우드 연동으로 '피지컬 AI' 글로벌 시장 공략

**Source**: 블로터 | **Published**: 2026-09-01 16:26:44 | **Topics**: ai_industry, ai_compute_energy, physical_ai

## Summary
딥엑스가 AWS의 클라우드·IoT 인프라와 자사 NPU 'DX-M1'을 연동해 피지컬 AI 배포 환경을 구현했다. 클라우드에서 만든 모델을 현장 엣지 장비로 전송·관리하는 체계를 갖췄다.

## Key Points
- DX-M1과 AWS IoT Core·Greengrass 연동 구조 공개
- 클라우드에서 엣지 장비로 모델 배포·관리 자동화
- AWS 마켓플레이스를 통한 글로벌 유통 경로 확보

## Why This Matters
엣지 AI의 병목은 칩 성능이 아니라 현장 배포·업데이트 체계다. 이 부분이 표준 클라우드 도구로 해결되면 현장 확산 속도가 달라진다.
