# AnalysisBank: An Expert Analysis Pattern Library for Financial Report Generation

**Source**: arXiv CS.AI | **Published**: Wed, 02 Sep 2026 00:00:00 -0400 | **Topics**: llm_models, 금융회사 AI

## Summary
금융 리포트 생성이 목차·섹션 같은 구조 수준이 아니라 데이터에서 도출된 분석 단위로 구성돼야 한다는 주장 아래, 전문가 리포트를 재사용 가능한 분석 패턴 라이브러리로 정제한 AnalysisBank를 제안한다.

## Key Points
- 전문가 리포트를 분석 패턴 단위로 분해·라이브러리화
- 각 패턴은 데이터 신호·분석 동작·원문 근거를 함께 보관
- 추론 시 입력 신호에 맞는 분석 패턴을 매칭
- 구조 중심이 아닌 분석 중심 생성 방식

## Why This Matters
리포트 자동화의 한계가 문장 생성이 아니라 '어떤 분석을 할지' 결정에 있음을 보여준다. 사내 리서치 자산을 패턴으로 정리하는 작업이 선행 투자 항목이 된다.
