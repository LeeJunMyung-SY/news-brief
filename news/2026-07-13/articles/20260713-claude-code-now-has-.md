# Claude Code now has a built-in browser that lets the AI read, click, and type on external websites

**Source**: The Decoder | **Published**: Sun, 12 Jul 2026 15:02:06 +0000 | **Topics**: ai_agents

## Summary
Claude Code에 개발 환경 내에서 AI가 웹페이지를 열고 읽고 상호작용할 수 있는 내장 브라우저가 추가됐다. 외부 사이트에 대한 쓰기 동작은 분류기로 선별되며, 구매·계정 생성은 사용자 승인이 필요하다.

## Key Points
- Claude Code 내장 브라우저로 AI가 웹 읽기·클릭·입력 수행
- 쓰기 동작은 분류기로 사전 선별
- 구매·계정 생성은 사용자 승인 필수

## Why This Matters
코딩 에이전트의 작업 범위가 로컬 환경을 넘어 실제 웹 조작으로 확장되며, 안전장치 설계도 함께 제시됐다.
