# A single prompt was enough to hijack every AI agent in an AWS account, Zenity researchers found

**Source**: The Decoder | **Published**: Thu, 08 Oct 2026 13:01:01 +0000 | **Topics**: ai_agents

## Summary
Zenity Labs는 Amazon Bedrock AgentCore에서 공개 접근 가능한 에이전트 하나로 같은 계정·리전의 모든 AgentCore 에이전트를 장악할 수 있었다고 밝혔다. 임시 자격증명을 다루는 내부 AWS 인터페이스가 악용됐다.

## Key Points
- 공개 에이전트 1개로 계정 내 전체 에이전트 탈취
- 임시 자격증명 내부 인터페이스 악용
- 에이전트 간 권한 격리 부재가 원인

## Why This Matters
에이전트를 여러 개 운영하는 기업은 에이전트별 권한 격리와 외부 노출 에이전트 분리를 기본 통제로 설계해야 한다.
