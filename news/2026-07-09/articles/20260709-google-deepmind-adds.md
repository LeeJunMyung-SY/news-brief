# Google Deepmind adds background execution and MCP support to Gemini API managed agents

**Source**: The Decoder | **Published**: Wed, 08 Jul 2026 14:45:35 +0000 | **Topics**: ai_agents

## Summary
구글 딥마인드가 Gemini API의 관리형 에이전트에 네 가지 기능을 추가했다. 에이전트가 백그라운드에서 비동기 실행되고, 원격 MCP 서버에 직접 연결하며, 샌드박스 도구와 커스텀 함수를 함께 쓰고, 자격 증명을 갱신할 수 있다.

## Key Points
- 에이전트 백그라운드 비동기 실행 지원
- 원격 MCP 서버 직접 연결
- 커스텀 함수+샌드박스 도구 병행
- 자격 증명 자동 갱신

## Why This Matters
MCP 표준 채택과 장시간 실행 에이전트 지원은 실전 에이전트 배포의 핵심 요건이다.
