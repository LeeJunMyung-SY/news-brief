# 쿠콘, AI 에이전트용 MCP 상품관 오픈…기업 AX 지원 강화

**Source**: ZDNet Korea | **Published**: Mon, 20 Jul 2026 14:10:48 +0900 | **Topics**: ai_agents, ai_industry, 금융회사 AI

## Summary
쿠콘이 데이터 플랫폼 '쿠콘닷넷'에 MCP 전용 상품관을 열고 AI 에이전트가 즉시 활용할 수 있는 MCP 상품 30종을 공개했다. 클로드 데스크톱, 커서, VS Code 등 MCP 호환 환경에서 별도 API 연동 없이 금융·기업 실무 데이터를 자연어로 호출할 수 있다.

## Key Points
- 쿠콘, 쿠콘닷넷에 AI MCP 전용 상품관 오픈 및 MCP 상품 30종 공개
- MCP는 AI 에이전트가 외부 데이터·시스템을 조회하는 표준 통신 규격
- 기존 API 직접 연동 대신 자연어 명령으로 데이터 호출 가능
- 클로드 데스크톱·커서·VS Code 등 MCP 호환 환경 지원

## Why This Matters
MCP가 개발자 실험 단계를 넘어 금융 데이터 유통 사업자의 정식 상품 라인으로 편입됐다는 신호로, 국내 에이전트 도입의 데이터 접근 병목을 낮출 수 있다.
