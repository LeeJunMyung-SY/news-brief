# 코그니션, 코딩 모델 'SWE-2.1' 출시…장기 작업·사이버 보안 성능 강화

**Source**: AI타임스 | **Published**: 2026-11-26 16:39:42 | **Topics**: llm_models, ai_agents

## Summary
데빈 개발사 코그니션이 문샷 AI의 키미 K3에 강화학습만 적용한 코딩 모델 SWE-2.1을 공개했다. 장시간 자율 작업과 사이버 보안 성능을 크게 높였고, 보안 특화 모델과 추론 속도 10배 모델도 함께 선보였다.

## Key Points
- 키미 K3 기반 강화학습 코딩 모델 SWE-2.1 출시
- 프론티어코드 2.0 점수 전작 24.1%에서 대폭 상승
- 보안 특화·10배 고속 모델 동시 출시

## Why This Matters
오픈웨이트 베이스에 도메인 강화학습을 얹는 방식이 상용 경쟁력을 입증해, 기업의 특화 모델 구축 전략 선택지를 넓힌다. 다만 중국 베이스 모델의 공급 지연 리스크도 함께 고려해야 한다.
