# 미스트랄, 수학 증명·코드 검증 특화 ‘린스트랄 1.5’ 전격 공개…“퍼트넘벤치서 역대 최고 성적”

**Source**: AI타임스 | **Published**: 2026-07-04 17:22:39 | **Topics**: llm_models

## Summary
미스트랄 AI가 수학 증명과 코드 검증에 특화된 오픈소스 모델 린스트랄 1.5를 공개했다. 미스트랄 스몰 4 기반으로 Lean 4에 최적화된 코드 에이전트이며, 퍼트넘벤치에서 역대 최고 성적을 기록하고 57개 저장소에서 미발견 버그 5건을 찾아냈다.

## Key Points
- Lean 4 기반 정형 검증 특화 오픈소스 모델
- 퍼트넘벤치 역대 최고 성적 달성
- 실제 오픈소스 저장소에서 미발견 버그 5건 발견
- 미스트랄 스몰 4 계열 기반 코드 에이전트

## Why This Matters
정형 검증과 코드 안전성 분야에서 오픈소스 모델의 실용적 도약을 보여주는 사례다.
