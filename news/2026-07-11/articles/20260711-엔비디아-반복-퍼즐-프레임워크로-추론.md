# 엔비디아, '반복 퍼즐' 프레임워크로 추론 효율 극대화…"거대 모델 운영 비용 절반으로"

**Source**: AI타임스 | **Published**: 2026-07-11 11:36:34 | **Topics**: llm_models, ai_compute_energy

## Summary
엔비디아가 하이브리드 맘바-트랜스포머 모델을 성능 저하 없이 압축·최적화하는 '반복 퍼즐' 프레임워크를 공개했다. 1207억 매개변수 '네모트론-3-슈퍼'를 750억 규모로 압축해 서버 처리량을 최대 4.6배 높이고, 고성능 GPU 한 장으로 초장문맥 요청을 동시 처리할 수 있게 했다.

## Key Points
- 맘바-트랜스포머 하이브리드 모델을 성능 유지하며 압축
- 1207억 → 750억 매개변수로 최적화(Nemotron-Labs-3-Puzzle-75B-A9B)
- 서버 처리량 최대 4.6배 향상
- 초장문맥 요청을 단일 고성능 GPU로 동시 처리
- LLM 배포·추론 인프라 비용 절감 목표

## Why This Matters
대형 모델 추론 효율을 크게 끌어올려 상용 배포의 경제성을 개선하는 인프라 기술이다.
