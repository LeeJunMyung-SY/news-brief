# Grok Build coding agent leaks oodles of confidential info, some belonging to SpaceXSI

**Source**: Ars Technica Tech | **Published**: Tue, 10 Nov 2026 21:12:59 +0000 | **Topics**: ai_agents

## Summary
한 연구자가 Grok Build 코딩 에이전트로 만든 앱 3만5000개가 누구나 접근 가능하게 열려 있는 것을 발견했다. 일부는 SpaceXSI 소유의 기밀 정보도 포함했다.

## Key Points
- Grok Build 앱 3만5000개 공개 노출
- SpaceXSI 기밀 정보 포함
- 에이전트 생성 앱의 기본 보안 설정 문제

## Why This Matters
현업이 코딩 에이전트로 앱을 직접 만드는 흐름에서, 배포 전 접근권한·노출 점검을 자동화하지 않으면 정보유출 경로가 된다.
