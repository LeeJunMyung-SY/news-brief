# 알리바바, '행동' 대신 '환경' 예측하는 '큐원-에이전트월드' 공개…"학습 없이도 에이전트 성능 향상"

**Source**: AI타임스 | **Published**: 2026-06-25 13:34:20 | **Topics**: llm_models, ai_agents

## Summary
알리바바가 에이전트 환경 시뮬레이션에 특화된 언어 월드 모델 'Qwen-AgentWorld-35B-A3B'와 '397B-A17B'를 공개했다. 행동 대신 환경 자체를 예측해 별도 에이전트 전용 학습 없이도 성능을 높일 수 있다고 주장한다.

## Key Points
- MoE 기반 언어 월드 모델 2종 공개
- '무엇을 할까'가 아닌 '환경이 어떻게 변할까'를 예측
- 에이전트 전용 추가 학습 없이 성능 향상 주장

## Why This Matters
월드 모델 기반 에이전트 학습은 데이터·학습 비용을 줄일 수 있는 유망 방향으로, 에이전트 패러다임 경쟁의 한 축이다.
