# OpenAI launches Decisions API that reduces complex evaluations to yes, no, or pick one

**Source**: The Decoder | **Published**: Wed, 07 Oct 2026 15:36:39 +0000 | **Topics**: llm_models, ai_industry

## Summary
OpenAI가 텍스트·이미지를 예/아니오 확률, 범주 선택, 척도 점수로 판정하는 Decisions API를 출시했다. Responses API보다 약 10배 빠르고 입력 100만 토큰당 0.1달러이며, 유료 API 등급도 5단계에서 축소했다.

## Key Points
- 판정·분류 전용 API
- Responses API 대비 약 10배 속도
- 입력 100만 토큰당 0.1달러
- 유료 API 등급 체계 축소

## Why This Matters
심사·분류·모니터링처럼 판정형 업무를 저비용으로 대량 자동화할 수 있어, 금융권 이상거래·민원 분류 같은 활용 단가가 낮아진다.
