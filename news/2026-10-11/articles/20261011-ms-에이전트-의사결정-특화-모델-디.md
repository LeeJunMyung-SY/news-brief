# MS, 에이전트 의사결정 특화 모델 ‘디시전-1’ 공개…오픈AI도 API 정식 출시

**Source**: AI타임스 | **Published**: 2026-10-10 18:53:43 | **Topics**: llm_models, ai_agents

## Summary
마이크로소프트가 구조화된 의사결정 작업에 특화한 'Microsoft-Decision-1'을 공개했다. 큐원3.5-9B 기반 초기 버전은 모델 선택, 요청 분류, 작업 우선순위 지정, 결과 검증, 에이전트 제어 등에서 기존 LLM보다 빠르고 효율적으로 동작하며, 향후 MAI와 오픈AI 모델 기반으로 확장된다. 오픈AI도 Decisions API를 정식 출시했다.

## Key Points
- 에이전트 워크플로의 '판단 단계'를 전담하는 소형 저지연 모델 상용화
- 모델 선택·분류·우선순위·검증·제어 작업에서 대형 LLM 대체
- 큐원 기반 출발, MAI·오픈AI 모델 기반으로 확장 예정
- 오픈AI Decisions API 정식 출시로 '의사결정 모델' 카테고리 형성

## Why This Matters
에이전트 운영 비용의 상당 부분이 라우팅·검증 같은 반복 판단에서 발생하는 만큼, 이를 소형 전용 모델로 분리하는 아키텍처가 공급사 표준이 되면 기업의 에이전트 총비용 관리와 다중 모델 운영 설계가 달라진다.
