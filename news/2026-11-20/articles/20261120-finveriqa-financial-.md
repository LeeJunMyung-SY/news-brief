# FinVeriQA: Financial Research Agents for Question Answering: Routing, Retrieval, MCP Tool Use, and Provenance-Aware Evidence Verification

**Source**: arXiv CS.AI | **Published**: Fri, 20 Nov 2026 00:00:00 -0500 | **Topics**: 금융회사 AI, ai_agents

## Summary
LLM이 재무 비율을 잘못 계산하고 오래된 가격을 인용하며 질문을 엉뚱한 도구로 보내는 문제를 다룬 금융 리서치 에이전트 연구다. SEC 공시와 실시간 시장 데이터를 대상으로 한 오픈소스 다중 에이전트 프로토타입 FinVeriQA에서, 소형 결정 모델이 질문을 라우팅하고 투자 조언 요청을 걸러내는 구조를 검토한다.

## Key Points
- 금융 분석에서 계산 오류·시점 오류·도구 오선택 문제 제기
- SEC 공시와 실시간 시장 데이터 기반 다중 에이전트 프로토타입
- 소형 결정 모델이 라우팅과 조언 요청 선별 담당
- MCP 도구 사용과 출처 인지형 근거 검증 포함

## Why This Matters
금융 리서치 자동화의 실패 지점이 생성이 아니라 라우팅과 근거 검증에 있음을 보여줘, 증권·운용사가 리서치 에이전트를 설계할 때 역할 분리와 검증 계층을 우선 고려할 근거가 된다.
