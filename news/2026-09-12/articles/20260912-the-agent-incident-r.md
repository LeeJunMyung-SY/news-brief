# The Agent Incident Registry: Toward Preventing Repeated AI Agent Failures

**Source**: arXiv CS.AI | **Published**: Sat, 12 Sep 2026 00:00:00 -0400 | **Topics**: ai_agents, ai_policy

## Summary
도구 사용과 권한 위임 과정에서 발생한 에이전트 관련 사고를 출처 링크와 함께 정리한 사고 레지스트리(AIR)를 공개했다. 각 기록에 증거와 고정 식별자, 결측을 고려한 라벨을 붙여 보안 평가 결과와 실제 사고를 대조할 수 있게 했다.

## Key Points
- 공개된 에이전트 사고를 출처 연결 방식으로 목록화
- 기존 사고 저장소가 담지 못한 사고 발생 메커니즘을 기록
- 에이전트 보안 평가와 실제 사고의 대조 가능
- 결측 정보를 명시하는 라벨 체계 적용

## Why This Matters
에이전트 도입 승인 절차에서 '어떤 사고가 실제로 일어났는가'를 근거로 통제 항목을 정할 수 있다. 내부 사고 기록 체계를 설계할 때 분류 틀로 활용할 여지가 있다.
