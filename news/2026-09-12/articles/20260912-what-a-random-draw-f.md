# What a Random Draw from the MCP Registry Contains, and What Tool-Use Benchmarks Contain Instead

**Source**: arXiv CS.AI | **Published**: Sat, 12 Sep 2026 00:00:00 -0400 | **Topics**: ai_agents, ai_industry

## Summary
2만4135개 MCP 서버 명부에서 무작위 표본 400개를 추출해 직접 연결한 결과, 정상적으로 핸드셰이크를 마친 서버는 48.8%에 그쳤다. 기존 연구가 인기 목록이나 수작업 큐레이션 표본을 써서 '동작하는 서버'만 골라 왔다는 점을 지적한다.

## Key Points
- 무작위 표본 400개 중 절반 이하만 실제 연결 성공
- 기존 MCP 생태계 연구는 표본 선택 단계에서 이미 편향
- 도구 사용 벤치마크가 담는 서버 구성과 실제 레지스트리 구성이 상이
- 공개 시드로 재현 가능한 센서스 방식 제시

## Why This Matters
MCP 연동을 전제로 한 에이전트 로드맵은 외부 서버 가용성 가정에서부터 검증이 필요하다. 사내 도입 시 외부 커넥터는 개수가 아니라 실제 가동률과 유지보수 주체를 기준으로 선별해야 한다.
