# Grounding Agent Memory: Environment-Probing Curation for Enterprise Agents

**Source**: arXiv CS.AI | **Published**: Sat, 12 Sep 2026 00:00:00 -0400 | **Topics**: ai_agents

## Summary
세션을 넘어 경험을 축적하는 지속 메모리가 상용 에이전트 플랫폼에 도입되고 있으나, 완료된 작업 기록만 보는 큐레이터는 오류를 보존하거나 낡은 지식을 남긴다는 문제를 제기한다. 읽기 전용 최소권한 도구로 실제 환경을 확인해 메모리를 정제하는 방식을 제안한다.

## Key Points
- 완료 기록 기반 메모리 정제는 오류·과일반화를 그대로 남김
- 읽기 전용 최소권한 도구로 환경을 직접 확인하는 정제 방식
- 기존 비동기 큐레이터 구조에 호환되는 확장
- 장기 운영 에이전트의 지식 신선도 관리 문제 부각

## Why This Matters
에이전트를 오래 굴릴수록 성능이 좋아진다는 전제는 메모리 정제 체계가 있을 때만 성립한다. 사내 배치 시 메모리 검증 주체와 권한 범위를 함께 정해야 한다.
