# OpenAI's new Agents API gives developers the infrastructure behind Codex and ChatGPT

**Source**: The Decoder | **Published**: Fri, 11 Sep 2026 08:11:46 +0000 | **Topics**: ai_agents, llm_models, ai_industry

## Summary
오픈AI가 코덱스와 챗GPT를 돌리는 내부 인프라를 '에이전트 API'로 공개 베타 출시했다. 개발자는 수 시간 단위로 자율 실행되며 코드를 실행하고 하위 에이전트에 작업을 넘기는 클라우드 에이전트를 만들 수 있다. 토큰 사용량 외 별도 요금이 없고 클라우드플레어·버셀·오라클이 호스팅을 지원한다.

## Key Points
- 코덱스·챗GPT 운영에 쓰인 자체 에이전트 실행 인프라를 외부 개발자에게 개방
- 수 시간 연속 자율 실행, 코드 실행, 하위 에이전트 위임을 기본 제공
- 토큰 사용량 외 추가 과금 없음 — 에이전트 운영 원가 구조가 단순해짐
- 클라우드플레어·버셀·오라클이 실행 환경 제공

## Why This Matters
에이전트 오케스트레이션을 자체 구축하던 기업은 직접 개발 대신 플랫폼 채택을 재검토해야 한다. 동시에 장시간 자율 실행은 권한·감사 설계를 도입 조건으로 끌어올린다.
