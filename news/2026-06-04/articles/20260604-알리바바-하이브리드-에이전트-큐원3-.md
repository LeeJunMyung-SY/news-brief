# 알리바바, 하이브리드 에이전트 ‘큐원3.7-플러스’ 공개…“스스로 오류 수정하며 11시간 앱 개발”

**Source**: AI타임스 | **Published**: 2026-06-03 18:32:02 | **Topics**: llm_models, ai_agents

## Summary
알리바바가 멀티모달 LLM '큐원3.7-플러스'를 공개하고 모델 스튜디오로 API 서비스를 시작했다. 텍스트 전용이던 기존 플래그십과 달리 이미지·동영상까지 이해하며, 장기 추론을 강화해 스스로 오류를 수정하며 11시간 앱 개발을 수행한다고 강조했다. 비용은 큐원3.7-맥스 대비 최대 60% 낮다.

## Key Points
- 멀티모달 하이브리드 추론 모델
- 이미지·동영상 이해 지원
- 11시간 자율 앱 개발 시연
- 최대 60% 비용 절감
- 모델 스튜디오 API 제공

## Why This Matters
중국 빅테크가 멀티모달과 장기 자율 에이전트 역량을 결합한 모델로 에이전트 시장 공략을 본격화하고 있다.
