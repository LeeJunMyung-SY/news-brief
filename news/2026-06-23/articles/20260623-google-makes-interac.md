# Google makes Interactions API the default interface for Gemini models and agents

**Source**: The Decoder | **Published**: Mon, 22 Jun 2026 18:11:34 +0000 | **Topics**: ai_agents, llm_models

## Summary
Google DeepMind가 Gemini 모델과 에이전트의 기본 인터페이스를 새로운 Interactions API로 전환했다. 기존 generateContent API를 대체하며, 역할 기반 구조 대신 타입이 지정된 단계(typed steps)를 사용하는 간소화된 스키마를 채택했다.

## Key Points
- Gemini 기본 인터페이스를 Interactions API로 교체
- generateContent API 대체
- 역할 기반 대신 타입 단계 기반 스키마

## Why This Matters
주요 LLM 플랫폼의 API 패러다임 변경은 에이전트 개발 방식 전반에 영향을 준다.
