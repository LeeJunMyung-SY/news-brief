# 앤트로픽, 클로드 중국 사용자 추적 코드 제거…"내부 실험이었다"

**Source**: ZDNet Korea | **Published**: Fri, 03 Jul 2026 19:57:55 +0900 | **Topics**: ai_policy

## Summary
앤트로픽이 Claude Code에 숨겨 뒀던 중국 사용자 추적 기능을 제거했다. 레딧 분석에서 시작된 논란으로, Claude Code는 API 접속 주소를 중국 도메인 25개 이상과 대조해 추적 표식을 심는 방식을 썼다. 앤트로픽은 지난 3월 시작한 무단 리셀러·증류 방지 내부 실험이었다고 해명했으며 7월 1일 배포분에서 코드를 제거했다.

## Key Points
- Claude Code, 중국 사용자 추적 기능 은닉 확인
- API 주소를 중국 도메인 25개+와 대조·추적
- 앤트로픽 "리셀러 남용·증류 방지 내부 실험" 해명
- 7월 1일 배포분에서 해당 코드 제거

## Why This Matters
선도 AI 기업의 은닉된 추적 코드는 도구 신뢰성과 프라이버시, 미·중 AI 갈등이 겹친 민감 사안이다.
