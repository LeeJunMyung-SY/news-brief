# "But marinade" and leaked passwords are what researchers found in ChatGPT's hidden reasoning

**Source**: The Decoder | **Published**: Tue, 11 Aug 2026 17:38:49 +0000 | **Topics**: llm_models, ai_agents, ai_industry, ai_policy, 금융회사 AI

## Summary
보안 연구진이 오픈AI·앤트로픽·구글 API에서 암호화된 추론 트레이스를 추출해 모델 간에 옮길 수 있는 취약점을 찾아냈다. 공개 세션을 훑자 수십 개의 비밀번호와 API 키가 그 안에서 발견됐다.

## Key Points
- 주요 3사 API 공통으로 추론 트레이스 추출 가능
- 추출된 트레이스에서 비밀번호·API 키 다수 확인
- 모델 간 트레이스 이전도 가능
- 숨겨진 추론이 실제로 무엇을 담는지 노출

## Why This Matters
'추론 과정은 감춰져 있으니 안전하다'는 전제가 깨졌다. 프롬프트에 자격증명이 흘러드는 개발 관행을 점검하고, 모델 API 이용 구간의 데이터 취급 정책을 다시 짜야 한다.
