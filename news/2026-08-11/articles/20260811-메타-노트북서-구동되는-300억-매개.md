# 메타, 노트북서 구동되는 300억 매개변수 오픈 모델 '뮤즈 글리머' 출시

**Source**: AI타임스 | **Published**: 2026-08-11 13:06:53 | **Topics**: llm_models, ai_agents, ai_industry, 금융회사 AI

## Summary
메타가 고성능 PC와 맥북에서 직접 구동되는 300억 매개변수 멀티모달 오픈 모델 '뮤즈 글리머'를 공개했다. 4비트 양자화와 예측 디코딩으로 메모리와 지연을 줄였고 가중치는 아파치 2.0으로 배포된다.

## Key Points
- 300억 매개변수 멀티모달 모델을 로컬 기기에서 구동
- 4비트 양자화·예측 디코딩으로 메모리·지연 최소화
- 아파치 2.0 라이선스로 상업적 활용 허용
- 클라우드 비의존 상시 가동 에이전트를 겨냥

## Why This Matters
데이터 반출이 어려운 금융·공공 조직이 외부 API 없이 에이전트를 운영할 수 있는 현실적 선택지가 생겼다. 추론 비용 구조 자체를 재검토할 계기다.
