# Nvidia's SoL-Pi system cuts coding agent token usage nearly in half by optimizing the harness

**Source**: The Decoder | **Published**: Sat, 26 Sep 2026 10:30:32 +0000 | **Topics**: ai_agents

## Summary
엔비디아의 SoL-Pi는 코딩 에이전트와 모델 사이 제어 계층(하네스)을 최적화해 성능 저하 없이 토큰 사용량을 최대 49% 줄였다. 에이전트 비용이 모델 단가뿐 아니라 하네스 설계에 크게 좌우됨을 보여준다.

## Key Points
- 코딩 에이전트 토큰 사용 최대 49% 절감
- 모델이 아닌 하네스 계층 최적화
- 성능 변화는 미미

## Why This Matters
사용량 과금 확산 속에서 에이전트 운영비는 하네스·라우팅 설계로 관리할 수 있어 내재화 역량의 가치가 커진다.
