# 앤트로픽, 클로드 플러그인 개발 포털 공개...제출·검토·분석 통합 지원

**Source**: AI타임스 | **Published**: 2026-09-27 15:14:31 | **Topics**: ai_agents, ai_industry, llm_models

## Summary
앤트로픽이 클로드용 플러그인을 개발자가 제출하고 안전성 검토 진행 상황과 피드백을 확인하며, 승인 후 사용량·검색 데이터를 한곳에서 관리하는 개발 포털을 공개했다. 플러그인은 MCP 커넥터 등으로 외부 앱·업무 도구·데이터와 클로드를 잇는다.

## Key Points
- 플러그인 제출·안전 검토·배포 통합 포털
- 승인 플러그인의 사용량·검색 데이터 분석 제공
- MCP 커넥터 기반 외부 도구 연결 수요 대응

## Why This Matters
모델사가 앱스토어형 검수·유통 채널을 갖추며 에이전트 경쟁이 모델 성능에서 생태계 장악으로 이동하고 있어, 기업은 자사 서비스의 플러그인 입점 전략을 검토할 시점이다.
