# 앤트로픽, 클로드 코드에 '코드 모드' 추가...여러 도구 호출 한 번에 처리

**Source**: AI타임스 | **Published**: 2026-11-19 14:26:34 | **Topics**: ai_agents

## Summary
앤트로픽이 클로드 코드에 여러 개발 도구를 자바스크립트로 연결해 한 번에 실행하는 '코드 모드'를 실험 기능으로 추가했다. 중간 결과를 코드 내부에서 관리해 모델 호출 횟수와 토큰 사용량을 줄인다.

## Key Points
- 클로드 코드 2.1.323부터 실험 기능 제공
- 도구를 순차 호출 대신 코드로 묶어 실행
- 모델 호출·토큰 사용량 절감
- 기본 비활성, 사용자 선택 적용

## Why This Matters
에이전트 비용이 토큰 단위로 과금되는 만큼, 도구 오케스트레이션 방식이 엔터프라이즈 에이전트 TCO의 핵심 변수가 되고 있다.
