# DSRV, 쿠콘과 AI 에이전트 결제 사업 추진

**Source**: ZDNet Korea | **Published**: Fri, 06 Nov 2026 10:53:08 +0900 | **Topics**: ai_agents, 금융회사 AI

## Summary
DSRV와 쿠콘이 온체인 금융 데이터 연계와 AI 에이전트 결제 협력을 위한 MOU를 체결했다. 쿠콘의 MCP 기반 데이터 API에 DSRV 지갑 기술과 온체인 결제 표준 x402를 결합해 스테이블코인 결제·정산용 API를 우선 검토한다.

## Key Points
- 온체인 금융 데이터·에이전트 결제 MOU
- MCP 기반 데이터 API와 x402 결제 표준 결합
- 지갑 잔액·입금 감지·거래 확정·정산 데이터 API
- 기업은 블록체인 구축 없이 기존 API 방식으로 이용

## Why This Matters
AI 에이전트가 직접 결제하는 시대를 겨냥해 금융 데이터 사업자가 결제 인프라 계층을 선점하려는 움직임이다.
