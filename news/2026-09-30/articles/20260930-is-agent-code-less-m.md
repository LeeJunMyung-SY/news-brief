# Is Agent Code Less Maintainable Than Human Code?

**Source**: arXiv CS.AI | **Published**: Wed, 30 Sep 2026 00:00:00 -0400 | **Topics**: ai_agents, ai_industry, ai_workforce_training

## Summary
코딩 에이전트가 단일 이슈 해결에서는 좋은 성과를 내지만 그 코드 위에 후속 작업이 쌓일 때 유지보수성이 어떤지는 불확실하다는 문제를 다뤘다. 에이전트 코드와 사람 코드를 유지보수 상황에서 비교해 누적되는 하방 효과를 분석했다.

## Key Points
- 단일 이슈 성능과 유지보수성을 분리해 평가
- 후속 에이전트가 기존 에이전트 코드 위에 작업하는 상황을 설정
- 유지보수성 저하가 누적되는 효과를 검증
- 코드 리뷰·개발 프로세스 설계에 대한 함의 제시

## Why This Matters
코딩 에이전트의 생산성 이득이 기술부채로 상쇄될 수 있다는 점을 실증해, 도입 범위와 리뷰 게이트 설계를 구체화할 근거가 된다.
