# Critical Copilot vulnerability allowed hackers to steal 2FA code from users

**Source**: Ars Technica Tech | **Published**: Tue, 16 Jun 2026 11:15:46 +0000 | **Topics**: ai_policy

## Summary
마이크로소프트 코파일럿의 심각한 취약점 'SearchLeak'을 통해 공격자가 사용자의 2단계 인증(2FA) 코드를 탈취할 수 있었던 것으로 드러났다. 업계의 LLM 보안 접근이 반복적으로 실패하는 이유를 보여주는 사례다.

## Key Points
- 코파일럿 'SearchLeak' 취약점으로 2FA 코드 탈취 가능
- LLM 통합 제품의 구조적 보안 결함 노출
- 프롬프트 인젝션 계열 위험 재확인
- 업계 LLM 보안 모델의 한계 지적

## Why This Matters
LLM이 민감 데이터·인증에 접근하면서 새로운 공격면이 현실화되고 있음을 경고한다.
