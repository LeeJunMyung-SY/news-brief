# 앤트로픽 '페이블 5.2', AI 성능 평가 1위 탈환…API 가격도 20% 인하

**Source**: AI타임스 | **Published**: 2026-11-10 06:34:13 | **Topics**: llm_models, ai_agents, ai_industry

## Summary
앤트로픽이 클로드 페이블 5.2와 미소스 5.2를 출시했다. 페이블 5.2는 아티피셜 애널리시스 지능 지수에서 구글을 제치고 1위를 되찾았고, API 가격을 20% 인하해 기업용 시장에서 성능과 비용 경쟁력을 동시에 강화했다. 5.1 대비 코딩·추론·과학 연구·시각 처리가 개선되고 출력 속도는 최대 30% 빨라졌다.

## Key Points
- AAII 성능 평가 1위 탈환
- API 가격 20% 인하
- 코딩·추론·과학·비전 개선, 출력 속도 최대 30% 향상
- 미소스 5.2는 검증 기관 대상 제한 제공
- 로봇 제어·에이전트 협업 기능 강화
- IPO 앞두고 기업 시장 공세

## Why This Matters
최상위 모델의 가격 인하는 기존 계약 재협상과 모델 전환 검토의 직접적 근거가 된다. 성능 선두가 바뀌는 주기가 짧아 멀티벤더 전략과 평가 체계 상시화가 필요하다.
