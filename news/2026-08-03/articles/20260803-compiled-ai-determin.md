# Compiled AI: Deterministic Code Generation for LLM-Based Workflow Automation

**Source**: arXiv CS.AI | **Published**: Mon, 03 Aug 2026 00:00:00 -0400 | **Topics**: ai_agents, ai_industry, 금융회사 AI

## Summary
LLM이 컴파일 단계에서 실행 가능한 코드 산출물을 생성하고, 이후 워크플로는 모델 호출 없이 결정론적으로 실행되는 '컴파일드 AI' 패러다임을 연구한다. DSPy의 선언적 파이프라인 최적화와 LLM+P의 신경기호 계획을 선행 연구로 두고, 고위험 엔터프라이즈 워크플로 적용을 시스템 관점에서 분석한다.

## Key Points
- 컴파일 단계 후 모델 호출 없는 결정론적 실행
- 고위험 엔터프라이즈 워크플로 적용 시스템 연구
- DSPy·LLM+P 계보 위 시스템적 기여

## Why This Matters
매 실행마다 LLM을 호출하지 않아 비용·지연·비결정성을 동시에 없애는 구조로, 감사와 재현성이 필수인 금융권 워크플로 자동화에 특히 부합한다.
