# Physical Ai — 동향 요약

### 모델과 하드웨어의 자본 결합
선도 모델 기업이 휴머노이드 기업 지분을 취득하고 공동 개발에 나섰다. 승부처가 하드웨어 성능에서 파운데이션 모델 결합 속도로 옮겨갔다.

### 참여 기업군의 확장
게임사가 사회적 맥락을 이해하는 로봇 지능 개발에 뛰어들었다. 상호작용 데이터를 보유한 기업이 새 경쟁자로 등장했다.

### 도입 병목은 현장 데이터
대부분 공장이 설비 디지털 모델을 1%도 갖추지 못한 현실이 드러났다. 3D 스캔의 자동 CAD 변환처럼 데이터 병목을 푸는 기술이 확산 속도를 좌우한다.

### 검증 후 확대라는 국내 패턴
대형 유통사가 자동화 물류센터 1호기 성과에 후속 투자 규모를 연동했다. 물리 자동화는 단계적 조건부 투자가 표준이 됐다.
