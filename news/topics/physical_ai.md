# Physical Ai — 동향 요약

### 국방이 대규모 수요처로 확정됐다
전력화 조직 개편과 신속획득 제도로 소모성 무인기 대량 조달 경로가 열렸다. 민간 로봇·자율주행 밸류체인의 초기 매출 기반이 공공에서 나오는 구조다.

### 학습 데이터를 시뮬레이션이 대체한다
실물 작업 하나를 수천 개 변형으로 늘려 가상 환경만으로 제어기를 학습시키는 방식이 자리잡았다. 현장 데이터 수집 비용이 도입의 결정 변수에서 내려온다.

### 검증도 실물 이전으로 옮겨간다
설계 변경의 생산·성능 영향까지 가상에서 확인하는 방식이 개발 인프라의 기본이 됐다.

### 성과 지표는 개발 속도
비용 절감을 넘어 리드타임이 평가 기준으로 올라섰다.
