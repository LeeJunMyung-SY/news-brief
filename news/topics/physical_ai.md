# Physical Ai — 동향 요약

### 생산 자원의 재배분
완성차가 부진 차종의 생산 공간을 로보택시로 돌리며, 피지컬 AI가 실제 설비 투자 우선순위를 바꾸기 시작했다.

### 도입 실행의 서비스화
컨설팅이 업무 선정·ROI 진단부터 현장 가동까지 맡으며, 로봇 도입 병목이 실행 역량임이 드러났다.

### 현장 보안이라는 새 과제
센서 왜곡 공격이 경고되며, 로봇·자율주행 도입에 IT와 현장 안전을 잇는 보안 체계가 요구된다.

### 데이터 주권과 M&A
공장 로봇 데이터가 안보 자산으로 다뤄지며, 현장 데이터 확보 경로가 경쟁의 지정학 변수가 됐다.
