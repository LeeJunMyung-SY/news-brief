# AI Agents and Autonomous Systems — 동향 요약

### 도구 계층이 모델사로 통합된다
코딩 에이전트 기업이 모델 공급사에 인수되며 개발 도구가 모델 계약에 묶이는 구조가 만들어진다. 벤더 종속의 범위를 다시 그려야 한다.

### 병목은 모델이 아니라 데이터
성능을 가르는 제약이 모델 선택이 아니라 학습·운영에 쓸 내부 업무 데이터 확보로 옮겨갔다. 도입 로드맵의 선행 과제는 데이터 정비다.

### 사내 배포는 소스 통합이 관건
대형 제약사가 문헌·임상·내부 실험 데이터를 한 창구로 묶은 사내 에이전트를 운영 중이라고 공개했다. 성패는 모델이 아니라 데이터 연결에서 갈린다.

### 멈추는 능력이 평가 항목으로
되돌릴 수 없는 행동 직전에 사람에게 넘기는 판단을 따로 재는 시도가 나왔다. 잘하는가보다 언제 멈추는가가 도입 심사 기준이 된다.
