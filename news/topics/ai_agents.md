# AI Agents and Autonomous Systems — 동향 요약

### 업무 관찰이 자동화의 입력이 된다
데스크톱 작업 이력 자체를 수집해 자동화 후보를 제안하는 방식이 등장했다. 도입 검토의 첫 관문이 성능이 아니라 단말 로깅 통제로 바뀐다.

### 입력 문서가 공격면이다
외부 문서에 숨긴 지시문으로 자동 검토를 조작하려는 시도가 확인됐다. 심사·계약 자동화는 전처리 검증을 전제로 설계해야 한다.

### 병목은 모델이 아니라 데이터
성능을 가르는 제약이 모델 선택에서 내부 업무 기록 확보로 옮겨갔다.

### 보안 점검까지 맡기기 시작했다
오픈 모델이 상용 도구의 취약점을 찾아내며 적용 업무 범위가 넓어졌다.
