# AI Agents and Autonomous Systems — 동향 요약

### 단일 에이전트로의 회귀
모델이 복잡한 작업을 혼자 처리하게 되면서 공급사가 다수 서브에이전트를 단일 에이전트로 통합하라고 권고해, 멀티에이전트 설계의 운영 비용 재검토가 필요해졌다.

### 로컬 구동 에이전트의 현실화
수 GB 메모리에서 도는 경량 모델이 나와, 데이터 반출이 어려운 업무에서 기기 내 에이전트를 구축할 선택지가 생겼다.

### 결제 위임의 제도권 진입
국내 카드업계의 에이전트 결제 추진으로, 결제·업무 권한 위임의 인증·한도 설계가 여전히 핵심 과제다.

### 자율 실행과 거버넌스
자율 모드가 기본값이 되며 통제 책임이 공급사 판정으로 넘어가, 실행 격리·감사 기능이 인프라 선택 기준으로 자리 잡았다.
