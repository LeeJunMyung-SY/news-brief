# AI Agents and Autonomous Systems — 동향 요약

### 방어도 자동화로
공격 측이 에이전트를 쓰기 시작하자 취약점 탐지부터 패치·배포까지 전 과정을 자동화한 보안 체계가 나왔다. 사람 속도의 방어는 성립하지 않는다.

### 권한이 통제 대상으로
보안 업계의 사업 정의가 데이터 보호에서 실행 권한 통제로 이동한다. 에이전트를 업무에 붙이려면 권한 설계를 별도 항목으로 잡아야 한다.

### 근거를 재현하는 계층
결정 궤적을 기록해 같은 조건에서 다시 실행해보는 검증 구조가 연구되고 있다. 실행 권한을 주려면 사후 재현이 전제다.

### 병목은 실행 순서
지연의 상당 부분이 모델 추론이 아니라 순차적 행동-관찰 구간에서 발생한다. 체감 속도가 채택률을 가른다.
