# AI Agents and Autonomous Systems — 동향 요약

### 처리까지 맡는 단계로
상담·응대에 머물던 에이전트가 결제와 신고, 주문 완결까지 수행하며 처리 비중과 시간 단축이 정량 지표로 공개되기 시작했다. 도입 논거가 체험에서 회수 계산으로 넘어왔다.

### 문서와 마케팅으로 확산
문서 처리 전 과정을 맡는 에이전트가 구축형에서 구독형으로 내려오고, 마케팅에서는 판단과 집행까지 자율로 수행하는 제품이 등장했다. 부서 단위 도입 문턱이 낮아진다.

### 규제 산업이 다음 격전지
계약 검토와 규제 대응처럼 고비용 반복 업무가 몰린 영역에 빅테크가 동시에 진입했다. 승부처는 모델 성능이 아니라 기존 문서·시스템 연동 설계다.

### 권한 설계가 미해결 과제
기존 인증 체계는 작업 범위가 아닌 기능 단위 권한만 부여하고, 외부 도구 계층은 사후에 돌변할 수 있다. 실행 권한을 주려면 통제 지점을 새로 잡아야 한다.
