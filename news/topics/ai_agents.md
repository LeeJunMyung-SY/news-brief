# AI Agents and Autonomous Systems — 동향 요약

### 에이전트 공격의 자동화
전문 에이전트 분업으로 사람 개입 없이 공격하는 프레임워크가 확산돼, 방어 자동화와 실행 권한 통제가 도입 조건이 됐다.

### 검증이 새 병목
코드를 쓴 AI가 검토까지 맡는 조직이 절반에 달해, 작성과 검증 주체를 분리하는 거버넌스가 생산성 실현의 관건이다.

### 에이전트 접근의 유료화
플랫폼이 외부 에이전트의 데이터 접근에 과금하고 커머스 접근 협상이 이어져, 에이전트 원가가 플랫폼 협상력에 좌우된다.

### 금융 데이터 계층 형성
오픈뱅킹 데이터를 에이전트용 실시간 고객 뷰로 제공하는 제휴가 나와, 에이전트 금융의 데이터 인프라가 갖춰지고 있다.
