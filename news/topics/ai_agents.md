# AI Agents and Autonomous Systems — 동향 요약

### 실전 성능의 현실 점검
실사용 평가에서 최상위 에이전트도 완결률이 낮아, 도입 계획에 사람의 검수 공수를 전제로 넣어야 한다.

### 업무 메신저로 들어온 에이전트
대시보드 대신 메신저에서 분석과 실행 제안을 받는 형태가 확산돼, 도입의 승부처가 기능보다 기존 업무 흐름 내 배치로 옮겨간다.

### 통제의 증빙 요구
에이전트가 기업 시스템에 직접 접근하면서, 행동을 파악하고 보안 통제가 작동함을 입증하는 거버넌스가 규제 대응의 핵심이 됐다.

### 전문 영역 평가와 플랫폼 다극화
실험 데이터 분석 같은 전문 업무용 평가가 등장하고 중국발 플랫폼도 성장해, 선정 기준이 업무 적합성과 지정학으로 넓어진다.
