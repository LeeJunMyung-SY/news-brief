# AI Agents and Autonomous Systems — 동향 요약

### 금융권 에이전트 책임 기준
금융 당국의 에이전트 규율 연구와 외부 에이전트 접근 차단이 겹쳐, 에이전트 확산이 책임·접근권 협상 문제로 바뀌었다.

### 국산 모델 기반 상용화
고객 소통 플랫폼과 국산 LLM 기업이 에이전트 상용화 제휴에 나서고 국내 SI도 에이전틱 플랫폼을 글로벌 레퍼런스로 내세워, 데이터 주권형 에이전트 공급망이 형성되고 있다.

### 플랫폼 접근 충돌
에이전트의 웹 수집이 플랫폼 봇 차단에 걸리는 사례가 나와, 외부 서비스 접근 정책이 에이전트 운영 리스크로 떠올랐다.

### 채용 구조의 직접 대체
프런티어 랩에서 에이전트가 주니어 업무를 대체하며 채용이 급감해, 인력계획 재설계가 현실 과제가 됐다.
