# AI Agents and Autonomous Systems — 동향 요약

### 실행 계층으로 내려온 에이전트
업무를 배정받아 상시 가동되며 앱에 직접 로그인해 다단계 작업을 끝내는 제품이 나오면서, 검토 항목이 답변 품질에서 계정 권한 설계로 이동했다.

### 기간계 연동이 기준선
예약·결제·정산 시스템에 직접 붙어 실제 업무를 수행하는 다중 에이전트 솔루션이 상용화되며 도입 기대치가 올라갔다.

### 원가는 라우팅으로 관리
작업 단계마다 적합한 모델을 골라 배분하는 기술이 공개돼, 모델 하나를 고르는 문제가 여러 모델을 섞는 설계 문제로 바뀌었다.

### 전환 비용을 낮추는 경쟁
경쟁 서비스의 작업 맥락을 통째로 옮겨오는 기능이 등장하며 공급사 종속 구도가 흔들리고 있다.
