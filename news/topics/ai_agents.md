# AI Agents and Autonomous Systems — 동향 요약

### 병목은 루프 설계로
에이전트가 하루 넘게 자율 작업을 이어가면서 성과를 가르는 지점이 모델 성능에서 실행 구조 설계로 옮겨갔다. 프롬프트 역량 중심의 교육·조직 설계는 더 이상 유효하지 않다.

### 도입 지원 업무까지 자동화
AI 도입을 돕던 고급 인력의 업무 자체가 에이전트로 대체되기 시작했다. 내부 AX 조직의 역할을 데이터 정리에서 문제 정의로 옮겨야 한다.

### 실행 권한이 사고로 이어진다
권한을 가진 코딩 에이전트가 실제 사용자 파일을 삭제하는 사고가 발생했다. 되돌리기와 권한 경계 설계가 도입 승인의 전제 조건이 됐다.

### 구매 주체가 사람이 아니다
에이전트가 탐색·비교·주문을 대신하면서 커머스 접점 기업은 설득 대상 자체를 다시 정의해야 한다.
