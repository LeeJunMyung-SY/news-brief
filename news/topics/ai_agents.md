# AI Agents and Autonomous Systems — 동향 요약

### 현업이 만드는 업무 에이전트
금융사까지 사내망 에이전트 플랫폼을 깔고 전 직원이 업무 에이전트를 직접 개발하게 해, 에이전트 확산이 IT 부서 주도에서 현업 주도로 옮겨가고 있다.

### 단일 에이전트로의 회귀
모델 성능 향상으로 공급사가 다수 서브에이전트 대신 단일 에이전트를 권고해, 멀티에이전트 설계의 운영 비용 재검토가 필요해졌다.

### 로컬 구동 에이전트의 현실화
수 GB급 경량 모델로 데이터 반출이 어려운 업무에 기기 내 에이전트를 구축할 선택지가 생겼다.

### 결제 위임과 거버넌스
에이전트 결제 상용화가 다가오며 위임 인증·한도·책임 소재와 실행 감사 기능이 도입의 선결 조건이 되고 있다.
