# AI Agents and Autonomous Systems — 동향 요약

### 업무 환경 안으로 들어왔다
AI 검색·지식관리·문서작성이 메신저·화상회의와 한 묶음으로 배포되며, 에이전트가 별도 앱이 아니라 기본 업무 환경의 일부가 됐다.

### 성패는 데이터 계층에서
파편화된 사내 데이터를 연결하는 플랫폼에 자금이 몰리며, 모델 성능보다 데이터 준비도가 도입 성과를 가르는 변수로 굳었다.

### 기간계 연동이 기준선
예약·결제·정산 시스템에 직접 붙어 실제 업무를 끝내는 제품이 상용화되며 도입 기대치가 올라갔다.

### 원가는 라우팅으로 관리
작업 단계마다 적합한 모델을 골라 배분하는 기술이 공개돼, 모델 선택이 하나를 고르는 문제에서 여럿을 섞는 설계 문제로 바뀌었다.
