# AI Agents and Autonomous Systems — 동향 요약

### 통제가 인프라 기본 기능으로
클라우드 사업자가 개별 작업이 아닌 연속된 행동 흐름을 정책으로 검증하는 도구를 공개하며, 에이전트 통제가 애플리케이션이 아닌 플랫폼 계층의 문제로 옮겨갔다.

### 안전은 실행 환경의 계약
학습 단계 정렬만으로는 코드를 실행하고 데이터를 바꾸는 자율 에이전트를 막을 수 없다는 관점이 힘을 얻으며, 샌드박스와 사후 추적이 기본 요건이 됐다.

### 순위표로는 고를 수 없다
에이전트 성능 분산의 대부분이 과업과의 상호작용에서 나온다는 분석이 나오며, 공개 리더보드 대신 자사 업무 기반 평가가 조달 조건이 되고 있다.

### 확장 수단이 오히려 부담
재사용 지침을 계속 붙이는 방식이 성공률을 낮추고 토큰·실행시간을 늘리는 사례가 확인돼, 지침 관리에도 검증이 필요해졌다.
