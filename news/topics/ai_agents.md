# AI Agents and Autonomous Systems — 동향 요약

### 에이전트의 직원화
주요 플랫폼이 에이전트에 업무 신원과 하위 에이전트 위임 기능을 부여해, 에이전트가 앱 기능이 아닌 조직 구성원처럼 운영되는 단계로 들어섰다.

### 보안 격리가 도입 전제
공개 에이전트 하나로 계정 내 전체 에이전트가 장악되는 취약점이 드러나, 권한 격리와 외부 노출 분리가 기본 통제가 됐다.

### 통제 비용 낮추는 감시 계층
도입은 늘지만 운영 전환은 정체된 가운데, 모델 내부 신호 기반 저비용 감시 기술이 등장해 운영 통제의 경제성이 개선되고 있다.

### 자본 유입과 오픈소스 대안
에이전트 기업에 대형 투자가 이어지고 오픈소스 에이전트도 기업용으로 진입해, 벤더 종속을 피하는 조달 선택지가 넓어지고 있다.
