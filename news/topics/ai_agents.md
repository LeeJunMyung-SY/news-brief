# AI Agents and Autonomous Systems — 동향 요약

### 모델 공급망 보안 리스크
소량의 학습 데이터 오염만으로 에이전트에 백도어가 남고 미세조정으로도 제거되지 않아, 실행 권한을 가진 에이전트는 샌드박스와 행동 감시가 전제가 됐다.

### 보안 대응의 자동화와 권한 한계
멀티 에이전트 보안 체계가 탐지부터 패치까지 분 단위로 처리하지만 자동 패치 오류 위험이 남아, 사람 승인 지점 설계가 핵심 과제다.

### 반복 작업의 비용 최적화
라우팅·추출 전용 초저가 소형 모델이 나와, 에이전트 워크플로를 모델 계층으로 나누는 설계가 운영비 절감의 표준이 되고 있다.

### 금융 에이전트의 책임 공백
금융 거래를 대행하는 에이전트가 확산되는데 책임 경계와 결제 신뢰 체계가 미비해, 해석과 실행을 분리하는 거버넌스가 도입 전제로 떠올랐다.
