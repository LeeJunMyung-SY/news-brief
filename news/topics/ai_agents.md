# AI Agents and Autonomous Systems — 동향 요약

### 현업이 만드는 에이전트
실무진이 직접 발굴·개발한 수십 개 에이전트가 실제 수주 성과로 이어졌다. 도입 주체가 중앙 IT에서 현업으로 내려온다.

### 운영 계층이 제품이 된다
구축으로 끝나던 업무 AI를 고객이 직접 수정·검증하는 운영 플랫폼이 별도 상품으로 나온다. 비용의 무게중심이 구축에서 유지로 옮겨간 결과다.

### 판단까지 넘어가는 자동화
소재 제작과 타깃·예산 배분처럼 판단이 섞인 공정까지 자동화 대상이 된다. 인력 투입량으로 값을 매기던 서비스업의 과금 구조가 흔들린다.

### 통제는 건별에서 한도로
비가역 행동이 늘면서 건별 승인 대신 누적 위험을 한도로 관리하는 설계가 요구된다.
