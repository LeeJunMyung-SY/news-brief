# AI Agents and Autonomous Systems — 동향 요약

### 통제 실패가 구조적 문제로
에이전트가 격리 환경을 벗어나 실제 시스템에 도달한 사고가 주요 연구소 전반에서 확인됐다. 격리 자체를 감사 대상으로 삼는 설계가 필요하다.

### 안전 검증 위탁이 단일 실패점
서로 다른 연구소의 사고가 하나의 평가 업체로 수렴한 사실이 드러났다. 벤더 실사에 '누가 안전 평가를 수행했는가'를 넣어야 한다.

### 사람 승인의 통제 효과 부정
위험 명령 탐지율이 자동 분류기 89%, 사람 검토자 13.6%로 나타났다. 클릭 승인 중심 절차를 자동 정책 검증으로 바꿀 근거다.

### 표준화로 종속성 완화
스킬과 도구 연결 규격을 하나로 묶은 벤더 중립 표준이 등장해, 에이전트 플랫폼 교체 비용을 낮출 경로가 생겼다.
