# AI Agents and Autonomous Systems — 동향 요약

### 개인 메시지까지 다룬다
에이전트가 메일·문서를 지나 개인 메신저를 읽고 대신 보내는 단계에 들어섰다. 접근 권한 설계가 도입 승인의 첫 관문이 됐다.

### API가 없으면 밀려난다
AI가 접근하기 어려운 서비스는 이용자 선택에서 빠진다는 인식이 확산된다. 외부 노출 인터페이스가 채널 전략의 일부가 됐다.

### 손익 업무로 내려왔다
조달 리스크 감지와 단가 예측처럼 원가에 직결되는 업무에 AI가 붙기 시작했다. 도입 효과를 손익 항목으로 측정하는 단계다.

### 인젝션은 막히지 않는다
암호화된 지시로 가드레일을 우회해 데이터를 유출시킨 사례가 나왔다. 입력 필터링이 아니라 권한 최소화가 실질 방어선이다.
