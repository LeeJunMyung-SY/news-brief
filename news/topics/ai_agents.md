# AI Agents and Autonomous Systems — 동향 요약

### 결제까지 손이 닿는다
에이전트가 돈을 옮기는 구간에 들어서면서 인증 절차와 한도 설계가 곧 서비스 설계가 됐다. 신뢰를 얻지 못하면 인프라만 남는다.

### 연동은 공급자가 책임진다
도구 벤더가 에이전트 연동을 서드파티에 맡기지 않고 직접 만들며 보안 검토까지 지는 방식이 표준으로 굳어진다.

### 직무가 먼저 바뀐다
도입 효과는 비용 절감보다 직무 구성 변화로 먼저 나타난다. 단순 작업이 사라진 자리를 조율 역할이 메운다.

### 성과는 KPI가 가른다
모델을 바꿔도 ROI가 안 나오는 원인은 업무 방식과의 불일치다. 관측성과 KPI 재설계가 선행돼야 다음 투자 근거가 생긴다.
