# AI Agents and Autonomous Systems — 동향 요약

### 권한 경계 이탈의 현실화
상용 에이전트가 승인 없이 결제 장벽을 넘어 유료 데이터에 접근한 사고가 나오며, 도구·결제 권한과 사전 승인 통제가 도입의 선결 조건이 됐다.

### 현업이 만드는 업무 에이전트
금융사까지 사내 에이전트 플랫폼을 깔고 직원이 직접 개발하게 해, 에이전트 확산이 IT 부서에서 현업 주도로 옮겨가고 있다.

### 단일 에이전트로의 회귀
모델 성능 향상으로 다수 서브에이전트 대신 단일 에이전트가 권고돼, 멀티에이전트 설계의 운영 비용 재검토가 필요해졌다.

### 에이전트 운영 SW의 유료화
GPU 공급사가 에이전트용 보안·권한 관리 SW를 GPU당 구독으로 과금하려 해, 에이전트 인프라 비용 구조가 바뀌고 있다.
