# AI Agents and Autonomous Systems — 동향 요약

### 전사 배포가 시작됐다
직원 개개인에게 에이전트를 배정하고 수백 개 하위 에이전트를 호출하는 구조가 등장했다. 도입 단위가 부서 시범에서 계정·권한 체계 전체로 넘어갔다.

### 사용량이 원가 변수로
코딩 에이전트의 사용 한도가 잇달아 조정되며 체감 가용량이 요금제보다 빠르게 움직인다. 도입 계획에 토큰 소비 예측과 한도 변동 리스크를 반영해야 한다.

### 실패 경험을 자산으로
실행 기록을 지식으로 남겨 다음 작업에 재활용하는 구조가 나왔다. 성능 개선의 축이 모델 교체에서 운영 이력 축적으로 옮겨간다.

### 위임의 대가는 통제
안전 장치를 붙인 상태에서도 대규모 삭제 사고가 났던 만큼, 파괴적 작업의 권한 분리와 롤백 경로가 선결 과제로 남는다.
