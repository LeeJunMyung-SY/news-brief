# AI Agents and Autonomous Systems — 동향 요약

### 장시간 자율 작업의 현실화
에이전트가 인간 기준 수십 시간짜리 작업까지 수행하게 되며, 자동화 설계의 초점이 사람의 검수 지점 배치로 옮겨간다.

### 플랫폼과 앱의 접근권 충돌
OS 사업자는 자사 에이전트를 키우며 외부 접근을 조이고 민감 앱은 화면 읽기를 차단해, 접근 권한이 경쟁과 신뢰의 쟁점이 됐다.

### 메모리 구조가 비용을 좌우
긴 컨텍스트보다 요약·선택 검색이 효율적이라는 연구가 나와, 에이전트 설계에서 메모리 관리가 비용과 정확도의 핵심이 됐다.

### 에이전트 결제 수단의 다변화
에이전트 대리 결제에 후불 수단이 붙으며, 결제 채널에서 수단 간 노출 경쟁이 시작됐다.
