# AI Agents and Autonomous Systems — 동향 요약

### OS·단말 사업자의 직접 참전
단말과 OS를 가진 사업자가 앱 조작과 코딩까지 맡는 범용 에이전트 조직을 꾸려, 접점 주도권 경쟁이 플랫폼 보유 기업 중심으로 재편되고 있다.

### 전용 단말의 가격 공세
통신 요금을 묶은 저가 에이전트 전용 기기가 연말 출시를 앞둬, 스마트폰 밖에서 이용 습관을 선점하려는 시도가 본격화됐다.

### 기업 SW의 자체 생성 전환
코딩 에이전트로 개발 비용이 급감하며, 단순 기능 소프트웨어를 사서 쓰기보다 필요할 때 만들어 쓰는 방식이 조달 선택지로 떠올랐다.

### 통제 실패와 데이터 격리
에이전트발 장애와 타인 정보 노출 사례가 이어져, 권한 위임과 데이터 격리 설계가 도입의 전제 조건으로 굳어졌다.
