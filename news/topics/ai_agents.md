# AI Agents and Autonomous Systems — 동향 요약

### 감독 업무까지 자동화
규제기관이 탐지부터 보고서 작성까지 감시 전 과정을 에이전트로 묶었다. 판단이 개입하는 업무도 자동화 대상이 됐다는 신호다.

### 폐쇄망으로 들어간다
외부 전송 없이 도는 코딩 에이전트가 등장하며, 보안 규제로 도입을 미뤄온 조직에도 경로가 열렸다.

### 구매 주체가 사람이 아니다
에이전트가 탐색·비교·결제를 대신하면서 결제 기업이 모델 중개 계층을 인수하는 선점 경쟁이 시작됐다.

### 실행 권한이 사고로
권한을 가진 에이전트의 파일 삭제 사고 이후, 되돌리기와 권한 경계 설계가 도입 승인의 전제 조건이 됐다.
