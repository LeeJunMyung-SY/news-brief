# AI Agents and Autonomous Systems — 동향 요약

### 승인 권한의 위임
에이전트가 코드 리뷰를 넘어 승인까지 맡기 시작해, 기업은 자동 승인 범위와 사람 검토 기준을 새로 설계해야 한다.

### 실행형 업무 에이전트 확산
사내 에이전트 플랫폼이 조회를 넘어 신청·승인 요청·데이터 입력까지 수행하며, 공공·기업 에이전트가 실행형으로 넘어가고 있다.

### 에이전트 실행 인프라
클라우드가 다수 에이전트 동시 실행을 전제로 CPU·보안칩까지 재설계해, 에이전트의 비용과 격리 보안이 인프라 과제가 됐다.

### 차단·유출과 책임 배분
외부 에이전트 차단, 사고 책임 고객 전가, 에이전트를 활용한 내부 유출 사례가 겹쳐, 권한·로그 관리가 확산의 전제가 됐다.
