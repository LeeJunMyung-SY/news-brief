# AI Agents and Autonomous Systems — 동향 요약

### 입력 문서가 공격면이 된다
외부에서 들어온 문서에 사람 눈에 보이지 않는 지시문을 심어 자동 검토를 조작하려는 시도가 실제로 확인됐다. 심사·계약 검토 자동화는 전처리 검증을 전제로 설계해야 한다.

### 맥락 수집이 단말까지 내려왔다
개인 PC의 앱·웹 활동 이력을 기억해 작업을 이어주는 비서 기능이 나왔다. 생산성 이득만큼 사내 정보 통제 항목이 늘어난다.

### 병목은 모델이 아니라 데이터
성능을 가르는 제약이 모델 선택에서 내부 업무 기록 확보로 옮겨갔다. 도입 로드맵의 선행 과제는 데이터 정비다.

### 보안 점검도 상시 자동화로
에이전트가 스스로 침투를 시도하는 방식이 제품군으로 자리잡았다.
