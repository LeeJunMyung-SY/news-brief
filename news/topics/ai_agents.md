# AI Agents and Autonomous Systems — 동향 요약

### 권한 위임이 제도로 열렸다
금융 마이데이터에 에이전트가 금리인하 요구·정책자금 신청 같은 권리 행사를 대행하는 근거가 생겼다. 에이전트가 추천을 넘어 실행 주체가 되면서 책임 소재 설계가 도입의 전제가 됐다.

### 호출형에서 상주형으로
업무 협업 도구 안에서 대화 맥락을 읽고 호출 없이 개입하는 에이전트가 등장했다. 접근 범위와 개입 조건을 정하는 일이 성능 검증보다 앞선 관문이다.

### 상호운용 표준이 앞단 경쟁
국제 에이전트 표준 채널에 공공 연구기관이 참여하며 연계 규격 선점 경쟁이 본격화됐다. 표준의 향방이 도입 기업의 벤더 종속 여부를 가른다.

### 인프라 전제가 바뀐다
에이전트 수천 개 운용을 전제로 한 인프라 현대화 청사진과 다단계 추론 전용 가속기가 함께 나왔다. 도입 판단 기준이 모델 성능에서 추론 지연·처리량으로 이동한다.
