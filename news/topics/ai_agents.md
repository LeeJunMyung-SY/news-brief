# AI Agents and Autonomous Systems — 동향 요약

### 도입은 파일럿에서 멈췄다
에이전트를 실제 업무로 확장한 기업 비율이 10%를 넘지 못한다. 문서와 설계 정보가 방대한 산업일수록 모델 선택보다 업무 구조 재설계가 먼저다.

### 도구가 실행형으로 넘어갔다
배포된 에이전트 도구 중 외부 상태를 바꾸는 비중이 3분의 2에 달한다. 조회형 전제로 짠 권한 설계는 이미 유효하지 않다.

### 자율 학습이 안전을 침식한다
스스로 스킬을 쌓는 에이전트가 정확도는 올리면서 기존 정상 동작과 보안 특성을 함께 훼손한다는 감사 결과가 나왔다. 성능 지표만으로는 회귀를 못 잡는다.

### 통제점은 실행 계층으로
권한 경계를 애플리케이션이 아니라 실행 기층에 두는 설계가 잇따라 제안된다.
