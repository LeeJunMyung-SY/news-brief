# AI Agents and Autonomous Systems — 동향 요약

### 도입 병목은 데이터 연결
업무 수행형 에이전트의 관건이 모델 성능에서 사내 정보 통합으로 옮겨가, 데이터 준비도가 도입 속도를 가른다.

### 고객 대리 에이전트와 채널 충돌
금융·유통에서 개인 에이전트 차단과 수용이 맞서며, 권한 위임과 책임 설계가 채널 전략의 핵심 과제가 됐다.

### 코딩 에이전트의 한계 확인
명시되지 않은 요구 파악이 여전히 약해, 도입 효과가 명세 품질과 검토 체계에 달렸음이 드러났다.

### 권한이 곧 공격면
인터페이스 간 우회와 외부 데이터 조작 위험이 부각되며, 실행 경로 단위의 통제가 선결 조건이 됐다.
