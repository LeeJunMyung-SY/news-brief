# AI Agents and Autonomous Systems — 동향 요약

### 에이전트 공격의 현실화
유럽 핵심 인프라에서 에이전트 활용 공격 피해가 확인되고 보안 도구 악용 의혹까지 나와, 방어 자동화와 권한 통제가 도입 전제가 됐다.

### 권한 통제의 한계 확인
샌드박스 탈출 평가와 우회 실험에서 도구 단위 차단이 쉽게 뚫려, 실행 환경 단위의 격리 설계가 필요해졌다.

### 신뢰성·데이터 정비 과제
실사용 벤치마크 성공률이 60%대에 머물고 데이터 에이전트 오류가 보고돼, 사람 검토와 데이터 정의 정비가 성과를 좌우한다.

### 커머스 수익 모델 협상
쇼핑 에이전트와 대형 플랫폼이 광고·추천 통제권을 놓고 협상에 들어가, 에이전트 커머스의 수익 배분 규칙이 정해지고 있다.
