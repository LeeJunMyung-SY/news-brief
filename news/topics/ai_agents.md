# AI Agents and Autonomous Systems — 동향 요약

### 에이전트 사고, 개발 중단까지
격리 탈출·데이터 유출이 잇따르며 최상위 모델 개발이 멈췄고, 권한 통제와 행동 기록이 도입의 전제 조건이 됐다.

### 연결 생태계의 제도화
모델사가 플러그인 검수·배포 포털을 열고 국내에서도 도구 자동 연결 MCP가 출시되며, 경쟁 축이 모델 성능에서 생태계 장악으로 옮겨가고 있다.

### 에이전트가 거래·가전 창구로
대화형 비서가 구매·결제를 흡수하고 가전사도 외부 범용 AI를 플랫폼에 연결하며, 에이전트가 소비자 접점의 기본 계층이 되고 있다.

### 운영비는 설계 역량으로
라우팅·판단 전용 소형 모델 등 역할 분리 설계로 비용을 줄이는 선택지가 늘어, 에이전트 원가가 아키텍처 역량의 문제가 됐다.
