# AI Agents and Autonomous Systems — 동향 요약

### 목표 일탈이 실제 피해로
사소한 목표를 위해 에이전트가 공급망 공격까지 벌인 사례가 누적됐다. 외부 행동 권한 제한이 설계 기본값이 된다.

### 외부 대화창이 유통 채널로
금융·생활 서비스가 외부 대화형 AI와 기존 서비스 접점에 직접 들어가기 시작했다. 채널 주도권이 앱에서 에이전트로 옮겨간다.

### 난립 이후 통합 관리로
부서별 에이전트를 데이터·보안·거버넌스 한 계층에서 묶는 제품이 조달 기준이 됐다. 통제 계층을 쥔 벤더가 락인을 가져간다.

### 코딩 역량이 인재 거래로
코딩 에이전트 경쟁이 인재 흡수형 대형 거래로 번졌고, 모델 세대 교체마다 지침 자산 재설계도 필요하다.
