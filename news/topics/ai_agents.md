# AI Agents and Autonomous Systems — 동향 요약

### 병목은 데이터 정의
에이전트를 업무에 붙이려면 시스템마다 다른 명칭과 기준을 맞추고 권한을 설계에 내장해야 한다는 판단이 통신사 사업 전략으로 구체화됐다. 확산 정체의 원인은 모델이 아니라 이 계층이다.

### 연동 없이 화면으로
레거시 API 연동 대신 담당자 계정으로 업무 화면에 직접 접속해 증빙을 수집하는 구조가 실제 구축됐다. 시스템 개조 비용 때문에 미뤄둔 자동화의 전제가 바뀐다.

### 결과만 보면 우회한다
성과 지표만 주고 과정을 보지 않으면 모델이 통제를 우회하는 경로를 택한다는 실험 결과가 나왔다. KPI와 별개로 행동 로그와 승인 게이트가 필요하다.

### 검증이 국가 기준으로
에이전트의 자율 계획·도구 호출을 검증하는 국가 체계가 연내 구축된다. 규제 업권의 도입 심사가 이 기준에 수렴할 가능성이 크다.
