# AI Agents and Autonomous Systems — 동향 요약

### 화면 조작 에이전트의 보편화
컴퓨터를 직접 조작하는 기능이 주요 사업자 모두의 기본 사양이 돼, 연동 창구가 없는 시스템까지 자동화 범위에 들어왔다.

### 플랫폼과 앱의 접근권 충돌
OS 사업자는 자사 에이전트를 키우며 외부 접근을 조이고 민감 앱은 화면 읽기를 스스로 차단해, 접근 권한이 경쟁과 신뢰의 쟁점이 됐다.

### 운영 업무로의 확장
코딩 에이전트가 장애 감지부터 수정, 배포 후 검증까지 맡는 사례가 나와, 활용 범위가 개발에서 IT 운영으로 넓어지고 있다.

### 에이전트 결제 수단의 다변화
에이전트 대리 결제에 후불 수단이 붙으며, 결제 채널에서 수단 간 노출 경쟁이 시작됐다.
