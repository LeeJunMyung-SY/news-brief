# AI Agents and Autonomous Systems — 동향 요약

### 에이전트가 기록을 갖기 시작했다
AI 비서가 사용자 활동을 구조화해 상시 보유하는 기능이 등장했다. 유용성이 기록량에 비례하는 만큼 보존 범위와 접근 통제가 도입 전 결정 사항이 된다.

### 연결 규격이 공공까지 내려왔다
공공기관이 데이터를 MCP 형태로 개방하며 에이전트가 외부 시스템을 직접 조회하는 방식이 표준 경로로 자리 잡는다.

### 통제 지점이 게이트웨이로 모인다
여러 모델·에이전트 호출을 단일 관문에서 관리하려는 수요가 제품 도입으로 나타난다.

### 산업 현장이 다음 무대
작업자 지원형 에이전트에 수요 산업 기업이 직접 투자한다.
