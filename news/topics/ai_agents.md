# AI Agents and Autonomous Systems — 동향 요약

### 에이전트 공격의 실침해화
에이전트 활용 공격이 정부기관을 넘어 대형 SW 공급사 개발망까지 침투해, 공급망 단위의 권한·인증 통제가 도입 전제가 됐다.

### 데이터 정의가 정확도 좌우
모델사가 비즈니스 지표 표준을 담은 시맨틱 레이어를 직접 만들 만큼, 에이전트 성과는 사내 데이터 정의와 거버넌스 정비에 달렸다.

### 레거시 연계와 업무 지식화
기존 시스템을 유지한 채 연계 계층과 스킬로 에이전트를 붙이는 방식이 확산돼, 업무 노하우의 표준화가 경쟁력이 된다.

### 에이전트 커머스의 책임 공백
에이전트 실결제가 성공하는 한편 주문 오류와 플랫폼 차단이 겹쳐, 정확성 보장과 오류 책임 규칙이 확산의 관건이 됐다.
