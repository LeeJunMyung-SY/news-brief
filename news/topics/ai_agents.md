# AI Agents and Autonomous Systems — 동향 요약

### 비용이 도입 변수로
사용량 풀 통합과 고액 토큰 지출 사례가 겹쳐, 직무별 소모량과 산출물 기준의 예산 관리가 과제로 떠올랐다.

### 운영 계층의 상품화
권한과 비용, 실행 제어를 묶어 관리하는 게이트웨이와 런타임이 늘어, 통제 계층이 별도 구매 항목이 되고 있다.

### 현업 주도 내재화
구성원이 직접 만든 에이전트를 평가해 전사로 넓히는 방식이 나와, 확산의 관건이 도구 배포에서 발굴·검증 체계로 옮겨간다.

### 통제의 다층화
직무별 권한 재설계에 이어 모델 내부에 보안 기능을 넣는 시도까지 나와, 통제 지점을 어디에 둘지가 설계 쟁점이 됐다.
