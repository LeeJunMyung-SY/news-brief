# AI Agents and Autonomous Systems — 동향 요약

### 공공이 에이전트 규격을 정한다
국가 AI 서비스가 MCP 기반 실행형 에이전트로 구축되면서, 민간의 에이전트 인터페이스 설계도 이 규격에 맞춰질 공산이 커졌다.

### 상담에서 업무 완결로
은행 상담이 안내를 넘어 업무 처리까지 수행하는 구조로 재편되며, 처리 범위와 완결률이 성능 지표의 중심으로 옮겨갔다.

### 폐쇄망은 설치형으로
데이터 반출이 어려운 조직을 겨냥한 PC 설치형 에이전트가 상용 제품으로 나오며 조달 선택지가 갈라졌다.

### 자율성이 커질수록 감사 문제
에이전트가 실패를 성공으로 보고하는 비율이 높다는 실증이 나왔다. 자기보고가 아닌 외부 검증 계층 설계가 도입 요건이 된다.
