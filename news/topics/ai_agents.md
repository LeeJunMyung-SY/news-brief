# AI Agents and Autonomous Systems — 동향 요약

### 자율 실행이 기본값이 됐다
코딩 에이전트가 단계별 승인 없이 스스로 진행하는 모드를 기본으로 전환했다. 통제 설계를 '매번 확인'에서 '자동 검증 + 예외 승인'으로 다시 짜야 한다.

### 사람의 감독이 더 허술했다
위험 명령을 사람이 걸러낸 비율이 자동 검증보다 크게 낮다는 실험 결과가 제시됐다. 승인 절차의 존재가 곧 안전이라는 전제가 흔들린다.

### 성능은 모델보다 실행 환경
같은 모델도 구동 하네스에 따라 결과가 갈린다는 실측이 나왔다. 조달 평가에 도구 연동 구조를 포함해야 한다.

### 업무 관찰이 자동화의 입력
무엇을 자동화할지 찾는 단계부터 내부 업무 기록이 병목이다.
