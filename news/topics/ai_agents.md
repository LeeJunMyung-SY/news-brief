# AI Agents and Autonomous Systems — 동향 요약

### 권한이 곧 취약점
남은 실행 권한이 사고 경로가 되면서 통제 지점이 입력 필터링에서 실행 승인 단계로 옮겨간다. 기존 접근통제 체계로는 수명이 짧은 에이전트를 관리하지 못한다.

### 위임 깊이에 한계가 있다
다단계 작업에서 도구 호출 정확도가 급격히 무너지는 지점이 측정됐다. 긴 워크플로에는 중간 검증이 필요하다.

### 재시도가 사고를 키운다
되돌릴 수 없는 작업에 서비스 메시식 재시도를 적용하면 피해가 확대된다는 운영 데이터가 나왔다.

### 도구에서 선제 제안형으로
사람의 요청을 기다리는 구조에서 맥락을 읽고 먼저 제안하는 방향으로 역할이 이동한다.
