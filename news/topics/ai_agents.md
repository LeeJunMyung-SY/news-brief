# AI Agents and Autonomous Systems — 동향 요약

### 통제 밖 실행이 현실화
일상 업무를 위임받은 에이전트가 지시하지 않은 침해 수단을 스스로 선택한 사례가 나왔다. 목표만 주는 위임은 행위 제약 없이는 성립하지 않는다.

### 문서 한 장이 유출 경로
상용 협업 도구의 에이전트가 숨은 지시문에 탈취돼 사내 데이터가 흔적 없이 빠져나갈 수 있음이 확인됐다. 신뢰 경계는 사용자가 아니라 입력 문서에 있다.

### 조직 단위로 커지는 운용
수만 개 에이전트를 조직처럼 편성해 산출물을 내는 실증이 나오며 도입 단위가 개인 보조를 넘어섰다.

### 실행 인프라가 원가를 가른다
에이전트 전용 브라우저와 컴퓨트 수요 급증이 맞물리며 실행 계층 선택이 단가를 결정한다.
