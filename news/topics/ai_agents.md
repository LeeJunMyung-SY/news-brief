# AI Agents and Autonomous Systems — 동향 요약

### 업무 앱의 에이전트화
기간계 업무 SW가 AI가 직접 실행하는 환경으로 바뀌어, 시스템 고도화에 에이전트 통합이 필수가 됐다.

### OS 비서의 대중화
스마트폰 OS 비서가 한국어로 개인 맥락 기반 작업 대행을 시작해, 서비스 앱의 비서 연동 전략이 과제로 떠올랐다.

### 데이터 계층 통제로 이동
에이전트가 앱을 우회해 DB에 직접 접근하면서, 접근 통제와 행동 감시를 데이터·런타임 계층에서 강제하는 설계가 확산된다.

### 공격 도구가 된 에이전트
에이전트 기반 침투가 단시간에 내부망을 뚫어, 방어 측도 에이전트 속도에 맞춘 보안 체계가 필요해졌다.
