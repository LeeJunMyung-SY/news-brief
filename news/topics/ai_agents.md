# AI Agents and Autonomous Systems — 동향 요약

### 위임의 대가가 자산 파괴로
안전 장치를 붙인 상태에서도 대규모 데이터가 통째로 삭제되는 사고가 나왔다. 필터의 존재가 통제를 담보하지 않으며, 파괴적 작업의 권한 분리와 롤백 경로가 도입 요건으로 올라선다.

### 실행 환경 운용을 모델이 배운다
외부 메모리·도구 사용 규칙을 사람이 짜는 대신 모델이 스스로 학습하는 접근이 등장했다. 장기 실행 성능의 관건이 모델 크기에서 실행 환경 운용으로 옮겨간다.

### 접점이 결제까지 흡수한다
대화형 접점이 탐색·예약·결제를 한 흐름으로 끌어안으며 자사 채널을 우회하는 거래 비중이 늘고 있다.

### 성과를 토큰으로 잰다
투입 토큰 대비 업무 성과를 보는 지표가 제안되며 에이전트 예산의 근거가 실행 로그로 옮겨간다.
