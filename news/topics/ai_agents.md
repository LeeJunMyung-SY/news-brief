# AI Agents and Autonomous Systems — 동향 요약

### 상시 실행 주체로 넘어간다
종료 없이 구동하며 스스로 다음 과제를 만드는 에이전트가 시험되고 있다. 요청형 도구를 전제로 한 승인·과금 구조로는 관리가 어렵다.

### 접점이 결제까지 흡수한다
대화형 검색이 가격 추적·예약·결제를 한 흐름으로 끌어안으면서, 자사 채널을 거치지 않는 거래 비중이 늘고 고객 데이터 접점이 플랫폼으로 넘어간다.

### 권한 관리가 도입 전제로
에이전트를 사람과 동일한 아이덴티티 관리 대상으로 묶는 통합 보안 전략이 등장했다. 남은 실행 권한이 사고 경로가 되는 만큼 권한 설계가 도입 순서를 앞선다.

### 성과를 토큰으로 잰다
투입 토큰 대비 업무 성과를 보는 지표가 제안되며, 에이전트 예산의 정당화 근거가 실행 로그로 옮겨간다.
