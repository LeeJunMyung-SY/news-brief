# AI Agents and Autonomous Systems — 동향 요약

### 결제까지 맡는 에이전트
카드망과 계좌이체 양쪽에서 에이전트가 실제 결제를 완결하며, 탐색 보조를 넘어 거래 실행 주체로 올라섰다.

### 금융 규제 업무에 실투입
은행 운영과 KYC 검증에 에이전트가 실가동되고 온보딩 개선 수치가 나오며 컴플라이언스가 우선 적용 영역이 됐다.

### 실행 기반의 개방화
기기 칩이 에이전트를 전면에 내걸고 모델 중립 실행환경이 오픈소스로 풀리며, 경쟁 축이 프레임워크에서 업무 설계와 데이터로 옮겨간다.

### 권한 설계가 도입 요건
외부 도구를 통한 에이전트 탈취가 실증되고 국내 개인정보 당국이 권한 범위·책임 기준 논의에 착수해, 권한 격리와 감사가 도입의 전제가 됐다.
