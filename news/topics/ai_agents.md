# AI Agents and Autonomous Systems — 동향 요약

### 입력 문서가 공격면이 된다
외부에서 들어온 문서에 사람 눈에 보이지 않는 지시문을 심어 자동 검토를 조작하려는 시도가 확인됐다. 심사·계약 검토 자동화는 전처리 검증을 전제로 설계해야 한다.

### 병목은 모델이 아니라 데이터
성능을 가르는 제약이 모델 선택에서 내부 업무 기록 확보로 옮겨갔다. 도입 로드맵의 선행 과제는 데이터 정비다.

### 활용 역량이 현업으로 내려왔다
에이전트 성과가 개발 숙련도보다 도메인 통찰에서 갈린다는 결과가 나왔다. 인재 기준을 개발 직군 밖으로 넓혀야 한다.

### 도구가 공급사로 흡수된다
개발 보조 도구가 컴퓨팅 보유 기업 안으로 묶이며 협상 여지가 줄었다.
