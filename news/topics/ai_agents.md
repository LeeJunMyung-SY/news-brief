# AI Agents and Autonomous Systems — 동향 요약

### 업무 앱의 에이전트화
기간계 업무 SW가 사람이 조작하는 도구에서 AI가 직접 실행하는 환경으로 바뀌어, 시스템 고도화에 에이전트 통합이 필수가 됐다.

### 에이전트 설계의 양극화
단일 에이전트 회귀론과 1천 개 규모 탈중앙 협업 실험이 공존해, 업무 특성별 아키텍처 선택이 중요해졌다.

### 에이전틱 커머스의 마찰
리테일러가 쇼핑 에이전트를 봇으로 차단하기 시작해, 에이전트 결제·구매 서비스는 가맹점 수용성이 관건이 됐다.

### 권한 통제의 선결 조건화
승인 없는 데이터 접근 사고 이후 실행 권한·감사 기록 설계가 에이전트 도입의 전제 조건으로 굳어지고 있다.
