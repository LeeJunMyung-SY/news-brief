# AI Agents and Autonomous Systems — 동향 요약

### 대화창 안의 커머스
AI 어시스턴트가 기업 프로필·브랜드 에이전트·예약 연동을 받아들이며 고객 유입 채널이 되고, 차량 구매처럼 고가 거래까지 대화창에서 끝나기 시작했다.

### 플랫폼의 접근 통제
대형 커머스가 외부 에이전트를 차단하고 금융권은 에이전트 거래 식별 기술을 도입해, 에이전트 활동의 허용·인증이 새 경쟁 축이 됐다.

### 앱 개방 표준의 확산
크리에이티브·업무 SW가 MCP로 외부 에이전트에 기능을 열어, 사내 도구의 에이전트 연동성이 도입 효과를 좌우한다.

### 생성 앱의 보안 공백
코딩 에이전트로 만든 앱 수만 개가 공개 노출돼, 현업 개발 확산에는 배포 전 권한 점검 자동화가 전제가 됐다.
