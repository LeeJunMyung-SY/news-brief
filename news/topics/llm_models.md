# Large Language Models and Foundation Models — 동향 요약

### 프런티어 단가 급락
최상위 모델 가격 40~50% 인하에 이어 음성 모델까지 최대 95% 인하가 나오며, 사용량 예산과 계약 조건을 다시 볼 시점이다.

### 모델이 업무 인터페이스로
신모델이 음성 비서에 탑재돼 메일·일정·협업툴을 직접 조작하며, 경쟁 축이 성능에서 업무 앱 연결성으로 옮겨간다.

### 능력 주장은 검증 대상
성과 발표의 과장 논란에 더해 추론 최적화가 글쓰기 품질을 떨어뜨렸다는 설명까지 나와, 자사 업무 기준 평가가 중요해졌다.

### 연구 성과가 사업 가치로
모델 기업이 자체 실험실의 과학 발견을 앞세우며, API 판매를 넘어 연구개발 성과 자체를 기업가치의 근거로 삼기 시작했다.
