# Large Language Models and Foundation Models — 동향 요약

### 프런티어 랩의 공개시장 검증
선두 모델 공급사가 분기 매출 168억달러와 흑자를 앞세워 IPO 로드쇼를 시작했지만 성장 둔화로 기대를 밑돌아, 모델 사업의 수익성·성장률이 시장 전체의 AI 투자 심리를 좌우하는 변수가 됐다.

### 소액 사후학습 특화 모델의 비용 경쟁력
30만달러 사후학습으로 특정 지식 작업에서 프런티어 모델을 넘고 작업당 비용을 1/63로 낮춘 사례가 나와, 범용 API 호출과 오픈 모델 특화 학습 사이의 선택 기준이 비용 측면에서 구체화됐다.

### 오픈 모델 자체 운영 생태계
추론 인프라 기업과 오픈 모델 플랫폼이 국내 기업 경영진 대상 벤더 종속 탈피 경로를 제시해, 망분리·데이터 통제가 중요한 규제 산업에 오픈 모델 운영이 현실적 선택지로 자리 잡고 있다.

### 거래 데이터 파운데이션 모델
은행이 거래 데이터로 자체 파운데이션 모델을 주권 클라우드에서 학습하는 첫 사례가 나와, 범용 모델 호출과 자체 모델 구축의 선택 기준이 금융 AI 전략의 핵심 변수가 됐다.
