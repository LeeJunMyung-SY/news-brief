# Large Language Models and Foundation Models — 동향 요약

### 로컬 구동이 현실 선택지로
대형 오픈 모델을 고사양 PC급 환경에서 돌릴 수 있을 만큼 양자화가 진전됐다. 민감 데이터 업무에서 자체 구동 검토의 비용 전제가 달라진다.

### 소형화가 단가를 흔든다
소형 모델이 프론티어급 성능에 근접하며 API 장기 계약과 자체 운영의 손익 비교가 다시 열렸다.

### 안전장치 제거판이 유통된다
공개 가중치의 거부 기능을 걷어낸 변형이 곧바로 배포되며, 오픈 모델 도입 시 자체 통제 계층이 필수가 됐다.

### 조달에 권리 리스크가 붙는다
학습 데이터 소송이 확대되며 모델 선택 검토 항목에 지식재산 리스크가 추가됐다.
