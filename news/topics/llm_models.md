# Large Language Models and Foundation Models — 동향 요약

### 개발 속도의 가속
AI가 차세대 모델 개발에 투입되며 개선 주기가 절반 수준으로 짧아져, 모델 선택·계약 전략의 갱신 주기도 빨라져야 한다.

### 보안 특화 모델 등장
공격·방어 역량을 갖춘 모델이 승인 기반으로 공급되기 시작해, 기업 보안 점검에 AI를 쓰는 조건 설계가 과제가 됐다.

### 업종 특화 모델 부상
의료·제약 분야 특화 파운데이션 모델이 실증에 들어가, 규제 업종에서 범용 모델과 특화 모델을 나눠 쓰는 구도가 형성된다.

### 모델 신뢰성 검증
은밀한 성능 저하 사례가 나오며 공급사 감사와 과제별 검증이 중요해졌다.
