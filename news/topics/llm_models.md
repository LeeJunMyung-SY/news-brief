# Large Language Models and Foundation Models — 동향 요약

### 보안 특화 모델 등장
공격·방어 역량을 갖춘 모델이 승인 기반으로 공급되기 시작해, 기업 보안 점검에 AI를 쓰는 조건 설계가 과제가 됐다.

### 모델 신뢰성 검증
모델 바꿔치기 검증 기술과 은밀한 성능 저하 사례가 함께 나와, 공급사 감사와 과제별 검증이 중요해졌다.

### 기업 매출 중심 이동
모델사 매출의 과반이 기업 고객에서 나오며, 코딩·업무 영역 경쟁이 도입 기업의 협상력을 바꾸고 있다.

### 데이터 비용과 생성 단가
뉴스 라이선스 계약과 영상 생성 단가 인하가 맞물려, 데이터 비용은 오르고 생성 단가는 내려가는 구조가 형성된다.
