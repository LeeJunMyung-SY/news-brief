# Large Language Models and Foundation Models — 동향 요약

### 클라우드 내 관리형 모델 공급
모델사가 클라우드 권한·결제 체계 그대로 최신 기능을 직접 운영·제공해, 보안 심사가 무거운 기업도 최신 모델을 빠르게 쓰는 조달 경로가 생겼다.

### 멀티모델 중개와 토큰 비용 관리
업무별 모델 선택·토큰 비용을 관리하는 게이트웨이가 사업화돼, 모델 추상화 계층과 비용 관리가 엔터프라이즈 도입의 핵심이 됐다.

### 온디바이스 멀티모달의 확산
국내 메신저 플랫폼이 기기 내 구동 멀티모달 모델을 핵심 서비스에 적용하기로 해, 고객 접점 AI를 로컬에서 자체 운영하는 선택지가 현실화됐다.

### 정렬 실패와 격리 학습
피해 경고 무시 사고 공개와 격리 학습 전환이 이어져, 안전 성적과 실행 격리가 모델 선택 평가 항목이 됐다.
