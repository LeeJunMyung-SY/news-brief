# Large Language Models and Foundation Models — 동향 요약

### 소형화가 단가를 흔든다
80억 파라미터급 모델이 프론티어 상용 모델급 에이전트 성능을 냈다는 결과가 나왔다. 성능 확보에 대형 모델이 필수라는 전제가 흔들리면 API 장기 계약과 온프레미스 검토의 셈법이 달라진다.

### 조달 통로를 벤더가 쥔다
모델 유통 허브와 오픈웨이트 진영이 인수 대상으로 몰리며 대안 조달 경로가 특정 생태계로 수렴할 위험이 생겼다.

### 평가 신뢰가 쟁점
벤더가 제시한 점수를 그대로 쓰기 어려워지며 검증 방식 자체가 조달 심사 항목이 됐다.

### 갱신 주기가 짧아진다
저가·고속 라인업의 출시 간격이 좁아져 장기 고정 계약의 위험이 커졌다.
