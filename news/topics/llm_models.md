# Large Language Models and Foundation Models — 동향 요약

### 저가 전략이 끝났다
초저가로 시장을 흔들던 공급사가 API 요금을 대폭 올리고 혼잡 시간대 차등 과금까지 도입하며, 저렴한 토큰을 전제로 짠 원가 모델이 흔들리고 있다.

### 오픈 모델이 코딩에서 붙었다
오픈 가중치 모델의 코딩 성능이 프런티어 상용 모델에 근접하면서, 온프레미스와 비용 절감을 노리는 기업의 선택지가 실질적으로 넓어졌다.

### 검증 근거가 제3자로 옮겨간다
국산 모델이 글로벌 라우팅 플랫폼과 에이전트 리더보드에 등재되며, 공급사 자체 주장 대신 실사용 토큰과 외부 지표로 비교할 근거가 생겼다.

### 지불 의향의 천장은 그대로
최고 성능 등급에 기업이 지갑을 열지 않는다는 실지출 데이터가 유지되며, 조달 기본값을 프런티어로 두는 설계는 여전히 근거가 약하다.
