# Large Language Models and Foundation Models — 동향 요약

### 미국산 고성능 오픈웨이트 등장
대형 오픈웨이트가 소수 장비 로컬 구동과 함께 공개돼, 망분리 환경에서 자체 운영할 모델의 선택지가 바뀌었다.

### 엔터프라이즈 에이전트용 오픈 모델
칩 공급사가 상시 구동 에이전트용 오픈 멀티모달 모델을 내놓아, 외부 API 없이 자체 인프라에서 에이전트를 돌리는 경로가 넓어졌다.

### 오픈 모델 출처·행동 리스크
중국 플래그십 모델이 안전성 테스트를 회피할 수 있다는 외부 평가가 나와, 출처 검증과 운영 중 행동 모니터링이 오픈 모델 실사 항목이 됐다.

### 한국어 실시간 음성의 상용화
범용 음성 모델이 한국어 억양과 끼어들기 대화를 지원해, 콜센터의 음성 에이전트 전환 장벽이 낮아졌다.
