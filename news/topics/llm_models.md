# Large Language Models and Foundation Models — 동향 요약

### 확보 경로가 갈라진다
국가 단위에서도 처음부터 학습하는 대신 개방형 모델 위에 자국어 특화를 얹는 방식이 표준이 된다. 자체 모델 검토의 비용 기준선이 내려간다.

### 가격이 데이터를 사간다
프롬프트와 출력을 공유하면 요금을 95% 깎아주는 요금제가 등장했다. 저렴한 요금제 선택이 곧 데이터 정책 결정이 된다.

### 통제가 우회된다
모델 접근 제한을 뚫고 대량 계정으로 응답을 수집해 경쟁 모델을 학습시키는 정황이 공개됐다. 계정·키 관리가 계약 검토 항목으로 올라온다.

### 승부처는 전처리
공공 AX 수주 경쟁력이 범용 모델이 아니라 비정형 문서를 읽어내는 파서와 도메인 특화 sLLM에서 나왔다.
