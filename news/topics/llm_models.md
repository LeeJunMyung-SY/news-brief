# Large Language Models and Foundation Models — 동향 요약

### 최상위 모델의 제한 출시
성능 선두 모델이 보안 파트너에게만 먼저 열리는 방식이 굳었지만 공급사별 기준은 제각각이어서, 최신 모델 접근 시점이 도입 일정의 변수가 됐다.

### 산업 특화 모델의 공동 개발
범용 모델에 도메인 기업의 기술을 결합한 전용 모델을 수익 공유 방식으로 만드는 사례가 나와, 특화 모델 확보 경로가 구매에서 제휴로 넓어졌다.

### 벤치마크와 실무의 괴리
최상위 모델조차 실무 코딩 안정성에 의문이 제기돼, 공개 점수가 아닌 자사 업무 기반 평가셋으로 모델을 골라야 할 필요가 커졌다.

### 경량 모델과 국내 리전
대형·경량 이원화와 최신 모델의 국내 리전 제공으로, 반복 업무는 소형 모델에 맡기고 규제 업무는 국내 리전을 쓰는 조합 설계가 현실화됐다.
