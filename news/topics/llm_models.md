# Large Language Models and Foundation Models — 동향 요약

### 사용량 기반 과금의 변동성
통합 사용량 한도 체계에서 과금 수정만으로 한도가 크게 줄어, 기업은 모델 비용의 예측 가능성을 계약으로 확보해야 한다.

### 중국 모델 공급 둔화
칩 통제와 증류 차단으로 중국 대표 모델의 출시 주기가 길어져, 오픈웨이트 기반 서비스의 업데이트 리스크가 커졌다.

### 오픈 기반 특화 모델
오픈웨이트에 강화학습만 얹은 코딩·보안 특화 모델이 상용 성능을 입증해, 기업의 특화 모델 구축 선택지가 넓어졌다.

### 엔터프라이즈 신뢰 경쟁
데이터 비열람 추론과 공급사 안전 철학 논쟁이 이어져, 보안·통제 보장이 모델 선택 기준으로 자리 잡았다.
