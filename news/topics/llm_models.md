# Large Language Models and Foundation Models — 동향 요약

### 도메인 특화가 차별점
범용 성능 경쟁과 별개로 업무 데이터를 사후학습한 수직 모델이 실제 제품으로 나오기 시작했다. 정형 데이터 전용 모델이 빅테크를 앞선 사례도 나왔다.

### 생성하지 않는 모델
텍스트 없이 판정만 내려 지연과 원가를 극단적으로 낮추는 접근이 등장했다. 대량 반복 판단 업무의 선택지가 넓어진다.

### 모델 교체 자유가 계약 쟁점
개발도구에 타사 모델을 연결하는 사용이 늘며 락인 여부가 조달 검토 항목으로 올라왔다.

### 공급사 재무가 평가 항목
선두 모델사의 상장 지연과 대규모 조달이 이어지며 재무 실사가 모델 선택에 포함된다.
