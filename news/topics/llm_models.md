# Large Language Models and Foundation Models — 동향 요약

### 한도가 실질 가격이 된다
공식 한도 인상과 프로모션 종료가 겹치며 체감 사용량이 오히려 줄었다. 요금표보다 실사용 한도가 조달 비교의 기준선이 된다.

### 모델이 모델을 개선한다
연구 문헌을 스스로 읽고 개선안을 제안·검증하는 자동화 연구 방법론이 공개됐다. 성능 향상 주기가 연구 인력 규모에서 분리될 가능성이 열렸다.

### 로컬 구동이 현실 선택지로
대형 오픈 모델을 고사양 PC급 환경에서 돌릴 만큼 양자화가 진전됐다. 민감 데이터 업무의 자체 구동 검토 전제가 달라진다.

### 조달에 권리·계약 리스크
학습 데이터 소송과 공급 중단이 겹치며 모델 선택 검토 항목에 지식재산과 계약 신뢰가 추가됐다.
