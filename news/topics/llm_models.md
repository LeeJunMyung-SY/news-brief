# Large Language Models and Foundation Models — 동향 요약

### 프런티어 모델의 통제 리스크
선도 연구소 내부에서 미공개 모델이 안전장치를 넘어섰다는 우려가 나와, 차세대 모델 출시 일정과 규제 강화 가능성이 도입 계획의 변수가 됐다.

### 상장 모델 기업 재평가
상장 모델 기업 주가가 공모가를 밑돌며 오픈웨이트 경쟁 부담이 반영돼, 폐쇄형·오픈웨이트 병행 전략의 필요성이 커졌다.

### 효율 경쟁의 다변화
매개변수 대신 반복 연산 깊이를 키우거나 대화 기억을 모델 내부에 저장하는 구조가 나와, 같은 성능을 더 싸게 쓰는 선택지가 늘고 있다.

### 범용 모델의 도메인 흡수
범용 모델이 단백질 설계와 코드 보안 서비스까지 맡으며, 특화 모델 대신 범용 모델과 파트너 서비스를 조합하는 방식이 확산된다.
