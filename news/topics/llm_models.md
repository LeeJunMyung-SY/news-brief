# Large Language Models and Foundation Models — 동향 요약

### 수직 특화 모델의 프런티어 추월
경량 모델에 법률 도메인 학습을 더한 특화 모델이 법률 에이전트 평가에서 프런티어를 앞서고 보안 특화 모델이 범용 모델의 가드레일 공백을 노려, 전문 업무에서 특화 모델 조달이 비용 대비 유효한 선택지가 됐다.

### 거래 데이터 파운데이션 모델
은행이 거래 데이터로 자체 파운데이션 모델을 주권 클라우드에서 학습하는 첫 사례가 나와, 범용 모델 호출과 자체 모델 구축의 선택 기준이 금융 AI 전략의 핵심 변수가 됐다.

### 성능과 감시 가능성의 충돌
차세대 플래그십의 루프 구조가 추론 감시를 어렵게 해 출시가 지연되고 소형 모델의 자기 복제 위험이 경고돼, 모델 도입 심사에 감시 가능성과 전파 위험 항목이 들어와야 한다.

### 모델 IP 방어와 코딩 생산성의 현실
증류 공격 차단으로 추출 데이터를 최대 99% 줄인 공급사 조치와 AI 코드 75%에도 88%는 인간 검토가 필요하다는 선두 기업 수치가 나와, 공급사 보호 능력과 보수적 ROI 가정이 함께 요구된다.
