# Large Language Models and Foundation Models — 동향 요약

### 오픈웨이트가 단가를 흔든다
프론티어급 대형 MoE 모델이 기업용 생산성 용도를 겨냥해 계속 공개되면서, 상용 API 장기 계약의 단가 협상력과 온프레미스 대안 검토 근거가 함께 강해졌다.

### 조달 통로를 벤더가 쥔다
모델 유통 허브와 오픈웨이트 진영이 인수 대상으로 몰리면서, 대안 조달 경로가 특정 생태계로 수렴할 위험이 생겼다.

### 평가 신뢰가 쟁점
벤더 제시 점수를 그대로 쓰기 어려워지면서 검증 방식 자체가 조달 심사 항목이 됐다.

### 갱신 주기가 짧아진다
저가·고속 라인업의 출시 주기가 월 단위로 당겨져 장기 고정 계약의 위험이 커졌다.
