# Large Language Models and Foundation Models — 동향 요약

### 능력이 배포 범위를 정한다
사이버 공격 능력이 임계치를 넘은 모델은 기능 일부를 잠근 채 출시된다. 조달 시 '어떤 기능이 열리는가'가 성능만큼 중요해졌다.

### 가격이 경쟁 변수로
캐시 읽기 가격을 대폭 낮춘 신모델이 나오며 성능 경쟁이 단가 경쟁과 함께 움직인다. 총소유비용 기준의 재비교가 필요하다.

### 표시 의무가 API로 구현
AI 생성 텍스트 워터마크 검증이 상용 API 형태로 열렸다. 콘텐츠를 생성·유통하는 조직은 검증 경로를 컴플라이언스에 편입해야 한다.

### 국가가 프론티어에 베팅
독자 모델 단계를 넘어 최상위 모델 확보가 정책 목표로 상향되며 조달 선택지의 구성이 달라진다.
