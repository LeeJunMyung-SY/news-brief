# Large Language Models and Foundation Models — 동향 요약

### 국산 모델에 공통 잣대가 생겼다
국가 독자 모델 프로젝트 참여사들의 외부 벤치마크 점수가 동시에 공개되며, 공급사 자체 발표가 아닌 제3자 지표로 비교할 근거가 처음 마련됐다.

### 후발주자가 순위를 뒤집는다
뒤늦게 합류한 개발사가 첫 공식 평가에서 국내 최고 점수를 기록하며, 선점 효과보다 최근 학습 전략이 성능을 가른다는 점이 드러났다.

### 개선의 축은 에이전트와 장기 맥락
주요 국산 모델의 점수 상승이 에이전트 작업과 장기 컨텍스트 영역에 집중되며, 평가 기준 자체가 대화 품질에서 업무 완수로 이동했다.

### 성능이 아니라 단가가 가른다
최상위권에 근접한 모델이 낮은 가격으로 잇따라 나오며 조달 협상의 기준선이 성능 비교에서 단가로 옮겨갔다.
