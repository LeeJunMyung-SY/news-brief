# Large Language Models and Foundation Models — 동향 요약

### 개방 노선의 재부상
최상위 성능 모델까지 가중치를 여는 흐름이 국가 경쟁 논리와 결합해 되살아났다. 폐쇄형 API 단일 전제의 아키텍처는 유효기간이 더 짧아졌다.

### 소비자 하드웨어로 내려온 성능
압축 시 20GB 미만으로 도는 에이전트 모델이 등장하며 민감 데이터 업무의 자체 호스팅이 현실 선택지가 됐다.

### 역량 등급이 배포를 제약한다
사이버 역량이 임계에 닿은 모델은 자격 심사 채널로만 열린다. 성능이 곧 접근 가능성은 아니게 됐다.

### 평가 기준의 재정의
벤더 자체 벤치마크와 실사용 체감의 괴리가 공개 쟁점이 되며 조달 기준도 흔들리고 있다.
