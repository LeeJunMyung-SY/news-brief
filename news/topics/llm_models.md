# Large Language Models and Foundation Models — 동향 요약

### 비용 비교 기준이 뒤집혔다
토큰 단가가 비싼 모델이 작업 완료 기준으로는 더 저렴할 수 있다는 분석이 나왔다. 단가표 비교는 조달 오판을 부른다.

### 국가가 직접 만든다
대규모 공적 자금을 단일 법인에 집중해 최상위 모델을 확보하려는 전략이 실행 단계로 들어섰다. 분산 지원 기조가 폐기됐다.

### 도메인 특화가 표준이 된다
범용 모델 구독 대신 자사 데이터로 전용 모델을 만드는 방식이 대기업 조달의 기본형으로 자리 잡는다.

### 능력이 인증을 넘어선다
화면 조작 능력이 기존 봇 차단 체계를 무력화하며 서비스 인증 설계를 다시 보게 만든다.
