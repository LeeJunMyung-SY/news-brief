# Large Language Models and Foundation Models — 동향 요약

### 미국산 고성능 오픈웨이트 등장
8160억 매개변수 오픈웨이트가 맥 2대 로컬 구동과 함께 공개돼, 중국 오픈 모델 보안 경고가 커지는 시점에 망분리 환경 자체 운영 모델의 선택지가 바뀌었다.

### 엔터프라이즈 에이전트용 오픈 모델
칩 공급사가 상시 구동 에이전트용 1200억 오픈 멀티모달 모델과 로컬 소형 모델을 내놓아, 외부 API 없이 자체 인프라에서 에이전트를 돌리는 경로가 넓어졌다.

### 오픈 모델 출처의 리스크화
미국 프런티어 랩이 중국 오픈 모델의 통제 난점을 공개 경고해, 저비용 오픈 모델 채택 시 출처와 보안 검증이 벤더 실사 항목이 됐다.

### 작업당 단가의 급락
프런티어 모델이 미공개 물리 연구 문제를 건당 2.4달러에 풀고 음성 모델은 고객센터 해결률과 비용으로 경쟁해, 고난도 작업의 단위 비용 구조가 재편되고 있다.
