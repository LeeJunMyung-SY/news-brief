# Large Language Models and Foundation Models — 동향 요약

### 주권형 오픈 모델의 부상
유럽·미국에서 대형 오픈 웨이트 모델이 잇따라 나오고 한국도 지분투자형 프런티어 육성에 나서, 중국산 외 자체 호스팅 선택지가 넓어졌다.

### 모델 정책이 조달 기준으로
보안 업무 수행 가능성을 차별점으로 내세운 모델이 등장해, 거부 범위 등 모델 정책이 단가·성능과 함께 조달 비교 항목이 됐다.

### 경량·특화 모델의 가성비
온디바이스 임베딩과 저가 이미지 모델이 상위 모델을 따라잡는 주기가 짧아져, 용도별 소형 특화 모델 조합이 비용 전략의 핵심이 됐다.

### 무료 접근 축소와 단가 재평가
무료 티어 축소로 소비자 접점 과금이 강화되는 한편 지능 단가는 계속 떨어져, 짧은 주기의 모델·요금 재평가가 필요하다.
