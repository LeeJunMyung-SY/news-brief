# Large Language Models and Foundation Models — 동향 요약

### 월 단위 모델 교체 주기
주요 연구소가 한 달 새 여러 프런티어 모델을 내놓으며, 교체 가능한 멀티모델 구조가 조달 기준이 됐다.

### 빅테크의 자체 모델화
플랫폼 기업이 외부 모델을 저가 자체 모델로 대체해, 추론 시장이 가격 비교형으로 바뀌고 있다.

### 증류를 통한 역량 유출
우회 접근으로 확보한 상위 모델 출력을 증류에 쓰는 시장이 형성돼, API 접근 통제가 모델사의 핵심 방어 과제가 됐다.

### 용도 제한의 취약성
상용 모델의 안전장치가 단순 프레이밍으로 뚫린다는 평가가 나와, 출력 통제와 독립 검증이 신뢰의 기준이 됐다.
