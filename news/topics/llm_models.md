# Large Language Models and Foundation Models — 동향 요약

### 모델 공급의 다변화
기업용 모델사까지 경쟁 모델을 호스팅하기 시작해, 선택의 축이 단일 모델 성능에서 안전한 다중 모델 운영으로 옮겨간다.

### 안전의 학습 단계 편입
공격 데이터를 학습에서 제한한 모델이 나와, 오남용 대응이 출시 후 필터에서 설계 단계로 앞당겨지고 있다.

### 콘텐츠 기능의 실무화
이미지 생성 속도와 편집이 개선되며, 마케팅 제작의 내재화 범위와 저작권 검토 부담이 함께 커진다.

### 공급사 실사의 확대
위험 공시와 보안 논란이 이어져, 모델 선택 기준이 성능에서 공급사 거버넌스로 넓어지고 있다.
