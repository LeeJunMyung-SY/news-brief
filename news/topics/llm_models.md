# Large Language Models and Foundation Models — 동향 요약

### 증명 책임이 벤더로
최상위 모델 출시에서 성능 수치보다 안전 검증 자료가 앞자리에 놓였다. 도입 심사에서 시스템 카드가 표준 제출물이 되어간다.

### 벤치마크가 갈린다
같은 모델을 두고 주요 평가기관의 결론이 정반대로 나왔다. 공개 점수만으로 모델을 고르는 방식의 유효기간이 끝나간다.

### 확보 경로가 열린다
가중치를 넘어 학습 데이터와 레시피까지 공개한 모델군이 나왔다. 근거 제시가 요구되는 업권의 자체 모델 검토 문턱이 내려간다.

### 가격이 데이터를 산다
데이터 제공 동의를 대가로 요금을 대폭 깎는 구조가 굳어진다. 요금제 선택이 곧 데이터 정책 결정이 된다.
