# Large Language Models and Foundation Models — 동향 요약

### 기본 모델의 실사용 도약
범용 챗봇 기본 모델의 이미지 이해·지시 수행 성능이 크게 올라, 문서·이미지 기반 일상 업무의 활용 폭이 넓어졌다.

### 모델 교체 주기의 단축
현재·차기 모델을 동시 개발하며 몇 주 만에 성능 순위가 바뀌어, 특정 모델 종속보다 교체 가능한 구조가 중요해졌다.

### 범용 모델의 영역 확장
범용 모델이 별도 학습 없이 로봇 제어까지 맡기 시작해, 전용 모델 개발 비용 구조가 흔들리고 있다.

### 능력 측정과 안전 규범
검증 가능한 증명 능력과 지능 지표 공개가 이어지며, 성능 측정이 개발 속도 조절의 기준으로 쓰이고 있다.
