# Large Language Models and Foundation Models — 동향 요약

### 실행형 통합 AI의 등장
국내 컨소시엄의 실행형 소비자 AI 베타와 그룹 자체 LLM의 주거 서비스 탑재처럼, 모델 경쟁이 성능 지표에서 실제 서비스 실행과 계열사 확산으로 옮겨가고 있다.

### 주권형 오픈 모델의 부상
유럽·미국의 대형 오픈 웨이트 모델과 한국의 지분투자형 프런티어 육성으로, 중국산 외 자체 호스팅 선택지가 넓어졌다.

### 특화 모델의 데이터 병목 공략
로봇 학습 영상을 구조화하는 비전언어모델처럼 용도 특화 모델이 데이터 가공 병목을 겨냥해, 소형 특화 모델 조합이 비용 전략의 핵심이 됐다.

### 모델 정책과 단가 재평가
보안 업무 수행 가능성 등 모델 정책이 조달 비교 항목이 되고 지능 단가는 계속 떨어져, 짧은 주기의 모델·요금 재평가가 필요하다.
