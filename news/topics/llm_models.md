# Large Language Models and Foundation Models — 동향 요약

### 비용이 모델 선택을 바꾼다
폐쇄형 최상위 모델의 토큰 비용 부담에 기업들이 오픈웨이트 모델을 검토하며, 업무별 모델 조합이 원가 관리의 핵심이 됐다.

### 최상위 모델, 안전에 제동
선두 모델사가 안전 사고로 최상위 모델 학습을 멈추고 차세대에 집중하며, 공급사 로드맵이 세대 단위 리스크가 됐다.

### 가격 계층의 분화
최상위 요금제 신설과 경량·무료 모델 공개가 동시에 진행되며, 고성능 구독과 저가 특화 모델 조합이 도입 전략의 기본이 됐다.

### 개발자 모델 경쟁 가속
주요 모델사가 개발자 행사를 앞두고 신모델 출시를 앞당기며 교체 주기가 짧아져, 특정 모델에 묶이지 않는 구조가 중요해졌다.
