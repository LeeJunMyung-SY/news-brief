# Large Language Models and Foundation Models — 동향 요약

### 지불 의향의 천장
최고 성능 모델에 기업이 지갑을 열지 않는다는 실지출 데이터가 나오며, 조달의 기본값을 프런티어 등급으로 두는 설계가 근거를 잃었다.

### 저가 세대교체가 몇 주 단위로
가성비 모델의 교체 주기가 짧아지고 할인 폭도 커지면서, 다년 단가 계약보다 재협상 여지를 남기는 방식이 유리해졌다.

### 오픈웨이트도 값을 올린다
저가 공세를 이끌던 진영이 API 단가를 인상하기 시작해, 오픈 모델 기반 원가 절감 전략의 지속성을 다시 따져야 하는 국면이다.

### 구동 문턱이 조달 변수로
경량화와 추론 가속으로 온프레미스 구동 요건이 낮아지면서, 성능 점수보다 자사 장비에서 실제로 돌아가는지가 선택 기준으로 올라섰다.
