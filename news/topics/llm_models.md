# Large Language Models and Foundation Models — 동향 요약

### 가격 지속성과 추론 비용
선두 모델사 손실 공개에 이어 중국 모델사가 운영용 추론 프레임워크를 오픈소스로 풀어, 추론 원가 절감이 모델 경쟁의 전선이 됐다.

### 국산 오픈모델 확산
게임사가 한국어·에이전트 특화 30B MoE 모델을 상업 이용 가능 라이선스로 공개하고 비전 인코더도 개방돼, 국내 기업의 자체 운용 선택지가 넓어졌다.

### 모델 공급망 진영화
중국 모델의 자국 칩 지원이 추론 단계까지 확대되고 미국의 원산지 규제가 이어져, 기반 모델 출처 확인이 조달 실사의 기본 항목이 됐다.

### 특화 모델 조합
금융 문서 추출·다국어 파이프라인 재사용성 연구가 이어져, 범용 LLM 단일 의존 대신 업무별 특화 모델 조합이 원가·정확도 해법으로 자리잡고 있다.
