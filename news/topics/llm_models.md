# Large Language Models and Foundation Models — 동향 요약

### 성능·가격 동시 압박
최상위 모델이 1위를 탈환하면서 API 가격을 인하해, 모델 경쟁이 성능 우위에서 비용 경쟁력까지 동시에 요구하는 국면에 들어섰다.

### 에이전트용 소형 모델 계층화
반복 작업 전용 초저가 소형 모델이 등장해, 작업 유형별로 모델을 나눠 쓰는 계층 설계가 에이전트 운영비를 좌우하게 됐다.

### 국산 모델의 투자 유치와 개방
글로벌 칩 기업이 국내 독자 모델에 직접 투자하고 API 무료 개방이 이어져, 데이터 주권이 중요한 영역의 국산 선택지가 넓어진다.

### 벤치마크 해석의 한계
중국 모델의 추격 주장에도 선두사의 미공개 모델이 있어, 공개 점수만으로 모델을 고르는 조달 방식의 위험이 커졌다.
