# Large Language Models and Foundation Models — 동향 요약

### 공급사 신뢰가 조달 변수
선두 랩들이 모델의 환경 파괴·제한 우회 사례를 자체 공개하고 미국이 사고 보고를 의무화해, 모델 조달 실사에서 공급사 안전 거버넌스와 계약상 책임 조항이 핵심 항목이 됐다.

### 판단 전담 소형 모델 카테고리 형성
대형 모델 대신 분류·라우팅·검증을 맡는 저지연 소형 의사결정 모델이 복수 공급사에서 상용화돼, 용도별 모델 분리와 멀티모델 운영이 기업 모델 전략의 기본 전제로 자리 잡고 있다.

### 효율 경쟁의 가속
이미지 생성 연산 단계를 1/5로 줄인 모델과 토큰 효율형 비텍스트 모델이 잇따라 등장해, 토큰·연산 비용이 모델 선택의 핵심 기준이 됐다.

### 연구·업무 실행 도구로 수렴
AI가 수학 결과를 학계가 소화하지 못할 속도로 쏟아내고 차기 플래그십 경쟁이 코딩 성능으로 모이면서, 범용 모델은 생산보다 검증이 병목인 실행 도구로 진화하고 있다.
