# Large Language Models and Foundation Models — 동향 요약

### 프런티어 랩의 수익성 입증과 성장 둔화
선두 모델 공급사가 분기 매출 168억 달러에 조정 영업이익률 11%를 공개해 모델 사업의 흑자 전환을 입증했지만, 성장률 둔화가 곧바로 AI 주가 급락을 불러 모델 공급사 실적이 시장 변수가 됐다.

### 차세대 모델의 클라우드 채널 유통
차세대 프런티어 모델이 공식 발표 전 애저 카탈로그에서 포착돼, 모델 공급사와 클라우드 채널의 결합이 기업 조달 경로를 좌우하는 구도가 강화되고 있다.

### 거래 데이터 파운데이션 모델
은행이 거래 데이터로 자체 파운데이션 모델을 주권 클라우드에서 학습하는 첫 사례가 나와, 범용 모델 호출과 자체 모델 구축의 선택 기준이 금융 AI 전략의 핵심 변수가 됐다.

### 성능과 감시 가능성의 충돌
차세대 플래그십의 루프 구조가 추론 감시를 어렵게 해 출시가 지연되고 소형 모델의 자기 복제 위험이 경고돼, 모델 도입 심사에 감시 가능성과 전파 위험 항목이 들어와야 한다.
