# Large Language Models and Foundation Models — 동향 요약

### 업무 특화가 주류로
오픈웨이트 모델을 업무별로 사후학습해 프론티어급에 근접하면서 비용은 절반 이하로 낮추는 사례가 잇따른다. 모델 조달 기준이 '최상위 하나'에서 '업무별 최적'으로 옮겨간다.

### 음성 단가의 급락
실시간 음성 모델이 시간당 1달러대로 내려오며 상담 자동화의 손익분기가 근본적으로 달라진다.

### 데이터 통제가 선택 기준
로그 보관 정책 하나로 대형 고객이 최상위 모델을 철회했다. 성능보다 데이터 거버넌스가 조달을 좌우한다.

### 자체 개발의 현실적 한계
애플조차 외부 모델을 채택하며 모델 내재화의 난이도가 드러났다.
