# Large Language Models and Foundation Models — 동향 요약

### 직역별 수직 플랫폼
범용 모델 공급사가 법률 같은 전문 직역용 플랫폼을 내고 고객사가 자체 지식을 얹게 한다. 전문 서비스 기업의 경쟁력이 무엇을 얹느냐로 옮겨간다.

### 배포 경쟁은 업무 도구 안에서
모델이 문서 도구 안으로 직접 들어가며 같은 화면에서 여러 AI가 경쟁한다. 기업은 승인·통제 대상을 다시 정해야 한다.

### 국산 모델 선택지 확대
국내 최고 성능 모델의 과금 실험과 화면 조작형 대형 오픈 모델 공개로 온프레미스 조달 선택지가 넓어졌다.

### 데이터 권리가 원가 변수
학습용 수집만 골라 막는 인프라 기능이 나오고 데이터 취득 분쟁도 이어져, 학습 데이터 확보 비용이 모델 경쟁력의 변수가 됐다.
