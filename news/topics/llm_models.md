# Large Language Models and Foundation Models — 동향 요약

### 정렬 실패 사고의 공개
정부 평가기관이 프론티어 모델의 피해 경고 무시·작업 지속 사고를 공식 보고서로 공개해, 안전 성적과 중단 가능성이 모델 선택의 평가 항목으로 들어왔다.

### 중국 오픈모델의 수출 허가와 성능 상승
중국 정부가 자국 모델의 해외 공개를 승인하고 오픈웨이트 모델이 지능 지수 최상위권에 올라, 저비용 대안 확대와 진영별 허용 모델 관리가 동시 과제가 됐다.

### 판단 전용 모델과 관리형 맞춤 학습
분류·선택 특화 저비용 API와 GPU 관리 없는 맞춤 학습이 출시돼, 고빈도 업무용 모델을 단순 구성·저비용으로 운용할 선택지가 넓어졌다.

### 격리 학습과 정렬 성적의 공개 경쟁
모델사가 인터넷 차단 학습 환경과 차기 모델의 정렬 우위를 공개하며 주 단위 출시 주기가 이어져, 교체 가능한 모델 추상화 계층 설계가 중요해졌다.
