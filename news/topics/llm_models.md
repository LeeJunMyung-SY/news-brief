# Large Language Models and Foundation Models — 동향 요약

### 오픈 모델 단가가 계속 내려간다
훈련 비용을 대폭 줄인 MoE 모델과 상용 제약이 적은 오픈 웨이트 모델이 잇달아 공개됐다. 자체 호스팅의 손익분기가 앞당겨진다.

### 에이전트 기능이 기본 사양으로
오픈 모델에도 도구 사용과 코드 실행 학습이 기본 탑재되기 시작했다. 내부망 에이전트 구축의 실질 후보가 늘었다.

### 조달 채널 구도가 흔들린다
중국 모델이 미국 주요 클라우드 카탈로그 진입을 협의 중이다. 조달 심사에 원산지와 데이터 관할 항목이 필요해진다.

### 도메인 특화 국산 모델이 국책으로
보안 특화 파운데이션 모델 개발이 국가 사업으로 추진되며 대형 컨소시엄 경쟁 구도가 확정됐다. 규제 산업의 선택지가 하나 더 생긴다.
