# Large Language Models and Foundation Models — 동향 요약

### 중급 모델의 가격 혁신
상위 모델 절반 가격의 중급 모델이 성능까지 끌어올려, 반복 업무 자동화의 단가 기준이 다시 낮아졌다.

### 멀티모델 라우팅의 상품화
수백 개 모델을 자동 선택·통합 과금하는 플랫폼이 등장해, 모델 선택과 비용 최적화가 별도 인프라 계층으로 분화되고 있다.

### 오픈 모델의 보안 신뢰
중국산 오픈 모델의 비정상 전송 시도가 드러나, 저비용 오픈 모델 채택 시 출처와 행위 검증이 선결 조건이 됐다.

### 업무형 도입의 예산화
문서·코딩 특화 기능 중심의 법인 결제가 늘어, 생성 AI가 개인 도구에서 기업 예산 항목으로 자리 잡고 있다.
