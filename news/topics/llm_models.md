# Large Language Models and Foundation Models — 동향 요약

### 멀티모델 유통 플랫폼 경쟁
통신사가 국내 리전 모델을 한 플랫폼에서 원화 과금·할인으로 공급해, 모델 선택권과 데이터 주권이 국내 유통 경쟁의 축이 되고 있다.

### 오픈웨이트의 보안 시장 진입
프런티어급 모델이 가중치 공개와 함께 보안 업무를 겨냥해, 외부 API 없이 내부망에서 운영하는 도입 경로가 넓어졌다.

### 용량 경쟁으로 번진 가격전
공급사가 같은 요금에 처리량을 두 배로 늘리며, 기업 계약의 경쟁 축이 단가에서 사용량 한도로 이동했다.

### 수주 단위 교체와 평가 불안정
1위 모델과 평가 순위가 수주 단위로 바뀌어, 교체 가능한 구조와 자체 업무 기반 평가 체계가 중요해졌다.
