# Large Language Models and Foundation Models — 동향 요약

### 성능 수렴, 단가 경쟁
프런티어 모델이 성능 격차를 좁히며 API 인하와 토큰 효율로 경쟁해, 조달 기준이 단가·작업당 비용으로 이동했다.

### 판단 특화 모델 부상
반복 판단을 LLM 대신 경량 결정 모델로 처리하는 설계가 등장해, 에이전트 운영비 구조가 근본적으로 바뀔 수 있다.

### 빅테크의 자체 모델화
플랫폼 기업이 외부 모델 의존을 줄이고 자체 코딩·보안 모델을 저가로 내놓아, 공급사 협상 구도가 재편된다.

### 출력 보호와 안전 검증
중국의 증류 산업화와 해석가능성 기술 쟁탈전이 겹치며, 모델 출력 보호와 내부 검증 능력이 신뢰의 새 기준이 됐다.
