# Large Language Models and Foundation Models — 동향 요약

### 공급사 실사의 확대
상장 서류의 위험 공시와 내부 보안 논란이 함께 나와, 모델 선택 기준이 성능에서 공급사의 거버넌스로 넓어진다.

### 벤치마크 신뢰성 논쟁
평가 방식이 달라지자 미·중 모델 격차 해석이 갈려, 공개 수치보다 자체 업무 기준 평가가 중요해졌다.

### 표시 의무의 시험대
EU 기한을 앞둔 워터마크 대응이 이전 모델에서 우회돼, 규제 준수를 공급사 기능에만 맡기기 어렵다.

### 사용량 시대의 보안
계정 탈취로 단기간에 큰 요금이 발생하는 사례가 나와, API 키 관리가 비용 통제 항목으로 올라섰다.
