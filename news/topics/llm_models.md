# Large Language Models and Foundation Models — 동향 요약

### 최상위 모델의 제한 출시
성능 선두권 신모델이 보안 방어기관 등 신뢰 파트너에게만 먼저 열리며, 최신 모델 접근 자체가 도입 일정의 불확실성이 됐다.

### 공격 능력의 공개 모델 확산
공개 가중치 모델이 최상위 비공개 모델 수준의 공격 코드 작성 능력에 근접해, 접근 제한 중심 안전 전략의 한계가 드러났다.

### 국내 리전 제공으로 장벽 완화
최신 모델이 데이터 국외 반출 없이 국내 리전에서 제공되기 시작해, 규제 산업의 최상위 모델 도입 경로가 열렸다.

### 판단 전용 모델의 부상
생성 대신 선택지 확률만 계산하는 모델이 잇따라 나와, 반복 판단 업무를 대형 모델에서 떼어내 비용을 줄이는 조합이 가능해졌다.
