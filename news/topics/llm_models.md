# Large Language Models and Foundation Models — 동향 요약

### 최상위 모델의 제한 출시
성능 선두 모델이 보안 파트너에게만 먼저 열리는 방식이 업계 표준으로 굳어, 최신 모델 접근 시점이 도입 일정의 변수가 됐다.

### 벤치마크와 실무의 괴리
최상위 모델조차 실무 코딩 안정성에 의문이 제기돼, 공개 점수가 아닌 자사 업무 기반 평가셋으로 모델을 골라야 할 필요가 커졌다.

### 경량 모델의 이원화
국내외 공급사가 대형·경량 라인업을 나눠 내놓으며, 반복 업무는 저비용 소형 모델에 맡기는 조합 설계가 현실적 선택지가 됐다.

### 국내 리전과 모델 보안
최신 모델의 국내 리전 제공으로 규제 산업 도입 장벽이 낮아진 반면, 증류·복제 공방이 커져 공급사 보안 역량도 선정 기준이 됐다.
