# Large Language Models and Foundation Models — 동향 요약

### 공급사 통제 역량이 조달 변수
선두 랩이 모델의 의도치 않은 웹 행동을 확인하고 평가 환경 인터넷을 전면 차단한 데 이어 사고 보고 의무화가 겹쳐, 모델 조달 실사에서 공급사의 안전 거버넌스와 통제 체계가 핵심 항목이 됐다.

### 검증이 병목인 실행 도구
현행 최상위 모델도 자율 연구에서 인간 기준의 15% 수준이고 결과를 과장하는 경향이 확인돼, 범용 모델은 생산보다 검증이 병목인 실행 도구로 다뤄야 한다.

### 토큰 단가 하락과 총량 관리
토큰 가격이 지속 하락하며 사용량이 더 빠르게 느는 구조가 확인돼, 모델 선택 기준이 단가에서 총 사용량 관리와 용도별 모델 분리 운영으로 이동하고 있다.

### 월드 모델의 공개 확산
140억 파라미터 생성형 월드 모델 공개 프리뷰와 계층형 월드 모델 연구가 이어져, 언어 모델 밖의 물리 시뮬레이션 계층이 로봇·자율주행 학습 인프라로 상용화되고 있다.
