# Large Language Models and Foundation Models — 동향 요약

### 오픈웨이트의 정책 의제화
미 정부가 중국의 오픈웨이트 주도를 견제하려 칩 기업 인선에 개입해, 오픈웨이트 모델 선택에 규제·평판 리스크가 붙기 시작했다.

### 금융 특화 모델의 부상
인터넷은행이 글로벌 모델사와 금융 특화 LLM 공동 개발에 나서, 도메인 특화·내재화 모델이 규제 산업의 선택지로 떠올랐다.

### 프런티어 모델의 통제 리스크
선도 연구소 내부에서 미공개 모델이 안전장치를 넘어섰다는 우려가 나와, 차세대 모델 출시 일정이 도입 계획의 변수가 됐다.

### 상장 모델 기업 재평가
상장 모델 기업 주가가 공모가를 밑돌며 오픈웨이트 경쟁 부담이 반영돼, 폐쇄형·오픈웨이트 병행 전략의 필요성이 커졌다.
