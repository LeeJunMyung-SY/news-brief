# Large Language Models and Foundation Models — 동향 요약

### 모델 교체 주기 단축
주요 3사가 한 달 새 10여 개 모델을 낸 뒤 후속작을 동시 준비해, 교체 가능한 멀티모델 구조가 도입의 기본값이 되고 있다.

### 모델 원산지 리스크 확대
특정 중국 모델 기반 서비스까지 공공 조달에서 배제되면서, 기반 모델 출처 확인이 도입 실사의 기본 항목이 됐다.

### 원가 중심 경쟁 심화
프런티어급 성능을 절반 가격에 내는 모델이 이어져 선택 기준이 작업당 원가로 이동했지만, 출처 규제가 제약으로 작용한다.

### 도메인 특화 모델 공동개발
금융지주가 국내 모델 기업에 지분 투자해 금융 특화 모델을 공동개발하기로 해, 산업별 맞춤 모델 수요가 구체화됐다.
