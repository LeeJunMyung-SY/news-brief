# Large Language Models and Foundation Models — 동향 요약

### 증명 책임이 벤더로
최상위 모델 출시에서 성능 수치보다 안전 검증 자료가 앞자리에 놓였다. 도입 심사에서 시스템 카드가 표준 제출물이 된다.

### 모델사의 주주가 겹친다
신생 랩의 대형 라운드를 칩 공급사가 절반씩 채운다. 모델 선택지가 늘어도 자본 구조는 한곳으로 수렴한다.

### 벤치마크가 갈린다
같은 모델을 두고 평가기관의 결론이 정반대로 나온다. 공개 점수만으로 고르는 방식의 유효기간이 끝나간다.

### 가격이 데이터를 산다
데이터 제공 동의를 대가로 요금을 깎는 구조가 굳어진다. 요금제 선택이 곧 데이터 정책 결정이다.
