# Large Language Models and Foundation Models — 동향 요약

### 국산 모델이 지표에 올라섰다
복수의 국내 파운데이션 모델이 국제 종합 지표에서 유의미한 점수를 기록했다. 데이터 반출 제약이 큰 조직에서 대체 검토가 실질적 선택지로 올라온다.

### 성능 격차는 인프라가 만든다
후발 모델 기업이 열위를 인정하며 해법으로 대규모 연산 확충을 제시했다. 모델 선택 시 공급사의 인프라 확보력을 함께 봐야 하는 이유다.

### 개발 도구가 채택 경로
코딩 도구 인수가 모델 경쟁의 수단으로 쓰이고 있다. 개발 환경 점유가 곧 모델 채택으로 이어지는 구조가 굳어진다.

### 명시되지 않는 품질 저하
혼잡 시 작은 모델로 돌리거나 추론을 줄이는 관행이 실제 비용을 줄이지 못한다는 분석이 나왔다. API 조달 시 품질 조항을 따져야 한다.
