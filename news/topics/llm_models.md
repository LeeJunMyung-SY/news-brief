# Large Language Models and Foundation Models — 동향 요약

### 업무 수행이 평가 기준
모델 경쟁의 축이 벤치마크 점수에서 '업무를 끝까지 해내는가'로 옮겨갔다. 컴퓨터 조작 능력이 전면에 배치되며 위임 범위를 다시 그려야 한다.

### 단가는 내리고 배분이 남는다
토큰 값이 떨어지면서 같은 예산으로 처리량을 늘리는 국면이 됐다. 용도별 모델 배분과 라우팅 설계가 실효 비용을 결정한다.

### 속도형 모델의 자리
저지연·저비용 계열이 성능 격차를 좁히며 실시간 응대와 대량 배치의 대안으로 올라섰다.

### 학습 데이터는 계약으로
권리 처리를 사후 소송이 아니라 사전 라이선스로 푸는 재학습 사례가 나왔다. 데이터 조달 단계의 권리 설계가 표준이 된다.
