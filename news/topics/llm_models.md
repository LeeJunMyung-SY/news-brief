# Large Language Models and Foundation Models — 동향 요약

### 모델 조달의 지정학 리스크
중국의 오픈웨이트 수출 통제 추진으로 중국산 모델 자체 운영의 지속성이 정책 변수가 됐다. 모델 출처 다변화가 필요하다.

### 빅테크의 자체 프런티어 확보
클라우드 사업자가 조 단위 파라미터 자체 모델을 내세워 파트너 의존을 줄이면서, 클라우드 생태계의 기본 모델 구도가 바뀔 수 있다.

### 원가 기반 공급사 교체
대형 코딩 플랫폼이 비용을 이유로 모델 공급사를 바꿔, 모델 교체가 가능한 추상화 계층이 도입 기업 협상력의 원천이 됐다.

### 미국산 오픈웨이트와 에이전트 모델
고성능 오픈웨이트와 상시 구동 에이전트용 오픈 모델이 잇따라, 망분리 환경의 자체 운영 선택지가 넓어졌다.
