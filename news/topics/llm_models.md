# Large Language Models and Foundation Models — 동향 요약

### 조달 기준이 가격으로
성능 격차가 좁혀지자 값싼 대안 모델 채택이 빅테크로 번졌다. 단일 벤더 프리미엄이 흔들리며 협상력이 도입 기업 쪽으로 넘어온다.

### 추론 단가가 반토막
토큰 가격이 넉 달 만에 절반으로 떨어졌다. 원가 때문에 접었던 대량 추론 서비스의 손익분기가 다시 계산 대상이 된다.

### 데이터 벽에 부딪힌다
고품질 공개 텍스트 고갈이 가시화되며 경쟁 축이 사후학습·추론 최적화로 이동한다. 차별화 지점이 자체 도메인 데이터로 옮겨간다.

### 특화 모델이 갈라져 나온다
보안 등 도메인 전용 파운데이션 모델이 국가 사업으로 개발된다. 범용 모델 외 조달 선택지가 생긴다.
