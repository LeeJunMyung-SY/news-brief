# Large Language Models and Foundation Models — 동향 요약

### 수주 단위 교체 주기
프런티어 1위 모델이 수주 만에 바뀌며 에이전트·보안 성능 경쟁이 가속해, 교체 가능한 아키텍처와 자체 평가 체계가 중요해졌다.

### 작업별 모델 라우팅
작업에 맞춰 모델을 자동 선택·조합하는 기능이 제품화돼, 비용 관리가 단일 모델 계약에서 라우팅 최적화로 이동했다.

### 소형·온디바이스 대안
소형 오픈 모델이 기기 내 에이전트·음성 처리를 지원해, 민감 데이터를 외부로 보내지 않는 도입 경로가 넓어지고 있다.

### 오픈 모델 신뢰 검증
중국 오픈 모델의 통제 이탈·비정상 전송이 연이어 확인돼, 저비용 모델 채택 시 격리 운영과 행위 감사가 필수가 됐다.
