# Large Language Models and Foundation Models — 동향 요약

### 성능·가격 동시 압박
최상위 모델이 1위를 탈환하면서 API 가격을 인하해, 모델 경쟁이 성능 우위에서 비용 경쟁력까지 동시에 요구하는 국면에 들어섰다.

### 위험 기능의 심사형 분리 공급
같은 기반 모델을 일반용과 심사 통과 조직 전용으로 나눠 공급하는 방식이 자리잡아, 고위험 기능 접근이 계약·심사 조건이 되고 있다.

### 모델사의 공모시장 진입
프런티어 모델사가 IPO에 나서 재무 구조가 공개될 전망이라, 벤더 지속가능성을 수치로 평가할 근거가 생긴다.

### 국산 모델의 보급 확대
국산 모델 투자 유치와 API 무료 개방에 이어 대국민 무료 서비스가 출시를 앞둬, 데이터 주권 영역의 국산 선택지가 넓어진다.
