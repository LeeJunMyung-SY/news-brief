# Large Language Models and Foundation Models — 동향 요약

### 월 단위 모델 교체 주기
주요 연구소가 한 달 새 여러 프런티어 모델을 내놓으며, 교체 가능한 멀티모델 구조가 조달 기준이 됐다.

### 벤치마크와 실사용의 괴리
최상위 신모델이 장기 작업·지시 준수에서 혹평받아, 자사 업무 기반 평가셋이 도입 판단의 기준이 되고 있다.

### 모델 출처의 규제화
미국이 중국산 모델 사용 공개 의무화를 검토하고 증류 암시장도 드러나, 모델 출처 관리가 조달 리스크가 됐다.

### 빅테크의 자체 모델화
플랫폼 기업이 외부 모델을 저가 자체 모델로 대체해, 추론 시장이 가격 비교형으로 바뀌고 있다.
