# Large Language Models and Foundation Models — 동향 요약

### 프런티어 단가 급락
주요 연구소가 최상위 모델을 내놓으며 가격을 40~50% 내렸다. 성능 경쟁이 단가 경쟁으로 옮겨가 사용량 예산과 계약 조건을 다시 볼 시점이다.

### 성능 향상은 둔화
가격은 크게 내렸지만 독립 평가에서 지능 향상폭은 제한적이고, 벤치마크 자체의 결함도 드러났다. 공개 점수보다 자사 업무 기준 평가가 중요해졌다.

### 도메인 특화 국산 모델
정부 사업으로 보안 특화 대형 모델 개발이 시작됐다. 범용 모델 추격 대신 규제·보안 영역 특화가 공공·금융 조달의 대안이 된다.

### 오픈웨이트 추격
중국 오픈 모델이 최상위권에 근접하며 자체 호스팅 선택지가 넓어졌다.
