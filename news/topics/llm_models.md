# Large Language Models and Foundation Models — 동향 요약

### 모델 원산지 리스크 확대
특정 중국 모델 기반 서비스까지 공공 조달에서 배제되면서, 기반 모델 출처 확인이 도입 실사의 기본 항목이 됐다.

### 원가 중심 경쟁 심화
프런티어급 성능을 절반 가격에 내는 모델이 이어져 선택 기준이 작업당 원가로 이동했지만, 출처 규제가 저가 모델 채택의 제약이 된다.

### 온프레미스 오픈 모델
GPU 업체가 기업 자체 구동용 에이전트 모델을 내놔, 데이터 주권 제약 기업의 API 의존 탈피 경로가 넓어졌다.

### 레거시 현대화 수요 공략
COBOL 등 저자원 언어 코딩 강화로, 메인프레임 비중이 큰 금융권 차세대 전환에 AI 활용 여지가 커졌다.
