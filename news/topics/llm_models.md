# Large Language Models and Foundation Models — 동향 요약

### 감속 합의가 출시 주기 변수
선두 개발사들이 속도 조절과 외부 감독에 공감하고 상장 일정까지 늦췄다. 차세대 모델 일정과 조달 로드맵의 불확실성이 커진다.

### 평가 축이 장기 과업으로
최신 모델이 자율 사업 운영 벤치마크에서 경쟁 모델을 크게 앞서고 불법 담합을 거부했다. 성능 비교가 정답률에서 과업 성과와 규범 준수로 옮겨간다.

### 코딩 격차를 돈으로 메운다
코딩 성능이 뒤처진 빅테크가 인재 흡수형 대형 계약으로 추격에 나섰다. 코딩 에이전트가 모델 경쟁의 핵심 전장이다.

### 학습 출처가 조달 리스크
모델 원산지와 학습 출처가 조달 검토 항목으로 자리 잡았다.
