# Large Language Models and Foundation Models — 동향 요약

### 가격이 경쟁 축으로
플래그십 모델까지 정가 절반 수준으로 내려가고 오픈웨이트 모델이 성능 상위권에서 가격까지 낮추면서, 벤더 선택 기준이 성능 우열에서 단가와 계약 조건으로 옮겨가고 있다.

### 데이터 조건이 조달 관문
엔터프라이즈 계약의 차별화 요소가 데이터 무보존과 프라이버시 처리 방식으로 이동했다. 규제 산업의 도입 심사는 성능 평가보다 데이터 취급 조건에서 갈린다.

### 자체 모델은 오픈웨이트 위에
도메인 기업들이 오픈웨이트 모델을 자사 데이터로 다듬어 자체 모델을 갖추는 경로를 택하고 있다. 비용 절감과 차별화를 동시에 해결하는 방식이다.

### 출시 속도는 안전이 정한다
모델 로드맵이 기술 진도가 아니라 안전·보안 준비도에 묶이면서 공급 시점의 불확실성이 커졌다.
