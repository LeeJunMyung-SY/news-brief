# Large Language Models and Foundation Models — 동향 요약

### 통제권이 선택 기준
데이터 보관 위치를 고객 인프라로 옮기는 정책 전환이 시작됐다. 성능 비교보다 데이터 통제 조건이 도입 심사의 앞자리에 온다.

### 국산 모델은 기준 싸움 중
성능 순위보다 어떤 잣대로 지원 대상을 고르느냐가 국산 모델의 판을 정한다. 조달 후보군이 정책 결정으로 좁혀지는 구조다.

### 온디바이스가 전략 축으로
대형 플랫폼이 단말 실행을 승부처로 지목했다. 추론 원가와 개인정보 처리를 동시에 푸는 선택이 모델 규모 설계까지 바꾼다.

### 학습 데이터가 분쟁 지점
파산 자산에서 데이터를 사들이는 시도가 개인정보 권리 다툼에 걸렸다. 데이터 조달 경로 자체가 리스크 항목이 됐다.
