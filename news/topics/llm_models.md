# Large Language Models and Foundation Models — 동향 요약

### 갱신 주기가 몇 주로
상위 모델의 성능 개선판이 3주 간격으로 나오고 차세대 세대 교체도 임박했다. 특정 버전에 업무 프로세스를 고정하기 어려워져 운영 중 모델 교체 정책이 필수가 됐다.

### 규모 대신 추론 연산
모델을 키우는 대신 어려운 문제에 연산을 더 쓰는 방식이 성능 개선의 주된 경로다. 단가표가 아니라 작업당 비용으로 예산을 추정해야 맞는다.

### 능력이 아니라 봉인이 기준
위험 임계치를 넘은 사이버 능력은 기능을 잠근 채 출시된다. 벤치마크 점수가 곧 쓸 수 있는 기능을 뜻하지 않는다.

### 보안 특화 파생 모델
범용 모델에서 갈라져 나온 보안 전용 모델이 별도 제품군을 이루기 시작했다. 국산 파운데이션 모델도 같은 방향으로 움직인다.
