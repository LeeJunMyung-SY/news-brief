# Large Language Models and Foundation Models — 동향 요약

### 결정 전용 모델의 제품화
범용 LLM 대신 빠르고 저렴한 판단 모델이 별도 제품군으로 경쟁에 들어가, 심사·분류 같은 고빈도 업무의 비용 구조를 다시 짤 수 있게 됐다.

### 수직 응용의 성과 원천
의료 진단에서 AI가 의사를 앞선 성과의 대부분이 기저 모델에서 나온 것으로 분석돼, 응용 계층의 차별화는 데이터·워크플로·규제 대응에서 찾아야 함이 확인됐다.

### 모델 공급의 분산과 진영화
AI가 모델을 만드는 소규모 팀과 국내 게임사·유럽 음성 모델이 조달 대안으로 늘고 중국 모델사의 대규모 자본 유입이 겹쳐, 지역별 허용 모델 포트폴리오 관리가 장기 과제가 됐다.

### 모델 유통의 탈종속
프런티어 모델이 경쟁사 클라우드까지 공급되고 SaaS가 자체 이미지 모델을 내재화해, 기존 인프라 계약 안에서 모델을 갈아타는 조달 환경이 굳어지고 있다.
