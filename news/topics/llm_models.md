# Large Language Models and Foundation Models — 동향 요약

### 연구 도구로의 경쟁 이동
주요 연구소가 같은 학술 난제 해결을 연이어 발표하며, 모델 경쟁의 축이 벤치마크 점수에서 과학적 발견 역량으로 옮겨가고 있다.

### 작업별 모델 배분
크기·추론 강도별 선택 기준이 제시되며, 작업에 맞는 모델 배분이 비용 관리의 핵심 실무가 됐다.

### 소형 특화 모델의 약진
소형 모델이 특정 업무에서 프런티어 모델을 앞서, 온프레미스 도메인 모델이 현실적 대안이 되고 있다.

### 오픈 모델의 보안 신뢰
오픈 모델의 비정상 전송이 반복 확인돼, 저비용 모델 채택 시 출처와 행위 검증이 선결 조건이 됐다.
