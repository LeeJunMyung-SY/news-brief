# Large Language Models and Foundation Models — 동향 요약

### 데이터 통제가 조달 조건
기업 반발로 데이터 보존 정책이 철회되고 직접 저장·관리 옵션이 신설됐다. 모델 선택에서 성능만큼 데이터 취급 조건이 협상 항목이 됐다.

### 멀티 모델이 기본 구성
업무별로 여러 모델을 나눠 쓰는 사내 플랫폼이 표준 설계로 자리 잡으며, 요청을 어디로 보낼지 정하는 라우팅이 곧 비용 관리가 된다.

### 경쟁축이 운영 단가로
모델 자체보다 연산 부담을 줄이는 최적화 계층에 수익 지점이 형성된다. 추론 비용이 성능과 나란한 조달 기준이 됐다.

### 능력이 배포 범위를 정한다
위험 임계치를 넘은 능력은 기능을 잠근 채 출시된다. '어떤 기능이 열리는가'를 먼저 확인해야 한다.
