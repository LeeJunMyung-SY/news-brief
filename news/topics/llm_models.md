# Large Language Models and Foundation Models — 동향 요약

### 사용량 기반 과금의 변동성
과금 수정만으로 사용 한도가 크게 줄어든 사례가 나와, 기업은 모델 비용의 예측 가능성을 계약으로 확보해야 한다.

### 중국 모델 공급 둔화
칩 통제와 증류 차단으로 중국 대표 모델의 출시 주기가 길어져, 오픈웨이트 기반 서비스의 업데이트 리스크가 커졌다.

### 연구 자동화 경쟁
프론티어 연구소들이 수학·과학 연구를 수행하는 에이전트 성과를 잇달아 내놓아, 모델 경쟁의 축이 고난도 지식업무 위임 능력으로 옮겨 간다.

### 신뢰·통제 보장 경쟁
데이터 비열람 추론과 내부 해석 가능성 연구가 이어져, 보안·감사 가능성이 모델 선택 기준으로 자리 잡았다.
