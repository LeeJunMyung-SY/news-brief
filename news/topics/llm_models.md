# Large Language Models and Foundation Models — 동향 요약

### 소유 모델이 선택지로 올라왔다
오픈웨이트를 기반으로 자체 모델을 만드는 비용이 수천만 달러 수준으로 내려왔고, 성능은 독점 데이터와 결합할 때만 최상위였다. 자체 구축 판단의 기준이 성능에서 데이터 보유량으로 바뀐다.

### 가격과 데이터 정책이 채택률을 가른다
7만여 기업의 실지출 분석에서 단가와 데이터 보존 요건이 확산 속도를 갈랐고 시장 성장률 순위가 역전됐다. 벤더 선정에서 성능은 하나의 변수일 뿐이다.

### 개선 순환 속도가 승부처
좋은 모델을 한 번 만드는 것보다 실사용 데이터를 학습으로 되돌리는 순환을 빠르게 돌리는 쪽이 이긴다는 전략이 제시됐다. 파이프라인 설계가 모델 선택보다 앞선다.

### 단일 의존은 곧 중단 위험
주요 상용 모델이 챗봇과 API에서 동시 장애를 일으켰다. 대체 라우팅과 수동 대체 절차가 도입 요건에 포함돼야 한다.
