# Large Language Models and Foundation Models — 동향 요약

### 소유가 안보 논리로 격상
독자 파운데이션 모델 확보가 산업 정책을 넘어 안보 과제로 규정됐다. 모델 조달 전략에 국산·개방형 대체 경로를 포함할 근거가 생겼다.

### 플래그십 경쟁이 재점화
빅테크가 차세대 플래그십 모델과 소비자용 에이전트를 동시에 준비하며 출시 일정을 앞당기고 있다. 모델 교체 주기가 도입 계획의 변수로 커진다.

### 차별화는 독점 데이터에서
국가 간 협정까지 동원해 접근 불가능한 실전 데이터를 확보하려는 움직임이 나온다. 성능 우위는 데이터 보유와 결합할 때만 나타난다.

### 사용 통제가 제품군이 됐다
프롬프트 단계에서 민감정보를 선별 차단하는 기술이 정부 우수기술로 다수 지정됐다. 외부 모델 금지 대신 통과 조건 관리가 현실적 대안이다.
