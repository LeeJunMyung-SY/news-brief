# Large Language Models and Foundation Models — 동향 요약

### 도메인 특화가 차별점
범용 성능 경쟁과 별개로 산업 데이터를 학습한 수직 모델이 제품으로 나오고 있다. 보안처럼 맥락 해석이 중요한 영역에서는 특화 모델 조달이 실제 선택지가 됐다.

### 제품 통합이 조달을 바꾼다
별도 브랜드로 팔던 기능이 본체로 흡수되면서 용도별 구독을 쪼개 쓰기 어려워졌다. 계약 단위 재설계가 필요하다.

### 모델 교체 자유가 쟁점
개발도구에 타사 모델을 연결하는 사용이 늘며 락인 여부가 조달 검토 항목으로 올라왔다.

### 공급사 재무도 평가 항목
선두 모델사의 대규모 조달과 상장 지연이 이어지며 재무 실사가 모델 선택에 포함된다.
