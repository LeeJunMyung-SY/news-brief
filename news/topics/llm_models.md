# Large Language Models and Foundation Models — 동향 요약

### 국책 모델 평가가 흔들린다
벤치마크 최고점 사업자가 종합 평가에서 탈락하며 선정 기준 공개를 요구하는 이의제기가 나왔다. 국산 모델을 조달 후보로 볼 때 절차 불투명성이 리스크로 남는다.

### 도메인 특화가 국책으로 간다
폐쇄망 운영을 전제로 한 보안 특화 파운데이션 모델 개발이 국가 사업으로 추진된다. 망분리 규제 산업의 선택지가 실질적으로 늘어난다.

### 승부는 데이터와 후속 학습
최상위 모델 확보의 관건이 사전학습 규모가 아니라 데이터 확보와 포스트 트레이닝으로 지목됐다.

### 오픈 모델 단가는 계속 내려간다
자체 호스팅의 손익분기가 앞당겨지고 있다.
