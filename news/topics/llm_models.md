# Large Language Models and Foundation Models — 동향 요약

### 국산 모델의 무료 개방 공세
국내 독자 파운데이션 모델이 API를 무료로 풀며 개발자 확보에 나서, 국산 모델 경쟁이 성능 증명에서 생태계 선점으로 넘어갔다.

### 오픈웨이트의 지정학
서방권 오픈 모델이 중국 모델에 근접하고 중국 모델은 지역 사용 제한을 걸기 시작해, 라이선스 지역 리스크가 조달의 별도 변수가 됐다.

### 모델 밖 운영 계층의 차별화
기억 선별·재구성 같은 운영 기술이 장기 작업 성능을 끌어올려, 모델 선정 기준에 기억·세션 관리 역량이 추가된다.

### 벤치마크와 실전의 격차
공개 벤치마크 고득점 모델도 실사용 과제 해결률은 크게 낮아, 자사 업무 기반 평가가 필요하다.
