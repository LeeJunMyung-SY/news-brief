# Large Language Models and Foundation Models — 동향 요약

### 현장 데이터로 직접 만든다
대기업 계열 SI가 국내 파운데이션 모델 기업과 제조 특화 모델을 공동 개발한다. 조달 전략이 범용 모델 임차에서 도메인 데이터 기반 자체 확보로 이동한다.

### 소유 모델이 선택지로 올라왔다
오픈웨이트 기반 자체 구축 비용이 내려왔고, 최상위 성능은 독점 데이터와 결합할 때만 나왔다. 판단 기준이 성능에서 데이터 보유량으로 바뀐다.

### 비용과 주권이 배치를 가른다
워크로드 단가와 데이터 주권 요건이 퍼블릭·온프레미스 배치를 나누는 축이 됐다. 벤더 선정에서 성능은 하나의 변수일 뿐이다.

### 단일 의존은 곧 중단 위험
주요 상용 모델이 챗봇과 API에서 동시 장애를 냈다. 대체 라우팅과 수동 절차가 도입 요건에 포함돼야 한다.
