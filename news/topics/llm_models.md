# Large Language Models and Foundation Models — 동향 요약

### 교체 주기가 계획 변수로
중간 버전을 건너뛰고 차세대 플래그십으로 직행하는 움직임이 나타났다. 모델 버전을 고정한 도입 계획일수록 전환 비용을 미리 반영해야 한다.

### 코딩 도구가 경쟁의 관문
대형 인수를 통해 코딩 역량 격차를 좁히려는 시도가 공개적으로 진행 중이다. 개발 도구 점유가 곧 모델 채택으로 이어지는 구조다.

### 소유가 현실 선택지로
금융사가 자체 파운데이션 모델로 연구 조직을 세우고, 모델 기업은 현지 언어·규제에 맞춘 소버린 모델을 공급한다. 빌리기와 갖기 사이의 중간 경로가 넓어졌다.

### 실행 위치가 단말로
로컬에서 대형 모델을 구동·파인튜닝하는 하드웨어가 잇따라 나왔다. 데이터 반출 제약이 큰 조직의 대안이 생겼다.
