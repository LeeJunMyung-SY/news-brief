# Large Language Models and Foundation Models — 동향 요약

### 용량이 일정을 정한다
신모델 수요 폭증으로 최상위 요금제 신규 가입이 중단됐다. 성능보다 확보 가능한 연산량이 도입 속도를 가른다.

### 모델이 업종 제품으로
최신 모델을 금융 데이터와 결합한 업종 특화 제품이 나오며 경쟁 축이 데이터 제휴와 출처 검증 기능으로 옮겨간다.

### 가격은 사용량 기반으로
대형 공공 계약이 좌석 정액에서 토큰 사용량 과금으로 바뀌며 작업 단위 총비용이 조달 기준이 된다.

### 효율 모델이 원가를 누른다
메모리 사용을 크게 줄인 경량 모델이 나오며 에이전트 운영 원가 기준이 내려간다. 다만 출처 리스크가 따른다.
