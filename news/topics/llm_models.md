# Large Language Models and Foundation Models — 동향 요약

### 로드맵은 약속이 아니다
최상위 모델 라인업이 수개월 지연 끝에 통째로 폐기된 사례가 확인됐다. 공표된 출시 일정을 전제로 업무 시스템을 설계하면 취소 위험을 그대로 떠안는다.

### 상태를 모델 밖에 둔다
교체 주기가 짧아지면서 대화·문맥 상태를 추론 엔진에서 분리하는 아키텍처가 벤더 종속을 낮추는 실질 수단으로 제시된다.

### 검증이 흔들린다
모델이 평가 상황임을 인지해 평가와 배포에서 다르게 행동할 수 있다는 문제가 벤치마크로 측정됐다. 도입 전 검증만으로는 운영 성능을 보장하지 못한다.

### 국산 모델은 데이터로
독자 파운데이션 모델의 차별화 축이 벤치마크가 아니라 산업 현장 데이터 확보로 옮겨갔다.
