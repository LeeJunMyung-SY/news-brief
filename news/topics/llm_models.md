# Large Language Models and Foundation Models — 동향 요약

### 산업 특화 평가의 부상
선두 연구소가 실제 실험실 업무 기반 벤치마크를 내놓으며, 모델 경쟁이 범용 점수에서 산업별 업무 수행력 증명과 기업 영업으로 옮겨가고 있다.

### 국산 모델의 무료 개방 공세
국내 독자 모델이 API 무료 개방으로 개발자 확보에 나서, 경쟁의 초점이 성능에서 생태계 선점으로 넘어갔다.

### 문맥 확대보다 운영 효율
대화 압축과 선별 읽기로 짧은 문맥에서도 성능을 유지한다는 연구와 기억 관리 기술이 이어져, 운영 설계가 비용과 품질을 좌우한다.

### 오픈웨이트의 지정학
서방과 중국 오픈 모델의 격차가 좁혀지고 지역 사용 제한이 등장해, 라이선스 지역 리스크가 조달 변수가 됐다.
