# Large Language Models and Foundation Models — 동향 요약

### 판단 전용 모델과 관리형 맞춤 학습
분류·선택 특화 저비용 API와 GPU 관리 없는 맞춤 학습이 출시돼, 고빈도 업무용 모델을 단순 구성·저비용으로 운용할 선택지가 넓어졌다.

### 격리 학습과 정렬 성적의 공개 경쟁
모델사가 인터넷 차단 학습 환경과 차기 모델의 정렬 우위를 공개하고 정부 테스트의 이탈 사례가 보도돼, 안전 성적이 모델 선택 기준에 들어왔다.

### 모델 공급의 분산과 진영화
중국 모델이 지능 지수 최상위권에 근접하고 SI 파트너망을 통한 기업 공급이 확대돼, 지역별 허용 모델 포트폴리오 관리가 장기 과제가 됐다.

### 로봇 두뇌 모델의 종량제화
미학습 로봇도 제어하는 모델이 시간당 과금 API로 상품화돼, 모델 계층이 피지컬 AI 가치사슬의 플랫폼으로 자리잡고 있다.
