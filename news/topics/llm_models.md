# Large Language Models and Foundation Models — 동향 요약

### 범용 모델의 영역 확장
범용 모델이 로봇까지 직접 제어하며 전용 모델 조직이 축소돼, 파운데이션 모델 하나로 여러 도메인을 커버하는 구도가 강해진다.

### 모델 라우팅과 토큰 경제
업무별로 모델·인프라를 조합해 비용을 낮추는 라우팅이 사업화되며, 모델 선택 기준이 성능에서 총비용으로 이동한다.

### 세대 교체와 활용법 재정비
신규 플래그십 기본화와 함께 과거 프롬프팅 습관을 버리라는 지침이 나와, 사내 프롬프트 설정의 재점검이 필요하다.

### 비공개 모델 검증 요구
가장 앞선 모델이 내부용으로만 운영돼 감독 공백이 지적되며, 공급사 안전 체계가 도입 실사 항목으로 커진다.
