# Large Language Models and Foundation Models — 동향 요약

### 중급 모델의 가격 파괴
플래그십에 근접한 성능을 5분의 1 가격에 내놓는 경쟁이 이어져, 업무별 모델 조합과 원가 재산정이 조달의 기본이 됐다.

### 안전이 출시 속도를 제약
차기 플래그십 출시 보류에 이어 공급사가 상장 일정까지 안전 확보와 연동시키며, 모델 로드맵 자체가 도입 계획의 변수로 굳어졌다.

### 로컬 실행이 선택지로
대형 모델을 PC에서 직접 돌리는 하드웨어가 상용화돼, 민감 데이터 업무는 클라우드 API 대신 온프레미스 추론을 검토할 여지가 생겼다.

### 계약 조건이 경쟁 무기로
약정 한도·할인 정책으로 기업 고객을 다투는 구도가 계속돼, 사용량 증가 시나리오를 반영한 멀티벤더 협상이 중요해졌다.
