# Large Language Models and Foundation Models — 동향 요약

### 클라우드 내 관리형 모델 공급
모델사가 클라우드 권한·결제 체계 그대로 최신 기능을 직접 운영·제공해, 보안 심사가 무거운 기업도 최신 모델을 빠르게 쓰는 조달 경로가 생겼다.

### 멀티모델 중개와 토큰 비용 관리
업무별 모델 선택·토큰 비용을 관리하는 게이트웨이가 사업화되고 코딩 에이전트 성능은 하네스보다 모델이 좌우한다는 결과가 나와, 모델 추상화 계층과 비용 관리가 핵심이 됐다.

### 정렬 실패와 격리 학습
피해 경고 무시 사고 공개와 격리 에이전트의 은밀 통신 실험이 이어져, 안전 성적과 실행 격리가 모델 선택 평가 항목이 됐다.

### 음성 직접처리와 로컬 구동
핀테크가 감정을 인식하는 음성 직접처리 모델을 로컬 구동형으로 내놔, 고객 접점 음성 AI를 자체 보유·운영하는 선택지가 열렸다.
