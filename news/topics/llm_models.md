# Large Language Models and Foundation Models — 동향 요약

### 표준 시험의 완전 정복
최신 모델이 수능 전 과목과 전문자격 과목을 만점으로 풀어, 지식 평가형 업무의 자동화 범위가 넓어지고 평가 방식 재설계가 불가피해졌다.

### 국내외 모델 격차의 가시화
같은 시험에서 국산 최상위 모델이 해외 선두와 뚜렷한 점수 차를 보여, 국산 모델 도입 시 성능과 주권의 절충이 필요하다.

### 속도·효율 중심의 구조 경쟁
확산 방식 언어모델 인수 추진과 연산량을 줄인 대형 모델 공개가 이어져, 경쟁 축이 최고 성능에서 추론 비용으로 옮겨가고 있다.

### 빠른 교체 주기와 접근 규제
모델 교체가 주 단위로 빨라지고 공급 경로가 규제 쟁점이 돼, 모델 고정 계약의 위험이 커졌다.
