# Large Language Models and Foundation Models — 동향 요약

### 2026-08-05 08:45

중국 모델 진영의 공세와 가격 구조가 이번 회차의 핵심이다. 블룸버그는 중국 AI가 저가 경쟁을 넘어 최고 수준 성능까지 확보하면서 중간지대 개발사들이 '데드존'에 몰렸다고 분석했고, ZDNet 칼럼은 3주 사이 나온 중국 모델 3종의 출력 토큰 가격이 15달러와 0.28달러로 53배 벌어진다는 점을 짚으며 모델 선정 기준을 벤치마크에서 '요구 성능 대비 단가'로 재구성할 것을 제안했다. 오픈웨이트 진영에서는 세이퍼AI가 GLM-5.2의 프런티어급 성능과 안전장치 부재를 동시에 지적했고, 조지아공대 분석은 중국 오픈모델 금지 시 미국 기업이 연 120억달러를 추가 부담한다고 추정했다. 국내에서는 SKT의 688B 'A.X K2'와 독파모 2차 평가가 국산 모델 조달 라인업을 결정할 변수로 부상했다.

### 2026-08-04 16:22

국내 파운데이션 모델 경쟁의 2라운드가 시작됐다. 독자 AI 파운데이션 모델(독파모) 2차 평가에 SKT·LG AI연구원·업스테이지·모티프가 참여했고, 평가 축이 절대 성능에서 에이전트 성능과 산업 현장 적용으로 확장됐다. 카카오는 옴니 모델 '카나나-오'의 음성 제어를 자연어 지시 기반으로 고도화했다. 국산 모델 도입을 검토하는 기업에는 벤치마크 점수보다 현장 적용 실적이 선택 기준이 되는 흐름이 뚜렷해지고 있다.

### 2026-08-04 12:20

모델 경쟁의 무게중심이 '누가 더 큰가'에서 '누가 더 싸게 오래 일하는가'로 옮겨가고 있다. 알리바바는 2조4000억 파라미터의 큐원 3.8 맥스를 공개하면서 MoE로 추론 시 950억만 활성화해 비용을 낮췄고, 100만 토큰 컨텍스트와 16일간 자율 수행이라는 장기 작업 능력을 전면에 내세웠다. 국내에서는 모티프·업스테이지·SKT·LG AI연구원 4개 팀이 독자 파운데이션 모델 사업의 오픈웨이트 버전을 허깅페이스에 동시 공개하며 국산 모델 선택지를 구체화했다. 가중치가 공개된 국산 모델이 복수로 확보되면서, 망분리·데이터 주권 제약이 큰 조직도 온프레미스 파인튜닝이라는 현실적 경로를 갖게 됐다.

### 2026-08-04 08:28

오픈웨이트 진영의 무게중심이 중국으로 확실히 기울었다. 알리바바는 2조4000억 매개변수 규모의 플래그십 큐원 3.8-맥스를 공개하며 며칠 단위 장기 자율 작업 수행을 표방했고, 다음 주 가중치를 공개해 맥스급 최초의 오픈웨이트 배포가 된다. 미니맥스 H3는 오픈 모델로는 처음으로 영상 생성 랭킹 정상에 올랐다. 허깅페이스 CEO는 중국이 오픈 모델 부문을 주도하며 올해 안에 미국을 따라잡을 수 있다고 진단했고, 미국 오픈소스 스타트업들은 VC의 이해충돌과 수익 불확실성으로 자금난에 직면해 있다. 한편 엔비디아는 추론 단계를 90% 줄인 코스모스3 증류 모델을 내놓아 운영비 관점의 선택지를 넓혔다.

### 2026-08-03 16:47

모델 선택과 조달의 판단 기준이 정교해지고 있다. LLM API 제공자가 몰래 저가 모델로 교체하거나 토큰을 부풀리는 부정행위를 게임이론으로 억제하는 연구는 외부 API 계약의 검증 공백을 드러냈고, 능력이 규모가 아닌 정보 접근 구조에서 온다는 가설은 파라미터 경쟁 위주 판단에 제동을 건다. 실무 쪽에서는 통신 고객지원용 소형 모델 LoRA 튜닝을 에너지 소비까지 포함해 비교한 연구가 나와, 데이터 주권 제약이 있는 산업의 현실적 선택지를 보여줬다. 오픈AI는 챗GPT 브라우저 기능을 크롬 확장·데스크톱 앱으로 확대하며 별도 브라우저 전략에서 선회했다.

### 2026-08-03 12:23

모델 자체의 신규 공개보다 모델을 어떻게 업무에 붙이고 얼마나 싸게 돌리느냐가 부각된 회차다. 신한은행은 LLM에 RPA·OCR을 결합해 감정평가서 점검이라는 정형 심사 업무를 자동화했고, 케이뱅크는 코드 생성부터 사내 지식검색까지 개발 전 과정에 자율형 AI를 적용했다. 추론 효율 측면에서는 국내 기업 비드래프트가 구글 젬마팀·허깅페이스가 운영한 '패스트 젬마 챌린지'에서 동일 모델·동일 GPU 조건의 소프트웨어 최적화만으로 세계 1위에 올라, 추론 비용 최적화 역량이 독립된 경쟁력으로 자리잡고 있음을 보여줬다.

### 2026-08-03 08:31

모델 경쟁의 축이 성능에서 단가와 활용 범위로 옮겨갔다. 오픈AI는 GPT-5.6 가격을 최대 80% 내리고 사용자 10억·기업 고객 200만을 발표하며 저가-대량 전략을 공식화했고, 차세대 제품군 '아스트라'로 수학 난제 10건을 풀며 다음 세대를 예고했다. 중국·오픈웨이트 진영에서는 딥시크 V4-플래시, 미니맥스 H3, 싱킹머신즈 잉클링-스몰, 알리바바 큐원 ASR이 잇따라 나오며 저비용 대안이 두터워졌다. 도입 관점에서는 성능 격차보다 단가·라이선스 조건이 선택 변수로 부상했다.
