# Large Language Models and Foundation Models — 동향 요약

### 개방 노선의 재부상
최상위 성능 모델까지 가중치를 여는 흐름이 국가 경쟁 논리와 결합해 되살아났다. 폐쇄형 API 단일 전제의 아키텍처는 유효기간이 더 짧아졌다.

### 역량 등급이 접근을 가른다
사이버 역량이 임계에 닿은 모델은 신원 확인·목적 제한 심사를 통과한 조직에만 열린다. 성능이 곧 사용 가능성은 아니게 됐다.

### 국산 모델의 상용 채택
독자 파운데이션 모델이 데모를 넘어 상용 보안 제품의 핵심 엔진으로 들어갔다. 데이터 반출이 어려운 조직의 현실적 선택지가 늘었다.

### 소비자 기기로 내려온 성능
개인 기기에서 도는 모델이 등장하며 민감 업무의 자체 호스팅이 실제 선택지가 됐다.
