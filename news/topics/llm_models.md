# Large Language Models and Foundation Models — 동향 요약

### 원가가 채택을 가른다
기업용 추론 비용이 연중 최저로 떨어지고 경량 개방 모델이 4배 큰 모델과 대등한 성능을 내면서, 선택 기준이 성능에서 단가와 실행 위치로 옮겨갔다.

### 개방 노선이 표준이 됐다
칩 공급사까지 가중치를 열어 배포하고 1조 매개변수급 개방 모델을 예고하며, 클라우드 API 전제의 아키텍처 수명이 짧아지고 있다.

### 국산 모델의 검증 축적
독자 파운데이션 모델 다수가 해외 평가에 이름을 올리고 기술보고서까지 공개되며, 데이터 반출이 어려운 조직의 실질 후보가 됐다.

### 감춰진 추론이 위험 지점
암호화된 추론 흔적에서 자격증명이 추출되며 '보이지 않으니 안전하다'는 전제가 깨졌다.
