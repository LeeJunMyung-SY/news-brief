# Large Language Models and Foundation Models — 동향 요약

### 정액제에서 사용량 과금으로
토큰 기반 공용 쿼터와 계정 제한이 도입되며, 구독 AI의 비용 관리 단위가 좌석에서 작업·모델 소모량으로 바뀌고 있다.

### 지역별 모델 분화
글로벌 기기 기업도 중국 모델을 택하면서, 다국적 서비스는 지역마다 다른 모델을 쓰는 구도를 전제해야 한다.

### 편향·출처 실측의 필요
모델 성향이 출신국만으로 설명되지 않고 웹 콘텐츠 오염 우려도 제기돼, 주제별 직접 검증이 선택 기준이 됐다.

### 멀티모델 라우팅 표준화
작업별 자동 모델 선택이 확산되며, 모델 경쟁의 축이 단일 성능에서 비용 최적화로 옮겨가고 있다.
