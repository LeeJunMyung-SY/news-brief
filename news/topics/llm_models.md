# Large Language Models and Foundation Models — 동향 요약

### 도메인·인프라 수직 최적화
재료과학처럼 좁은 영역에 맞춰 모델과 학습·추론 인프라를 함께 설계하는 전략이 확산된다. 범용 모델 위에 얹는 방식과 경쟁 구도가 갈린다.

### 출력 형식 자체를 바꾸는 접근
텍스트 생성 대신 구조화된 판단을 직접 출력해 환각과 타입 오류를 제거하려는 모델이 나왔다. 대량 자동화의 검증 비용을 줄이는 방향이다.

### 국산 모델의 가격 실험
국내 최고 성능 모델이 한시 무료 개방 후 과금 전환을 예고했다. 조달 선택지가 해외 일변도에서 넓어지는 국면이다.

### 권리 리스크는 계속
학습 데이터 취득을 둘러싼 내부 문서가 공개되며, 모델 공급사의 법적 리스크가 이용 기업으로 전이될 여지가 남았다.
