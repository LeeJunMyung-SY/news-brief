# Large Language Models and Foundation Models — 동향 요약

### 원가 중심 모델 선택
프런티어급 일부 성능을 최대 42분의 1 가격에 내는 중국 모델이 다시 등장해, 모델 선택 기준이 성능에서 작업당 원가로 확실히 이동하고 있다.

### 모델 출처 리스크의 현실화
중국의 오픈웨이트 수출 통제 추진과 공공 금융기관의 중국산 모델 사용 지적이 겹쳐, 출처 다변화와 원산지 점검이 조달 기본값이 됐다.

### 에이전트 실행 기능의 내장
주력 모델이 병렬 에이전트 실행을 기본 제공하면서, 모델 경쟁이 단일 응답 품질에서 작업 분할·관리 역량으로 넓어지고 있다.

### 목적형 모델의 확산
의사결정·영상 등 특화 모델이 잇따라 나와, 범용 모델 대신 업무별 목적형 모델을 조합하는 선택지가 커지고 있다.
