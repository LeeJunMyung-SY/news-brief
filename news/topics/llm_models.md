# Large Language Models and Foundation Models — 동향 요약

### 오픈웨이트의 지정학
서방권 오픈 모델이 중국 모델 성능에 근접하는 한편 중국 모델은 일부 지역 사용을 제한하기 시작해, 모델 조달에서 라이선스 지역 리스크가 별도 변수가 됐다.

### 저가·장문맥 모델의 공세
중국 핀테크 계열이 저렴한 사용료와 긴 컨텍스트의 멀티모달 모델로 기업 에이전트 시장을 겨냥해, 경쟁의 축이 최고 성능에서 토큰당 성과로 더 기운다.

### 벤치마크와 실전의 격차
공개 벤치마크 고득점 모델도 실사용 과제에서는 해결률이 크게 낮아, 모델 선정에 자사 업무 기반 평가가 필요하다.

### 연구 보조의 실제 용도
과학 현장의 모델 활용이 데이터 분석·논문 작성에 집중되고 가설 생성 비중은 낮아, R&D 도입 효과는 보조 업무에서 먼저 나타난다.
