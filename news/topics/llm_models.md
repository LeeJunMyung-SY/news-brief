# Large Language Models and Foundation Models — 동향 요약

### 2026-07-30 12:22

모델 경쟁이 '다품종 라인업'에서 '단일 프런티어 집중'으로 수렴하는 조짐이다. 아마존은 노바 프리미어·옴니·릴·캔버스를 단계적으로 폐기하고 프런티어 모델 연구(FMR)에 역량을 통합해 연말 리인벤트 공개를 목표로 하고 있어, 노바 계열을 채택한 기업은 마이그레이션 점검이 필요해졌다. 구글은 제미나이 3.6을 에이전트 제품의 기반으로 전면에 내세웠고, 오픈AI는 학술 연구자 대상 무료 프로그램으로 생태계 선점에 나섰다.

### 2026-07-30 09:21

오픈웨이트 진영의 추격과 자체 모델 전략의 재편이 동시에 확인된 회차다. 아토믹 에이전트의 비교 테스트에서 문샷의 오픈웨이트 키미 K3가 비용 우위를 유지하면서 앤트로픽 페이블 5에 필적하는 결과를 냈고, 문샷은 이를 발판으로 더 큰 규모의 K4 개발과 엔비디아 블랙웰 추가 확보에 착수했다. 반면 아마존은 자체 모델 노바 조직을 정리하고 프리미어·옴니·릴·캔버스를 단계적으로 폐지하며 외부 인재 중심 재개발로 방향을 틀었다. 국내에서는 크래프톤이 21B 규모 한국어 음성 파운데이션 모델을 허깅페이스에 공개했고, CNBC는 아시아 시장에서 중국의 저가 모델이 실질 점유율을 가져가는 구도를 짚었다.

### 2026-07-29 16:20

모델 경쟁의 축이 성능 발표에서 '도입 조건'으로 옮겨간 회차였다. SK텔레콤은 6880억 파라미터 규모의 A.X K2를 아파치 2.0 오픈웨이트로 공개해 국내 최대 공개 모델 라인업을 갖췄고, 반대로 문샷 AI의 키미 K3는 '오픈'을 표방했지만 대기업·AI 서비스 사업자에게 별도 상업 계약과 출처 표시를 요구하는 제한적 라이선스로 확인됐다. 아마존은 자체 노바 시리즈를 단계적으로 접고 소수 프론티어 모델에 자원을 집중하기로 해, 빅테크조차 전 라인업 자체 보유 전략을 포기하는 흐름이 나타났다.

### 2026-07-29 12:21

국가 독자 파운데이션 모델(독파모) 프로젝트 2차수 성과가 한꺼번에 공개됐다. SK텔레콤은 688B 규모 'A.X K2'를 허깅페이스에 공개하며 직전 519B 모델 대비 수학·과학 추론과 장문 처리를 강화했고, 제조·국방·바이오 현장 투입과 조 단위 후속 모델 계획까지 밝혔다. 크래프톤은 같은 프로젝트에서 21B 음성 언어 모델을 내놓아 30B 이하급 한국어 성능 1위를 기록했다. 데이터 국외 반출이 어려운 규제산업 입장에서 온프레미스로 검토할 국산 오픈 웨이트 선택지가 실질적으로 넓어졌다는 점이 핵심이다.

### 2026-07-29 08:32

모델 경쟁 구도가 성능에서 비용·통제·지속성으로 이동하는 흐름이 뚜렷하다. 아마존이 노바 모델 대부분의 개발을 중단하고 신설 프런티어 조직으로 선회하면서, 빅테크조차 자체 모델 풀라인업 유지가 어렵다는 점이 드러났다. 국내에서는 카카오가 스마트폰에서 구동 가능한 카나나 경량모델 4종을 오픈소스로 공개해 온프레미스·온디바이스 선택지를 넓혔고, 중국은 오픈 웨이트 공세로 미국 대비 4분의 1 수준의 비용을 앞세워 글로벌 개발자의 상당수를 흡수하고 있다. 한편 앤트로픽의 미토스 프리뷰 모델이 2년 넘게 검증된 후양자 서명 방식의 취약점을 찾아내며, 프런티어 모델의 역량이 보안 영역에서 임계점을 넘고 있음을 보여줬다.

### 2026-07-28 16:22

이번 회차는 오픈웨이트 공개가 흐름을 주도했다. 문샷 AI가 2조8000억 파라미터급 '키미 K3' 가중치와 학습·추론 인프라 3종을 한꺼번에 오픈소스로 풀었고, 카카오는 상업적 활용까지 허용하는 라이선스로 온디바이스용 경량 모델 '카나나-2' 4종을 공개했다. 프런티어급은 자체 호스팅, 경량급은 단말·폐쇄망이라는 두 갈래로 자체 구축 선택지가 동시에 넓어진 셈이다. 다만 미국이 '증류'를 규제 대상으로 삼으려는 움직임과 맞물려, 오픈웨이트 채택 시 모델의 학습 계보와 라이선스 검증이 새로운 실무 과제로 떠올랐다.
