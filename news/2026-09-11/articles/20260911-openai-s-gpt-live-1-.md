# OpenAI's GPT-Live-1 API lets developers build apps that talk and listen at the same time

**Source**: The Decoder | **Published**: Thu, 10 Sep 2026 17:47:35 +0000 | **Topics**: llm_models

## Summary
OpenAI가 전이중(full-duplex) 음성 모델 GPT-Live-1을 개발자 API로 출시했다. 상호작용성 평가에서 80.1%를 기록해 이전 모델(45.4%)보다 크게 개선됐고, 가격은 분당 0.05달러다.

## Key Points
- 전이중 음성 모델 GPT-Live-1 API 공개
- 상호작용성 점수 45.4%→80.1%
- 분당 0.05달러로 저렴하진 않음
- 실시간 대화형 앱 구축 가능

## Why This Matters
사람처럼 끼어들고 응답하는 음성 에이전트가 API로 풀리면서 콜센터·상담 자동화의 원가 계산을 새로 해야 한다.
