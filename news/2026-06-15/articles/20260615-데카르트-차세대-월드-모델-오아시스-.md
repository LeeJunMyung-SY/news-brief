# 데카르트, 차세대 월드 모델 '오아시스 3' 출시…업계 최초 API 개방

**Source**: AI타임스 | **Published**: 2026-06-12 18:41:36 | **Topics**: llm_models, physical_ai_robotics

## Summary
데카르트가 자율주행차·로봇용 차세대 월드 모델 '오아시스(Oasis) 3'를 공개했다. 텍스트 프롬프트만으로 사실적인 주행 환경을 실시간 생성할 수 있으며, 업계 최초로 API를 통해 외부 개발자에게 개방했다. 실제 도로에서 발생하기 어려운 희귀 상황을 대규모로 시뮬레이션할 수 있다.

## Key Points
- 차세대 월드 모델 오아시스 3 공개
- 텍스트 프롬프트로 주행 환경 실시간 생성
- 업계 최초 월드 모델 API 개방
- 희귀 주행 상황 대규모 시뮬레이션 지원
- 로봇·제조 자동화로 확장 계획

## Why This Matters
월드 모델의 API 상용화로 자율주행·로봇 개발의 시뮬레이션 데이터 확보 방식이 바뀔 수 있다.
