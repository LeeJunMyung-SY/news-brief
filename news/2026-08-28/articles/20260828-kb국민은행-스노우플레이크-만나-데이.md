# KB국민은행, 스노우플레이크 만나 데이터 구조부터 다시 짰다

**Source**: 블로터 | **Published**: 2026-08-27 23:36:56 | **Topics**: 금융회사 AI, ai_industry

## Summary
KB국민은행이 AI 도입을 추진하는 과정에서 부서별로 흩어진 데이터와 메타데이터 부재라는 벽에 부딪혀 데이터 구조부터 재설계했다. 같은 '매출'이라는 용어도 영업·재무 부서가 다르게 해석하는 문제를 해결하기 위해 스노우플레이크 기반 통합 플랫폼을 구축했다.

## Key Points
- 부서별 데이터 분산·정형/비정형 혼재·메타데이터 부족이 AI 도입 병목
- 용어 정의가 부서마다 달라 학습 데이터로 쓸 수 없는 상태였음
- 스노우플레이크 기반 단일 클라우드 데이터 플랫폼으로 정비
- AI 활용보다 데이터 표준화가 선행 과제였음을 자체 확인

## Why This Matters
금융사 AI 프로젝트가 모델 선정이 아니라 데이터 거버넌스에서 좌초한다는 점을 실제 사례로 보여준다. AX 로드맵에서 데이터 표준·메타데이터 정비 예산을 선행 배치해야 할 근거가 된다.
