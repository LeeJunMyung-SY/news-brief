# 아이지에이웍스, 3400만명 행동 학습한 AI 모델 공개…사전 데이터 예측 시장 공략

**Source**: 전자신문 IT | **Published**: Fri, 28 Aug 2026 15:36:59 +0900 | **Topics**: llm_models, ai_industry

## Summary
아이지에이웍스가 약 3400만명 규모 소비자 행동 데이터를 학습한 자체 파운데이션 모델 '웍스FM'을 공개했다. 자사 고객 데이터만으로는 소비자의 미래 행동을 추론하기 어려운 기업 수요를 공략한다는 전략이다.

## Key Points
- 3400만명 규모 행동 데이터 학습한 자체 파운데이션 모델
- 합성 소비자 인텔리전스(SCI)와 결합해 예측 제공
- 자사 데이터 한계가 있는 기업이 타깃
- 스노우플레이크 행사에서 기술 구조·적용 전략 공개

## Why This Matters
범용 LLM 경쟁이 아니라 확보한 도메인 데이터 자체를 모델 경쟁력으로 전환하는 접근이다. 자체 데이터 자산의 사업화 경로를 검토할 근거가 된다.
