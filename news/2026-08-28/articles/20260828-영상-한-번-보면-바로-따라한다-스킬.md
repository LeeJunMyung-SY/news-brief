# "영상 한 번 보면 바로 따라한다"...스킬드 AI, 로봇 파운데이션 모델 'S1' 공개

**Source**: AI타임스 | **Published**: 2026-08-27 17:32:18 | **Topics**: physical_ai, physical_ai_robotics, ai_industry, llm_models

## Summary
스킬드 AI가 단 한 편의 비디오 시연만으로 처음 접하는 복잡한 작업을 수행하는 로봇 파운데이션 모델 'S1'을 공개했다. 대규모 사전학습을 통해 시연 영상에서 작업 의도와 절차를 즉석에서 학습하는 맥락 학습 능력을 갖춘 것이 핵심이다.

## Key Points
- 작업별 수십~수백 시간 시연 데이터 수집 과정 제거
- 별도 미세조정 없이 신규 작업 수행
- 맥락 학습(ICL) 기반 로봇 제어
- 새 환경 투입 시 준비 비용을 크게 낮추는 구조

## Why This Matters
로봇 도입 총비용의 대부분을 차지하던 작업별 학습 준비가 줄면 적용 가능한 공정 범위가 넓어진다. 다품종 소량 생산 현장의 로봇 도입 검토 기준이 달라질 수 있다.
