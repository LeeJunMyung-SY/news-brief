# 딥시크, V4 모델 API 가격 최대 1100% 인상...혼잡 시간대 2배 부과

**Source**: AI타임스 | **Published**: 2026-08-14 12:49:43 | **Topics**: llm_models, ai_agents, ai_industry, ai_compute_energy

## Summary
딥시크가 주력 모델 'V4 프로'와 'V4 플래시'의 API 가격을 최소 50%에서 최대 1100% 이상 인상한다. 사용량이 몰리는 시간대에 더 높은 요금을 매기는 피크·비피크 차등 요금제도 도입한다.

## Key Points
- 17일부터 새 요금제 시행
- 혼잡 시간대 2배 요금 부과
- 초저가 전략에서 선회

## Why This Matters
저가 오픈 모델을 전제로 짠 원가 모델이 흔들릴 수 있고, 시간대 차등 과금은 배치 처리 설계가 곧 비용 절감 수단이 됨을 뜻한다.
