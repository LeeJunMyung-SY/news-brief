# A2M: Trace-Optimized Agent Hijacking in the MCP Ecosystem

**Source**: arXiv CS.AI | **Published**: Wed, 23 Sep 2026 00:00:00 -0400 | **Topics**: ai_agents, ai_policy

## Summary
MCP 에이전트가 서드파티 서버의 도구를 의미 매칭으로 고르는 점을 악용해, 도구 메타데이터로 호출을 유도한 뒤 실행 기록을 바탕으로 조작하는 2단계 블랙박스 탈취 기법 A2M을 제시했다.

## Key Points
- 도구 메타데이터 최적화로 호출 확률 증가
- 실행 트레이스로 조작 메시지 정교화
- MCP 생태계의 의미적 공급망 위험 확인

## Why This Matters
외부 MCP 서버를 붙이는 순간 공급망 공격면이 생기므로, 기업은 허용 목록·도구 검증 절차를 에이전트 도입의 전제로 둬야 한다.
