# 오픈AI, 'GPT-6 솔·루나' 공개…"필요한 성능만 올리고 가격은 반값"

**Source**: AI타임스 | **Published**: 2026-09-23 06:09:40 | **Topics**: llm_models, ai_industry

## Summary
오픈AI가 'GPT-6 솔'과 'GPT-6 루나' 두 모델을 공개하고 API 이용료를 기존 대비 50% 인하했다. 솔은 100만 토큰당 입력 2달러·출력 10달러, 루나는 입력 0.10달러 수준으로 책정됐다. 최고 성능 경쟁보다 실무 핵심 기능의 효율을 끌어올린 것이 특징이다.

## Key Points
- GPT-6 솔·루나 2종 동시 출시
- API 가격 기존 대비 50% 인하
- 솔: 입력 2달러·출력 10달러(100만 토큰당)
- 독립 분석에선 성능 향상폭이 제한적이라는 평가도 나옴

## Why This Matters
프런티어급 모델 단가가 한 번에 절반으로 떨어지면서, 기업은 기존 모델 계약과 사용량 예산을 재산정할 근거가 생겼다.
