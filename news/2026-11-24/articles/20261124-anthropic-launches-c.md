# Anthropic launches Claude Ship, letting AI agents review, fix, and approve code changes

**Source**: TechCrunch AI | **Published**: Mon, 23 Nov 2026 22:05:50 +0000 | **Topics**: llm_models, ai_agents, ai_industry

## Summary
앤트로픽이 '클로드 십(Claude Ship)'을 출시해 AI 에이전트가 풀 리퀘스트를 검토·수정하고 승인까지 할 수 있게 했다. AI 생성 코드가 늘며 생긴 리뷰 병목을 해소하려는 목적이다.

## Key Points
- 에이전트가 PR 검토·수정·승인 수행
- 기존 코드 리뷰 기능을 확장
- AI 생성 코드 증가에 따른 승인 병목 해소 겨냥

## Why This Matters
승인 권한까지 에이전트에 넘기는 단계로, 기업은 자동 승인 범위와 사람 검토 기준을 새로 정해야 한다.
