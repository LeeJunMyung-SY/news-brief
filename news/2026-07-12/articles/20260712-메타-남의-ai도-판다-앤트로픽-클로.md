# 메타, 남의 AI도 판다…앤트로픽 '클로드' 직접 서비스 추진

**Source**: ZDNet Korea | **Published**: Sat, 11 Jul 2026 22:01:57 +0900 | **Topics**: ai_industry

## Summary
메타가 앤트로픽의 AI 모델 클로드를 자사 데이터센터에서 직접 서비스하는 방안을 추진 중이라고 세미애널리시스가 전했다. 클로드 전용 격리 서버 환경인 '프라이빗 인스턴스' 접근 권한을 놓고 앤트로픽과 최종 협상 단계에 있으며, 향후 오픈AI 모델까지 같은 방식으로 서비스할 것으로 전망된다.

## Key Points
- 메타, 자사 데이터센터에서 클로드 직접 서비스 추진
- API 대신 격리형 '프라이빗 인스턴스' 방식
- 앤트로픽과 최종 협상 단계
- MS 파운드리·AWS 베드록·구글 버텍스와 유사한 타사 모델 유통 모델

## Why This Matters
메타가 자체 모델 외 타사 프론티어 모델까지 인프라에 얹어 파는 방향으로 움직이며 AI 모델 유통 구조가 재편되고 있음을 보여준다.
