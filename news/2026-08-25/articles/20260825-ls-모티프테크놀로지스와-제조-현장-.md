# LS, 모티프테크놀로지스와 제조 현장 맞춤형 AI 모델 공동개발

**Source**: 연합뉴스 경제 | **Published**: Tue, 25 Aug 2026 10:52:33 +0900 | **Topics**: llm_models, ai_industry, physical_ai

## Summary
LS일렉트릭의 IT 서비스 자회사 LS ITC가 국내 AI 파운데이션 모델 개발 스타트업 모티프테크놀로지스와 제조 현장 맞춤형 AI 모델을 공동 개발한다. 범용 모델을 그대로 쓰는 대신 현장 데이터에 맞춘 도메인 특화 모델을 확보하는 방식이다.

## Key Points
- LS ITC-모티프테크놀로지스, 제조 특화 AI 모델 공동 개발
- 국내 파운데이션 모델 기업과 대기업 계열 SI의 결합 구도
- 범용 모델 임차 대신 현장 데이터 기반 자체 모델 확보
- 제조 현장 적용을 전제로 한 모델 설계

## Why This Matters
모델 조달 전략이 '빌려 쓰기'에서 '현장 데이터로 직접 만들기'로 이동하는 국내 사례다. 도메인 데이터를 가진 기업이 모델 계층에서도 주도권을 쥘 수 있음을 보여준다.
