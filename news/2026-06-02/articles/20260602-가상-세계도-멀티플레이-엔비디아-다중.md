# "가상 세계도 멀티플레이"…엔비디아, 다중 에이전트 월드 모델 ‘감마 월드’ 공개

**Source**: AI타임스 | **Published**: 2026-06-01 18:18:28 | **Topics**: ai_agents, physical_ai_robotics

## Summary
엔비디아가 여러 AI 에이전트가 동시에 상호작용하는 가상 세계를 실시간 생성하는 월드 모델 '감마 월드(γ-World)'를 공개했다. 기존 단일 에이전트 중심 시뮬레이션을 넘어 다수 플레이어와 로봇이 하나의 환경을 공유하는 '멀티플레이어 월드 모델' 시대를 여는 기술로 평가된다.

## Key Points
- 멀티플레이어 월드 모델 '감마 월드' 공개
- 여러 에이전트·로봇이 한 환경을 공유
- 실시간 가상 세계 생성 지원
- 단일 에이전트 중심 시뮬레이션의 한계 극복

## Why This Matters
다중 에이전트가 공유하는 월드 모델은 로봇·자율 시스템 학습 환경의 확장을 가능케 하는 기반 기술이다.
